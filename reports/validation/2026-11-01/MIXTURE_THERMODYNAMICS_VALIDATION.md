# PR-смесь: протокол проверки 2026-11-01

Реализованы явные компоненты, постоянные бинарные взаимодействия, однородные
PR-состояния, численный multistart TPD, PT/PH/PS и изоэнтальпийный сброс давления.
Код: `src/surface/peng_robinson_mixture.py`, `src/surface/mixture_equipment.py`.
Актуальное описание модели: [термодинамика](../../../docs/THERMODYNAMICS.md).

## Независимый эталон

CoolProp 7.2.0 установлен только в `/tmp/oil-pr-reference`, не добавлен в
зависимости симулятора. Эталон метан–этан: равные молярные доли, давления
1/3 MPa, доли пара 0.1/0.5/0.9, kij=0/-0.03 — 12 равновесных точек.
Получен PQ-вызовом, поскольку прямой PT-вызов этой версии может возвращать
однородный корень внутри двухфазной области. Это сравнение PR с PR, не HEOS
и не экспериментальная проверка.

В 7.2.0 коэффициенты PR округлены до 0.45724/0.07780. При той же конвенции
(только тестовый адаптер) максимальные ошибки: доля пара 2.60e-9,
плотность относительно 6.16e-9. В рабочей модели сохранены точные критические
коэффициенты: соответствующие отличия от округлённого эталона 1.66e-4
и 5.63e-4. Изменения физики ради совпадения не вносились.

Максимальная невязка компонентных молярных долей в этих случаях 2.34e-15,
логарифмов фугитивностей 1.04e-13. Эти числа характеризуют решение равновесия,
не точность EOS относительно реального флюида.

Файл эталона `tests/data/surface/pr_mixture_coolprop.json` воспроизводится
побайтно через `scripts/generate_pr_mixture_reference.py`.
Подробные сравнения и SHA256: `results/surface_mixture_20261101/validation.json`.

## Дополнительные проверки

Регрессия наземной части и FIM-связей на CPU: 336 passed, 23 skipped, 92.01 s.
Тепловой набор: 60 passed; наборы пересекаются, числа не суммируются. Включает независимые фазовые точки, термодинамические
тождества, химические потенциалы из производной Gibbs, инвариантность к порядку
компонентов, трёхкомпонентный flash, PH/PS-возврат, компонентную массу,
вырожденное сосуществование и недопустимые данные.
Старый CLI-пример чистого пропана даёт JSON, идентичный предыдущему результату.
Документация проходит `mkdocs build --strict`.

Пример смеси: `configs/surface_thermal_mixture.json`. При 0.25 kg/s сброс
3→1 MPa с входом 260 K: невязка энергии около 8.68e-10 W,
генерация энтропии около 82.95 W/K. Калорика постоянной Cp иллюстративная,
без независимой экспериментальной калибровки.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_peng_robinson_mixture.py tests/test_surface_peng_robinson.py tests/test_surface_thermal_equipment.py
python scripts/run_surface_thermo.py configs/surface_thermal_mixture.json --output /tmp/mixture.json
PYTHONPATH=/tmp/oil-pr-reference python scripts/generate_pr_mixture_reference.py --output /tmp/pr_reference.json
```

## Ограничения

CPU reference, до двух фаз L/V. Поиск TPD ограничен несколькими стартами,
не является сертификатом глобальной устойчивости. Нет водной фазы/ассоциации,
LLE/трёх фаз, температурных kij, производных flash, GPU-пакетирования или
автоматической интеграции с FIM. Сброс давления не определяет пропускную
способность или критическое истечение смеси. Тепловое сопло чистого вещества
на смесь не перенесено. Результаты Norne этим блоком не изменялись.
