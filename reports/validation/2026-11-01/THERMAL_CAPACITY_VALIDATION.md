# Управление ресурсами PR-схемы: проверка 2026-11-01

Добавлены независимые команды аппаратов по периодам, общие пределы работы,
нагрева и охлаждения, подбор общей допустимой доли подачи и отдельный учёт
непринятых компонентов. Руководство: [тепловая схема](../../../docs/THERMAL_PROCESS.md).

При фиксированных P/T/eta/split все поддержанные операции экстенсивны:
удельные состояния не меняются при общем масштабировании подач, а Q и W
масштабируются. Контроллер оценивает потенциальные нагрузки, учитывает также
абсолютные лимиты отдельных аппаратов и заново решает выбранный режим с
исходными пределами. Фазовые/численные ошибки не становятся ограничением мощности.
Нагрев и охлаждение не компенсируются взаимно в бюджете ресурсов.

Команды не изменяют соединения и применяются к исходному рецепту независимо
для каждого периода. Проверяются и при остановке. Пределы периода полностью
заменяют корневой блок на этот период. Checkpoint версии thermal_molar_process_v2
включает команды, ресурсы и отдельные requested/product/unprocessed накопления.
При чтении дополнительно проверяются массы принятых записей против запрошенных
подач, а не только контрольная сумма. Старые checkpoint другой реализации
отклоняются, не мигрируют автоматически.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_thermal_capacity.py tests/test_surface_thermal_process.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_surface_process.py configs/surface_thermal_process_controlled.json --output /tmp/controlled.json --stop-after 1
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_surface_process.py configs/surface_thermal_process_controlled.json --checkpoint /tmp/controlled.json --output /tmp/controlled.json
```

## Границы

Общий множитель всех подач, заданные давления и температуры, постоянная
эффективность, нет зависящих от расхода карт или гидравлики. Это не оптимальное
распределение индивидуальных скважин, не динамический баланс запасов,
не расчёт электрической сети или теплообменников конечной площади.
Тепловые свойства остаются демонстрационными постоянными Cp PR-смеси.
Непринятая подача учитывается в самостоятельной площадке, но не изменяет
дебиты пластового FIM. Водная фаза, динамика аппаратов и тепловая связь
с FIM не добавлены. Norne и GPU-ядро этим блоком не менялись.
