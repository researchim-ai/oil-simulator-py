# Равновесное сопло смеси: проверка 2026-11-01

Добавлен `MixtureEquilibriumNozzle`: общий состав, изоэнтропийный путь PR/PS,
максимум массового потока, критическая полка, отдельный PH-выход смешанного
потока, компонентные массы и проверка энергии/энтропии. CPU reference,
не интегрирован автоматически в black-oil FIM.
Актуальные уравнения и ограничения: [термодинамика](../../../docs/THERMODYNAMICS.md).

## Найденные и исправленные ошибки flash

1. При появлении второй фазы выигрыш полной энергии Gibbs может быть гораздо
меньше 1e-9, хотя TPD уже отрицателен. Фиксированный минимальный выигрыш
отбрасывал допустимое разделение. Теперь проверяется отсутствие увеличения
Gibbs в пределах округления; остальные критерии равновесия сохранены.
2. У границы beta=1 ограниченный least-squares мог завершаться по малому
масштабированному градиенту, хотя невязка оставалась выше допуска.
Остановка по этому признаку отключена; фактические невязки фугитивностей
и компонентного баланса продолжают проверяться.

Короткие регрессии: 3 MPa/205.752 K (beta≈2.32131e-5),
2166248.9107809598 Pa/240.9752268266243 K (beta≈0.999999913963).
Невязки проверяются без ослабления прежних допусков. Ошибки flash не
перехватываются для замены смеси однофазной аппроксимацией.
Удалены повторяющиеся стартовые оценки K; PH/PS повторно используют уже
рассчитанные в том же вызове температуры, без межшагового кеша состояния.

Включает независимые PR-эталоны, near-bubble/dew, идеальногазовый предел

9→17 точек, закрытие и неразрешённое критическое давление на границе диапазона.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_mixture_nozzle.py tests/test_surface_peng_robinson_mixture.py tests/test_surface_peng_robinson.py tests/test_surface_thermal_equipment.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_surface_thermo.py configs/surface_thermal_mixture_nozzle.json --output /tmp/nozzle.json
```

HEM предполагает общую скорость фаз и мгновенное фазовое равновесие.
Нет водной фазы, проскальзывания, задержки вскипания, IEC sizing, двухфазного
Mach, экспериментальной калибровки Cp/kij/Cd или GPU-пакетирования.
Критический поиск и TPD используют конечное число стартов/точек, не дают
математического сертификата глобальности. Norne не перезапускался:
пластовый решатель и его термодинамика этим опциональным блоком не изменены.
