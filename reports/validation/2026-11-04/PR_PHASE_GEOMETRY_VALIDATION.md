# PR-слои, конечные фазовые патрубки и уровень — 4 ноября 2026

Добавлено кинематическое геометрическое замыкание к компонентному
PR-сепаратору и общей PR-сети Torch float64 CPU/CUDA: горизонтальный/
вертикальный цилиндр, фазовые слои, круглый патрубок конечного диаметра,
неявное пропорциональное регулирование верхней границы выбранной фазы.
Руководство: [PR_PHASE_GEOMETRY.md](../../../docs/PR_PHASE_GEOMETRY.md).

**Область подтверждения:** общий P/T, заданная идеальная структура слоёв,
`g=0`. Это не пространственный гравитационный PR-профиль, не осаждение,
не капельный унос и не критическое истечение. Ненулевая g с этой
геометрией отклоняется. Для несмешивающихся жидкостей/идеального газа
прежняя гравитационная трёхфазная модель остаётся отдельным режимом.
FIM/Norne этим изменением не затронуты.

## Реализованный расчёт

EOS-фазы упорядочиваются по плотности, их объёмы задают высоты границ
через геометрию цилиндра. Неопределённое по плотностям расположение слоёв
не принимается. Площади фаз на отверстии вычисляются разностью круглых
сегментов. Для геометрического отбора этот вес заменяет долю глобального
фазового объёма, а не умножается на неё повторно. Поток переносит состав,
энтальпию и энтропию фактически извлекаемых фаз. При реверсе используется
патрубок другого сосуда.

Уровневый регулятор распознаёт фазу по наибольшей доле заданного
компонента и порогу. Если распознаваемой фазы нет, автоматическое
открытие равно нулю, включая положительное смещение и нулевой порог
при точном отсутствии компонента. Ручное открытие явно имеет приоритет.
Датчик, конечные границы слоёв и открытие входят в общий якобиан.

Убрано повторное обращение геометрии для общей верхней/нижней границы
соседних слоёв; в локальном расчёте потока повторно используется один
layout. Это сокращение вычислительной работы, а не измеренное заявление
об ускорении всей связанной модели.

`configs/surface_pr_geometry_network.json`: горизонтальный и вертикальный
сосуды с конечными запасами, геометрические патрубки, неявное уровневое

**24 принятых подшага, 0 дроблений**. Межсосудный поток ненулевой в
разрешённых периодах, открытия меняются по конечному уровню. Порог
распознавания этановой фазы 0.75 выбран между долями этана в жидкой
и газовой фазах этого примера; коэффициенты не калиброваны по установке.
Обратный поток подтверждён отдельными контрактными случаями выше.

Оба полных сценария повторены на RTX 3090: по **24 принятых подшага,
0 дроблений**, два фазовых состояния на каждом шаге.
Независимая CPU/CUDA-реконструкция прошла для обоих журналов.
Максимальные различия конечного одиночного сосуда: **1.060e-8 Pa**,
**5.116e-13 K**, **9.948e-14 mol**. В связанной сети:
**8.848e-9 Pa**, **1.990e-13 K**, **1.191e-13 mol**;
температура стенки совпала. Молярные разности приведены по максимальному
компоненту; это сравнение устройств одного решателя.

## Независимая реконструкция

Оба checker используют отдельный CPU-эталон
`scripts/compositional_geometry_audit.py`: скалярное обращение геометрии
через прежний метод и отдельные формулы круглых сегментов. Torch-layout,
Torch-патрубок и нелинейный решатель при реконструкции не вызываются.
EOS общая с runtime; это независимость сборки геометрии и балансов,
а не сравнение с другим промышленным термодинамическим пакетом.

Реконструированные максимальные CPU-невязки одиночного сосуда:
компоненты 3.670e-15 mol, энергия 1.760e-10 J, стенка 3.045e-11 J,
объём 1.952e-18 m³, логарифмические фугитивности 6.0e-15.
В связанной CPU-сети: компоненты 4.976e-15 mol, энергия флюида
3.493e-10 J, стенка 3.667e-11 J, общий энергетический баланс
4.753e-10 J. Это невязки дискретного решения, не точность реальных свойств.

Для CUDA-одиночного сосуда: компонентная невязка < 4.9e-15 mol,
энергетическая < 3.0e-10 J; для CUDA-сети — < 6.3e-15 mol и
< 4.9e-10 J локально, < 5.5e-10 J в общем энергетическом балансе.
Отдельные максимальные расхождения расхода между независимой геометрией
и runtime: < 1.7e-12 mol/s и < 3.7e-8 W для одиночного патрубка,
< 5.7e-15 mol/s и < 1.3e-10 W для межсосудного соединения.

Изменение в журнале площади патрубка, границы слоя либо показания
уровневого датчика с заново вычисленным checksum отклонено аудитором.
Конфигурация с ненулевой g отклонена CLI с сохранением прежнего
выходного файла. Эти отрицательные случаи сохранены в
`negative_verification.json`.
