# Полная энергия трубы: проверка 2026-11-02

## Изменение и область

Добавлен горизонтальный ThermalHomogeneousPipe: две замороженные фазы,
одна скорость/температура, несжимаемая жидкость, идеальный газ, явные
постоянные Cv. Консервативные массы/импульс/полная энергия решаются одним
неявным шагом. Энергетический поток (E+P)v включает работу давления.
Трение уменьшает кинетическую энергию, но не является внешним стоком E.
Тепловая связь — заданная температура окружения с явным H в W/(m K),
без запаса металла. Ненулевой дрейф, C0≠1 и наклон отклоняются явно.

Это не реализация полного энергетического drift-flux/PR/black-oil контура.
Нет фазового обмена, нефтяного/водного компонентов отдельно, реальной
калибровки Cv/H, GPU и сопряжения с пластом. Реальные данные пользователь
не предоставил. Тепловое проскальзывание и гравитационная энергия открыты.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --output results/thermal_pipe_20261102/full.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --stop-after 1 --output results/thermal_pipe_20261102/partial.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --checkpoint results/thermal_pipe_20261102/partial.json --output results/thermal_pipe_20261102/resumed.json
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/check_pipe_acoustics.py --thermal --output results/thermal_pipe_20261102/acoustics.json
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/benchmark_transient_pipe.py --thermal --output results/thermal_pipe_20261102/benchmark.json
```

CLI: три периода (горячая подача, закрытие, обратный перепад), время 0.06 s,
восемь конечных объёмов. Полный JSON равен JSON после partial/resume.
Максимальная невязка энергии шага 2.0634491e-7 J,
массы 1.1695800e-11 kg. Внешнее тепло 2276.8342803 J.
Невязки дискретных уравнений не являются ошибкой физической модели.
Контрольная точка включает полную энергию и её накопленный граничный аудит;
новые исходники несовместимы по fingerprint с прежними checkpoint.

## Независимый предел PDE

Малая стоячая адиабатическая волна без трения/теплообмена: фон 1 MPa,
300 K, alpha=0.98, амплитуда давления 100 Pa, время 0.005 s.
Изэнтропическое начальное возмущение и замкнутые границы.
Сетка и время уточняются совместно: N=8/16/32, dt=0.004/N s.
Средняя ошибка давления относительно линейного решения:
3.89687 / 2.06560 / 1.06006 Pa.
Ошибка температуры: 8.11388e-5 / 4.30089e-5 / 2.20720e-5 K.
При уточнении обе ошибки уменьшаются примерно вдвое.
Это проверка однородного калорического предела, не эксперимента со slip.
