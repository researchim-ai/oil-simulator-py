# Двухфазное HEM-соединение сети: проверка 2026-11-02

Добавлен `HEMNozzleConnection` (`pr_hem_nozzle`) в монолитную динамическую сеть.
Входной порт/горловина могут иметь одну или две фазы; фазовое изменение на
изоэнтропе не заменяется сухим газом. Физическая невязка и принятый поток
всегда используют полный существующий HEM-поиск.
Руководство: [двухфазная HEM-связь](../../../docs/DYNAMIC_NETWORK.md).

## Сохранение и область

Компонентный состав переноса берётся из текущего порта донора, полная
энтальпия переносится в принимающий запас. Двухфазные Mach/звук не возвращаются.
Прямое/обратное течение и коэффициент площади используют общую проверенную
обвязку PR-соединений. Минимальное давление, пределы расхода/перепада,
фазовая область и общий баланс проверяются без обрезания потока.

В пределах нелинейного шага точно совпадающие EOS/P/T/состав/параметры
поиска повторно используют PS-путь и критическую ёмкость. Изменённый донор
требует нового пути. Самостоятельный HEM по умолчанию сохраняет прежний PH-выход;
сеть решает его смешение сама и не создаёт отдельный пустой выходной объём.

## Якобиан

Для гладкого внутреннего максимума расхода используется dG/dPcrit=0.
Частные производные по исходным параметрам оцениваются при фиксированном
Pcrit, без повторного поиска максимума для каждого возмущения. Касательная
привязана к точному расходу базовой точки. Проверяются центральная и обе
односторонние производные по давлению горловины, фазы, конечность и границы.
Фазовая/негладкая/неразрешённая точка получает полный численный якобиан.
Невязка никогда не получает интерполированный поток.

PS-подсказка температуры ускоряет только поиск скобки; при необходимости
скобка расширяется до полной заявленной области. Уравнение, PT/VLE-проверка
и допуск результата сохранены. Численный отказ производной может вернуть
дорогую точную численную производную, но не другую модель истечения.

## Проверки

Общий CPU-набор: 398 passed, 23 skipped, 235.85 s. Целевой набор:
6 passed, 72.48 s; наборы пересекаются, числа не суммируются.
Проверены exact cache/critical plateau/изменение донора, масштаб площади,
однофазный вход с двухфазной горловиной, отказ однофазной PR-модели на том же
пути, критическая касательная против полного поиска, свежий физический replay,
двухфазный общий шаг, обратное направление, закрытие, restart и PS-подсказка.

Старый standalone-пример `surface_thermal_mixture_nozzle.json` даёт JSON,
полностью идентичный ранее сохранённому результату. Это проверка отсутствия
изменений самостоятельного режима по умолчанию после рефакторинга кэша.

## Сквозной пример

`configs/surface_vessel_network_hem.json`: исходный донор 3 MPa/220 K,
приёмник 1 MPa/220 K, каждый 0.01 m³, метан–этан 50/50 молярно.
A=1e-8 m², Cd=0.8, Pmin=0.5 MPa. Один открытый шаг 0.01 s и закрытый
шаг 0.01 s. Это короткий smoke-сценарий сохранения/связности, не длительный
промышленный прогон.

При открытии: входной порт и горловина двухфазные, молярная доля пара
горловины около 0.3860443; расход около 0.0037384565 mol/s,
критическое давление около 1.9568632 MPa. При закрытии расход нулевой.
Максимальная невязка энергии шага около 2.55e-10 J.
Прямой CLI и продолжение после открытого шага полностью совпадают.
Подробные остатки и SHA256: `results/hem_network_20261102/validation.json`.
Strict MkDocs, Ruff и git diff --check проходят.

Первый диагностический запуск выявил высокую стоимость полного HEM внутри
всех возмущений якобиана. Касательные уменьшают число полных поисков,
но контролируемый парный benchmark всей сети пока не выполнялся;
одиночные smoke-времена не используются как релизное обещание ускорения.
HEM-связь остаётся существенно дороже однофазного PR-sonic режима.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_hem_connection.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network_hem.json --output /tmp/hem.json --stop-after 1
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network_hem.json --checkpoint /tmp/hem.json --output /tmp/hem.json
```

## Ограничения

Мгновенное равновесие и одинаковая скорость фаз, PR с демонстрационными
постоянными Cp/kij. Нет воды, задержки вскипания, проскальзывания, linepack,
инерции/геометрии труб, событийных защит, GPU или теплового FIM. Сканирование
экстремумов и TPD имеют конечное число точек/стартов, глобальная полнота
математически не сертифицирована. Экспериментальная точность реального
нефтегазоводяного штуцера не подтверждается этими тестами. Norne не менялся.
