# Монолитная динамическая сеть: проверка 2026-11-02

Добавлены `VesselConnection`, `DynamicVesselNetwork`, расписание связанной
динамики и атомарный CLI/JSON restart. Руководство:
[динамическая сеть](../../../docs/DYNAMIC_NETWORK.md).

## Метод

Компонентные запасы/P/T всех сосудов решаются одновременно с балансом U и
постоянного объёма каждого. Поток связи зависит от новых давлений, состав и
энтальпия — от новой фазы фактического донора. Конечные разности видят
межаппаратные зависимости; кэш неизменённых локальных EOS-блоков сокращает
повторные термодинамические вычисления. Это CPU reference с плотным численным
якобианом, не масштабируемое GPU-ядро.

Связь — явно заданная линейная молярная проводимость с ограниченной областью
перепада/расхода. При выходе из неё состояние отклоняется, расход не обрезается.
Проводимость примера демонстрационная, не получена из измерений реального клапана.
Для обратного потока меняются донор и фазовый порт. Коэффициент проводимости
0..1 задаётся отдельно для каждого периода; ноль закрывает связь.

Внутренний компонентный/энтальпийный поток вычитается и добавляется одним
значением. В накопления границы входят только внешние потоки и тепло.
Ни скрытого lag по предыдущему состоянию, ни двойного учёта внутренних потоков.

## Проверки

Общий CPU-набор: 383 passed, 23 skipped, 156.36 s. Промежуточный целевой
набор до команд проводимости: 8 passed; он перекрывается с общим.
Проверки: связь по новым давлениям/составам, прямой/обратный поток,
закрытая связь, кольцо из трёх аппаратов, независимость от порядка перечисления,
один сосуд против исходного решателя, двухфазный перенос пара, границы
калибровки, численный отказ/rollback, общий дробящийся шаг, периодное
закрытие/открытие, внешний баланс, точный JSON resume и повреждённый checkpoint.

## Сквозной пример

`configs/surface_vessel_network.json`: два сосуда по 0.01 m³, исходные
2/1 MPa и 300 K, разные составы метан–этан. Переток 2 s, закрытая связь
с нагревом приёмника 100 W в течение 1 s, повторное открытие с множителем
0.5 и внешним отбором 0.01 mol/s ещё 2 s. Всего десять подшагов.

Конечные давления приблизительно 1.9302765/1.0728915 MPa,
температуры 297.878031/304.063119 K. Максимальная невязка энергии одного
шага около 1.10e-11 J. Внешний отбор всего 0.02 mol, подача отсутствует,
подведено 100 J тепла. Внутренние перетоки не попадают в внешний отбор.
Энтальпия относительно выбранного нуля может быть отрицательной;
знак её численного уровня не меняется ради отчёта.

Прямой CLI и продолжение после первого периода совпадают целиком, включая
состояния, историю шагов, интегралы и checksum. Данные и SHA256 —
`results/vessel_network_20261102/validation.json`. Строгая сборка MkDocs,
Ruff и git diff --check проходят.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_vessel_network.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network.json --output /tmp/network.json --stop-after 1
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network.json --checkpoint /tmp/network.json --output /tmp/network.json
```

## Оставшиеся ограничения

Линейная связь не заменяет газовый/двухфазный штуцер, трубопровод или sizing.
Нет linepack, инерции, воды, фазового проскальзывания, термики стенки,
событийного переключения портов/защит, GPU или FIM-связи. Калорика PR примера
демонстрационная. Короткий прогон доказывает численную связность/сохранение,
не экспериментальную точность или длительную промышленную устойчивость.
Norne и пластовое ядро этим модулем не менялись.
