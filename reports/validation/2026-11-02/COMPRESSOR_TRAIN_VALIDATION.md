# Компрессорная карта, динамический коллектор и антипомпаж

Дата: 2026-11-02. Реализованный блок: один сухой идеальный газ,
табличный компрессор, инерция вала, M/U нагнетательного коллектора,
конечные экспорт/рециркуляция и два цифровых регулятора. CPU.

## Что закрыто

- Приведённые координаты с явными p_ref/T_ref, билинейная карта по
  скорости/beta, изоэнтропический КПД, механическая и электрическая мощности.
- Диапазоны скорости/расхода, помпажная граница, максимальные температура
  и мощность. Ограниченные пробные состояния решателя помечены и не
  принимаются за физическое продолжение вне карты.
- При малом противодавлении выбранная схема включает правую границу
  расхода карты и явно учитываемый адиабатический trim-клапан нагнетания.
- Совместное неявное решение запасов/энергии газа и скорости вала;
  работа на валу согласована с кинетической энергией.
- Рециркуляция с конечной сопловой пропускной способностью, динамикой
  открытия и тепловой нагрузкой кондиционирования до T_suction.
- PI/PID скорости и запаса до помпажной границы, anti-windup по фактическим
  моменту/положению, override быстрого открытия, ручной режим и stuck.
- Standby для разгруженного запуска/торможения, run в области карты,
  off с выбегом и trip с защёлкой до явного сброса.
- Сквозные массовый/энергетический балансы и дискретная энтропия,
  расписание, атомарный JSON и restart с аудитом потоков/работ/двух PID.

Основные исходники: `compressor_map.py`, `compressor_train.py`,
`compressor_schedule.py`. Руководство: [модель](../../../docs/COMPRESSOR_TRAIN.md).
Карта и PID примера синтетические; паспортных данных нет.

## Независимые формулы

Определения приведённых расхода/скорости сопоставлены с
[Compressor (G), corrected coordinates](https://www.mathworks.com/help/hydro/ref/compressorg.html).
В нашем формате beta=0 — surge, beta=1 — choke; ориентация противоположна
приведённому источнику. Таблицы конкретной машины из него не копировались.

`scripts/check_compressor_train.py` независимо вычисляет:

1. Адиабатическую критическую продувку жёсткого идеальногазового объёма:
   T/T0=(M/M0)^(gamma−1), p/p0=(M/M0)^gamma; аналитическое M(t) строится
   из критического соплового расхода. Условия критичности проверяются.
2. Специально построенные стационарные частичную/полную рециркуляции:
   табличная точка, отдельная изоэнтропическая формула, сопловые площади
   для заданного разбиения потока, момент баланса вала и тепловая нагрузка.

Для продувки при dt=0.04/0.02/0.01 s ошибки массы:
0.0015183533 / 0.0007624688 / 0.0003820642 kg.
Отношения 1.99136 и 1.99566 подтверждают ожидаемый первый порядок
газового неявного баланса. Ошибка T на dt=0.01 — 0.01428624 K.
Эталонные M/T: 5.0656873893 kg и 295.40180995 K.

Для рециркуляции 60%: за 0.5 s экспортировано 0.1 kg,
возвращено 0.15 kg, отведено 7606.95513071 J кондиционирования.
Для полной рециркуляции: экспорт 0, возврат 0.25 kg,
отведено 12678.25855118 J. Значения тепла совпадают с независимыми
формулами до порядка 1e-11 J; дрейф M/U/скорости в этих построенных
равновесиях равен нулю в машинном представлении.
Внешний обмен массой при полной рециркуляции — roundoff порядка 1e-16 kg.

Это численная верификация, не промысловая калибровка и не эксперимент
по реальному помпажу. Нестационарная модель не объявляется вторым порядком
по одному только уравнению ротора.

## Сценарий 45.4 s

`configs/surface_compressor_train.json`, восемь периодов:

1. Разгруженный разгон 4.4 s: скорость 80.6910 rad/s.
2. Run 8 s с экспортом: скорость 85.0105 rad/s, давление 131482.1 Pa,
   конечный запас 0.52174.
3. Снижение открытия экспорта до 0.05: рециркуляция открывается;
   минимальный фактический запас **0.0759293**, конечный 0.2501995.
   Цель 0.25 кратковременно не достигается; это не скрывается.
4. Полная рециркуляция при закрытом экспорте: конечный запас 0.2500185.
5. Запрос 140 rad/s: привод ограничен 50 kW, конечная скорость
   **115.0222 rad/s**, ошибка 24.9778 rad/s. Уставка не объявляется достигнутой;
   запас сохраняется, конечное давление 159065.8 Pa.
6. Trip: питание снято, машина разгружена, рециркуляция открывается,
   газ возвращается во всасывающий резервуар, вал продолжает выбег.
7. Запрос run без reset оставляет effective_mode=off.
8. Standby после reset с отрицательным моментом: вал остановлен.

Максимальные остатки за весь сценарий: масса 1.10e-13 kg,
сквозная энергия 4.05e-8 J. Минимальное дискретное производство
энтропии 3.71e-5 J/K. Все периоды проходят без отказов подшага.
Непрерывный запуск и продолжение после четвёртого периода дают
побайтно одинаковые JSON.

## Негативные проверки

Заклинивший закрытый клапан и недостаточная площадь рециркуляции
приводят к явному `CompressorEnvelopeError` на помпажной границе,
а не к подмене расхода безопасным значением. После принятых подшагов
сохраняется последнее принятое физическое состояние для отдельного
отключения; обычный restart проверяется на границах завершённых периодов.

Проверяются также ограничения кондиционирования, температуры/мощности,
нулевая электрическая мощность, приведённый потолок скорости при другой
T_suction, неподвижный коллектор, выбег и число тактов PID при дроблении.
Подмена сохранённых потоков/работ/памяти PID выявляется даже после
пересчёта checksum. Самопроизвольный переход в постпомпажный цикл
или свободное обратное вращение в этой модели не рассчитываются.

## Границы закрытого блока

Одна машина и один сухой идеальный газ с фиксированным всасывающим
резервуаром. Рециркуляционное тепло имеет явный источник/сток; возврат
не считается новой подачей. PR/конденсация/многофазность, действительная
неустойчивая ветвь/вращающийся срыв, всасывающие запасы, распределённые
трубопроводы, группы агрегатов, переменные входные условия, FIM и GPU
остаются следующими расширениями. Операторский trip не называется
сертифицированной системой безопасности.
