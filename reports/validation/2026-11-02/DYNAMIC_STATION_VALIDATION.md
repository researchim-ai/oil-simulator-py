# Динамическая параллельная насосная станция

Дата: 2026-11-02. Блок: независимые валы параллельных насосов,
квазистационарная несжимаемая жидкостная сеть, общий электрический бюджет,
диспетчеризация и резервирование. CPU; карты и PID синтетические.

## Реализация

- `src/surface/dynamic_station.py`: совместное неявное midpoint-решение
  всех скоростей через общую гидравлику; индивидуальные события остановки.
- Общие валовые import/export-бюджеты, индивидуальные пределы приводов,
  ограничение скорости через момент, рекуперация/диссипативное торможение,
  мощность холостого хода и сквозной механический баланс.
- Существующие стационарные кандидаты оцениваются по электрическому
  потреблению с потерями; выдержка времени, deadband, отказ и резерв.
- Два уровня цифровых PID, tracking фактического воздействия,
  независимые физические подшаги, trip с защёлкой и сохранение доступности.
- `dynamic_station_schedule.py`: checksum, отпечатки численных исходников,
  модели, расписания и NumPy/SciPy, полное однократное воспроизведение
  предшествующей истории на restart. Плата за replay явная.
- `scripts/run_dynamic_station.py`: атомарный JSON; пример
  `configs/surface_dynamic_station.json`; руководство
  [DYNAMIC_STATION](../../../docs/DYNAMIC_STATION.md).

## Независимый эталон

`scripts/check_dynamic_station.py` вычисляет общий напор из собственного
скалярного массового баланса, квадратичных характеристик насосов и
сопротивления Пуазейля. Нагрузка не вызывает код насосной/сетевой модели.
Две связанные ОДУ валов интегрируются DOP853, rtol=atol=1e-12.
Инерции, характеристики, номинальные скорости, КПД и P0 агрегатов различны.

Гладкий случай, горизонт 4 s, начальные скорости 90/96 rad/s:

- dt=0.2 s: максимальная ошибка скорости 0.000535806278 rad/s;
- dt=0.1 s: 0.000133921227 rad/s;
- dt=0.05 s: 0.000033478413 rad/s.

Отношения ошибок 4.000906 и 4.000226. Эталонные конечные скорости:
100.5304391553 и 105.5654185818 rad/s.
Ошибка гидравлического давления при тех же скоростях ≤5.83e-11 Pa,
расхода ≤1.41e-18 m³/s; максимальный остаток энергии подшага ≤3.94e-12 J,
узлового массового баланса ≤4.34e-16 kg/s в этой задаче.
Это проверка формул/численного метода, не точность реального оборудования.

Отдельный случай открытия обратного клапана, начальные скорости 90/105 rad/s:
dt=0.025 s, ошибка скорости 0.000018904860 rad/s при допуске 0.0002 rad/s.
Идеальное отношение четырёх на негладком переключении не требуется.

Эталон с SHA256 исходников: `results/dynamic_station_20261102/reference_final.json`.

## Полный сценарий 56 s

1. Запуск: выбраны p1/p2, p3 в резерве. В t=20 s скорости
   103.712079/103.712079/0 rad/s, ошибка давления 1719.8194 Pa
   при уставке 400000 Pa.
2. Отказ p1: выбран p2/p3. В t=40 s скорости
   61.679779/103.972533/103.972533 rad/s; ошибка 814.2885 Pa.
   p1 физически выбегает, его кинетическая энергия не исчезает.
3. Возврат доступности p1 с redispatch: сохранён p2/p3 по deadband;
   в t=45 s ошибка давления 291.1471 Pa.
4. Trip на 2 s и попытка auto ещё 1 s без сброса: питание остаётся снятым,
   все три вала продолжают выбег, электрическое потребление равно нулю.
5. Явный сброс trip и торможение всех агрегатов: в t=56 s скорости нулевые;
   максимальный экспорт 784.1952 W, в покое фиктивной рекуперации нет.

Общий import-лимит 1000 W выдержан с округлением порядка 2.3e-13 W.
За сценарий приняты 594 физических подшага. Отклонены 33 пробы:
31 по ограничению изменения скорости, одна по нелинейному решению валов
и одна из-за сингулярного пробного гидравлического якобиана при торможении.
Дробление восстановило расчёт, отчётный интервал пройден полностью.
Это **не** сценарий без отклонённых проб; причины сохранены в JSON.
Максимальный остаток энергии подшага 1.408e-7 J,
суммы граничных массовых переносов 5.56e-17 kg.

Интегрально за весь сценарий: из сети получено 38096.6068241 J,
потери агрегатов 21000.1821713 J, потери труб/арматуры 12460.8299379 J,
граничная работа 4635.5947162 J. Начальные и конечные скорости нулевые;
накопленный остаток энергии −1.272e-6 J (около 3.34e-11 от электрического
обмена). Это остаток дискретного баланса, а не физическая точность модели.

Полный JSON и continuation после двух периодов побайтно совпали:
SHA256 `2343f28795f0ce9fe2d1e851c7a307e3998a4ac888d3399749131faa64f321e0`.
Файлы: `results/dynamic_station_20261102/full.json`, `partial.json`,
`resumed.json`, `scenario_summary.json`.
Полный запуск занял 15.70 s wall; continuation с воспроизведением первых
двух периодов — 18.44 s. Это разовый малый CPU-замер параллельно с
регрессионными проверками, не изолированный performance-бенчмарк,
не время Norne и не оценка ускорения GPU.

## Проверки и воспроизведение

26 целевых тестов покрывают независимую ОДУ, предел одного насоса,
взаимное влияние валов/клапанов, отдельные остановки, слабый разгон,
общие/индивидуальные ограничения, нулевую рекуперацию, electrical dispatch,
отказ с обходом dwell, восстановление давления, недостижимую уставку,
trip, PID при повторе шага, независимость dwell от порядка имён
и подделку checkpoint с пересчитанным checksum.

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
python -m pytest -q tests/test_surface_dynamic_station.py
python scripts/check_dynamic_station.py --output results/station/reference.json
python scripts/run_dynamic_station.py configs/surface_dynamic_station.json \
  --output results/station/full.json
python scripts/run_dynamic_station.py configs/surface_dynamic_station.json \
  --stop-after 2 --output results/station/partial.json
python scripts/run_dynamic_station.py configs/surface_dynamic_station.json \
  --checkpoint results/station/partial.json --output results/station/resumed.json
cmp results/station/full.json results/station/resumed.json
```

Широкая регрессия поверхности и FIM-сопряжения:
**728 passed, 23 skipped, 2 warnings**, 404.33 s.
Лог: `results/dynamic_station_20261102/regression.log`.
Предупреждения относятся к beta API PyTorch (`index_reduce_`, sparse CSR).
Команда:

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 MPLCONFIGDIR=/tmp/norne-mpl \
python -m pytest -q tests/test_surface*.py tests/test_fim*surface*.py \
  tests/test_fim_facility_coupling.py tests/test_fim_blackoil_active.py \
  tests/test_fim_blackoil_valve.py -m 'not slow'
```

После старта широкого набора добавлено последнее исправление: перестановка
имён тех же работающих насосов не сбрасывает время физического переключения.
Финальный целевой набор после этого исправления: **26 passed**, 22.74 s,
`results/dynamic_station_20261102/targeted_final.log`. Полный сценарий,
restart и независимый эталон повторены на конечных численных исходниках;
приведённые выше SHA и результаты относятся к ним. Полный широкий набор
после этой последней правки повторно не запускался.

SHA256 конечного `dynamic_station.py`:

SHA256 `dynamic_station_schedule.py`:

## Оставшиеся границы

Нет реальных паспортных данных и калибровки. Не реализованы обратное
вращение/турбинные квадранты, динамические запасы трубопроводов,
гидроудар и тепловой перенос в жидкости. Станция не включена в единый
компонентный/энергетический контур PR/FIM. Минимальные расход и запас
NPSH политики служат проверкой стационарных кандидатов, а не отдельными
переходными защитами. Этот блок не завершает весь промышленный моделер.
