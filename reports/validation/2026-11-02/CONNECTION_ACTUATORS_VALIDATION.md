# Приводы соединений: проверка 2026-11-02

## Реализованный блок

Нормированное положение соединения движется по аналитически интегрируемому
апериодическому закону с разными ограничениями скорости открытия и закрытия.
Модель работает внутри динамической PR-сети: линейная проводимость,
однофазное PR-сопло, двухфазное HEM-сопло используют фактическое положение
нового слоя. При tau=0 достижение команды конечное; при tau>0 — асимптотическое.
Добавлены normal/fail_safe/stuck, явное отказное положение и ограничение
изменения положения за принятый подшаг.

Событийная защита меняет команду, а не положение. Локализация времени события
повторно решает тот же физический подшаг из прежних запасов и положения.
Отказанные пробы не продвигают привод. Контрольная точка v4 сохраняет историю
и проверяет команды/отказы, закон движения, непрерывность и конечные положения.

## Комбинированный CLI-сценарий

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network_actuated.json --output results/actuators_20261102/full.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network_actuated.json --stop-after 2 --output results/actuators_20261102/partial.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_vessel_network.py configs/surface_vessel_network_actuated.json --checkpoint results/actuators_20261102/partial.json --output results/actuators_20261102/resumed.json
```

Два аппарата со стенками, 4 периода, длительность 5 s,
23 принятых подшага и 13 отклонённых проб, включая ограничения хода.
Полный JSON равен JSON после сохранения/продолжения.
Максимальная невязка энергии шага 5.0860649e-11 J.
Первая защита по давлению: 0.562425002447695 s; повторное начальное срабатывание
после сброса: 3 s. Конечное положение 0.17181875183577122: привод ещё не успел
закрыться. Давление не обрезается по порогу, закрытие не объявляется исполненным.

Сырые JSON, журналы и SHA256 исходников/конфига:
`results/actuators_20261102/validation.json` и соседние файлы.
