# Проверка отдельной механики привода

Дата: 2026-11-02. Новый блок `src/surface/rotating_drive.py`.
Область: однонаправленный вал, постоянные моменты двигателя/нагрузки
внутри периода, линейное вязкое сопротивление, идеализированное
преобразование электрической/механической энергии. CPU.

## Что реализовано

- Аналитические разгон и выбег с инерцией, устойчивый предел b→0.
- Точное определение остановки и идеальный удерживающий упор при ω=0.
- Рекуперативное и полностью диссипативное торможение.
- Работа нагрузки, изменение кинетической энергии, вязкие потери и
  электрические потери учитываются раздельно.
- Независимые проверки механического и общего энергетического балансов.
- Ограничения момента, скорости, пикового потребления/экспорта мощности
  на всей монотонной траектории; команда не обрезается молча.
- Проба момента нагрузки из уже существующих характеристик `Pump`,
  включая их границы расхода/мощности/NPSH.
- Расписание команд, checksum и отпечаток модели/исходников, атомарный CLI.
  При restart аналитическая история воспроизводится и проверяется заново.

## Метод проверки

Скорость проверяется по независимым формулам постоянного ускорения
и экспоненциального движения. Интегральная работа и вязкие потери —
против численной квадратуры при b от 0 и 1e-12 до 1e4 N m s.
Остановка, отрицательный электрический поток при рекуперации,
нулевой экспорт при диссипативном торможении, ограничения пиков
и аддитивность работ при разбиении интервала проверяются отдельно.

Насосный адаптер сверяется с существующей статической моделью:
при половинной скорости и половинном расходе мощность уменьшается
в восемь раз, момент — в четыре. Нулевой скорости с ненулевым расходом
не приписывается физически допустимый рабочий режим.

Сохранённая история с изменённой работой отвергается даже после
пересчёта checksum: повторное аналитическое вычисление обнаруживает
расхождение. Изменённая модель/расписание отвергаются по fingerprint.
Непредставимая траектория из конечных, но чрезмерных исходных величин
считается численным отказом, а не ограничением оборудования.

## Пример

`configs/surface_rotating_drive.json`: J=5 kg m², b=0.2 N m s,
КПД двигателя 0.9, рекуперации 0.7. Разгон 10 s, выбег 5 s,
период торможения 20 s. Скорости после периодов около
24.7260, 20.2439 и 0 rad/s. В последнем периоде остановка происходит
через 7.26817 s, оставшееся время вал покоится.
Электрическая энергия по периодам около +2930.002, 0 и −490.059 J.
Максимальные остатки механического/общего балансов около 4.55e-13 J.
Это синтетический пример, паспортных измерений нет.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_rotating_drive.py tests/test_surface_equipment_maps.py tests/test_surface_controls.py tests/test_surface_station.py tests/test_surface_liquid_network.py tests/test_surface_gas_equipment.py
python scripts/run_rotating_drive.py configs/surface_rotating_drive.json --output results/rotating_drive_20261102/full.json
python scripts/run_rotating_drive.py configs/surface_rotating_drive.json --stop-after 1 --output results/rotating_drive_20261102/partial.json
python scripts/run_rotating_drive.py configs/surface_rotating_drive.json --checkpoint results/rotating_drive_20261102/partial.json --output results/rotating_drive_20261102/resumed.json
cmp results/rotating_drive_20261102/full.json results/rotating_drive_20261102/resumed.json
```

Численные артефакты, tests.log, docs_build.log и manifest.json находятся
в `results/rotating_drive_20261102/` и не включаются в git.
Релевантный регресс-набор: **106 passed**, 2.13 s.
Непрерывный запуск и restart дают побайтно одинаковые JSON.
Ruff, git diff --check и строгая сборка MkDocs проходят.

## Что этот блок не закрывает

Нагрузка постоянна внутри каждого интервала. Совместное нелинейное решение
вала и гидравлики, PI/PID, рабочие карты компрессора/помпаж, электромагнитная
динамика и тепловая модель двигателя, свободное обратное вращение,
распределение потерь по флюиду/окружению, связь с FIM и GPU остаются
следующими задачами. Нельзя объявлять этот отдельный блок готовой моделью
насосной/компрессорной станции или всего промысла.
