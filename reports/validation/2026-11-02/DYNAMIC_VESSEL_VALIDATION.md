# Динамический сосуд PR-смеси: проверка 2026-11-02

Добавлены неизменяемые запасы компонентов/внутренней энергии, совместное
неявное решение запасов, P/T и постоянного объёма, фазовый/смешанный отбор,
подачи и тепло, ограничения давления/объёмной доли жидкости, дробление шага,
точный отчётный интервал, расписание и атомарный JSON-перезапуск.
Руководство: [динамический сосуд](../../../docs/DYNAMIC_VESSEL.md).

## Уравнения и область

Жёсткий perfectly mixed контрольный объём. Внутри PT PR/VLE с численной TPD;
на каждом шаге одновременно закрываются компонентные балансы, внутренняя
энергия с энтальпийными потоками и объём. Backward Euler первого порядка,
логарифмические положительные запасы/P, температурная область компонентов.
Сами невязки проверяются независимо от флага остановки нелинейного решателя.

Минимальные запасы не подменяются нулями. Отсутствующий фазовый порт не
заменяется bulk. Объёмная доля жидкости определена только при разрешённых
жидкости/паре; геометрическая высота уровня не рассчитывается. При отказе
на минимальном шаге исходное состояние остаётся прежним, интервал не
считается частично пройденным. Ошибка не превращается в сокращение подачи.

## Проверки

Общий CPU-набор: 374 passed, 23 skipped, 140.35 s.
Промежуточный целевой набор: 10 passed, затем добавлены ещё две проверки
области/команд; они включены в общий набор. Наборы пересекаются.

Независимые пределы: закрытый нагрев через Cv, заполнение с энтальпией
входа/работой потока, адиабатическое опустошение идеального газа.
При максимальном шаге 1/0.5/0.25 s ошибки температуры опустошения около
0.0548851/0.0276061/0.0138390 K — ожидаемый первый порядок по времени.
Эти отличия включают малую разницу между PR при низком давлении и идеальным
газом; это не ошибка EOS относительно эксперимента.

Двухфазный отбор проверен по изменению состава запаса, энергии и фазовому
объёму. Также проверены неизолированная подача, границы уровня/давления,
неверное направление тепла, опустошение/бюджет подшагов, дробление и полный
интервал, несовместимое состояние, checksum и точное JSON-продолжение.

## Сквозной пример

`configs/surface_dynamic_vessel.json`: V=0.1 m³, исходные 3 MPa/220 K,
метан–этан 50/50 молярно. Отбор пара, затем нагрев 10 W, затем отбор обеих
фаз. Всего 1.6 s и восемь принятых подшагов. Это короткий smoke-прогон
физической связности/сохранения, не проверка длительной работы промышленного аппарата.

Конечные P≈2.9988019 MPa, T≈219.988519 K. Прямой CLI и продолжение после
первого периода совпадают целиком: физические запасы, энергия, P/T, время,
интегралы потоков, принятые шаги и checksum. Численные остатки и SHA256:
`results/dynamic_vessel_20261102/validation.json`; отдельно `time_refinement.json`.
Строгая сборка MkDocs, Ruff и git diff --check проходят.

## Воспроизведение

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -m pytest -q tests/test_surface_dynamic_vessel.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_dynamic_vessel.py configs/surface_dynamic_vessel.json --output /tmp/vessel.json --stop-after 1
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_dynamic_vessel.py configs/surface_dynamic_vessel.json --checkpoint /tmp/vessel.json --output /tmp/vessel.json
```

## Оставшиеся границы

CPU reference с демонстрационными постоянными Cp/kij. Локальное продолжение
состояния, не глобальный сертификат UV-равновесия. Нет водной фазы, уноса,
проскальзывания, двух температур фаз, карты/геометрии сепаратора, стенки/UA,
автоматического закрытия клапанов по событию, динамической сети аппаратов,
теплового FIM или GPU-ядра. Расходы заданы, гидравлика арматуры не решается.
Norne и пластовый решатель этим модулем не менялись.
