# Управляемые сопротивления и регулирование в black-oil сети

Расширение от 31 октября 2026. Один набор PVT, изотермическое равновесие Rs,
однородная смесь с равными скоростями фаз; остальные ограничения дерева сохранены.

## Физическое замыкание

У ветви `ProductionPipe` появились `loss_coefficient` (K >= 0, по умолчанию 0)
и `valve_opening` (0 < a <= 1, по умолчанию 1). Эффективное дополнительное
сопротивление равно K/a². Оно **равномерно распределено по длине ветви**,
а не приложено в одной точке. Это управляемое сопротивление в однородном
приближении; его нельзя выдавать за калиброванную модель реального штуцера.

В существующем уравнении импульса при массовом потоке на единицу площади G
и удельном объёме смеси v(p,m) градиент диссипативных потерь задаётся как

```
drag = (f / D + K / (a² L)) G² v / 2
-dp/dx = (drag + g dz/dx / v) / (1 + G² dv/dp)
```

Плотность, вязкость и фазовое состояние меняются вдоль ветви. Интеграл
разбивается на узлах PVT и подвижном давлении насыщения. То же сопротивление
входит в механический баланс и его диссипацию. Проверяется докритическая
ветвь уравнения импульса; недопустимый режим не заменяется произвольным расходом.
Проверка постоянной воды воспроизводит аналитическое добавочное падение
давления K G²/(2 rho) и производную по K.

Полностью закрытая ветвь пока отклоняется: без статического распределения фаз
нельзя корректно рассчитать её многофазную гидростатику. Открытие меняет только
сопротивление; компонентные массы не меняются.

## Производные и FIM

AD интеграла даёт производные давления по трём компонентным массовым расходам,
давлению принимающего узла и K. Далее используется d(K/a²)/da = -2K/a³.
Дерево переносит производные по всем источникам и регулируемым ветвям.

`BlackOilPressureControl` регулирует давление свободного узла открытием одной
ветви ниже него по потоку. Используются ограниченный Newton и бисекция.
При достижении уставки из p_control(m,a) = target следует

```
da/dm = -(dp_control/dm) / (dp_control/da)
dp_node/dm = partial_p_node/partial_m + (dp_node/da) da/dm
```

Та же поправка применяется к производным по принимающему давлению и другим
ручным открытиям. На пределе открытия используются производные фиксированного
оборудования, а отчёт содержит фактическое отклонение от уставки. Истощение
бюджета или сингулярный тангент — численный отказ, а не успешный режим.
Крайние открытия заданного диапазона должны быть допустимы для PVT/импульса;
нарушение области на конце диапазона не маскируется автоматическим расширением PVT.
Полные производные входят в B/D и оператор Шура существующей black-oil FIM-связи.

## Использование

```bash
python scripts/run_fim_blackoil_surface.py configs/fim_blackoil_surface_active.json --days 5 --device cpu --output /tmp/active.json
python scripts/run_fim_blackoil_surface.py configs/fim_blackoil_surface_regulated.json --days 5 --device cuda --network-backend torch_device --output /tmp/regulated_cuda.json
python scripts/run_surface_schedule.py configs/surface_gathering_active.json configs/surface_gathering_active_schedule.json --gathering --output /tmp/gathering.json
```

В FIM спецификация `physical_surface_network` принимает `controls` с картой
`valve_openings` и `pressure_control` с параметрами `valve`, `node`,
`target_pressure_pa`, `min_opening`, `max_opening`, `pressure_tolerance_pa`,
`max_evaluations`. Регулятор и ручная команда на одну ветвь конфликтуют.
Изменение через `set_surface_controls` атомарно; смена граничного давления
сохраняет K и открытия. `set_surface_pressure_control(None)` отключает регулятор.

В конфигурации площадки сбора `pressure_control` задаётся рядом с `gathering`.
Периоды расписания принимают `gathering_valve_openings` и
`gathering_target_pressure_pa`; команды сохраняются до следующего изменения,
включая остановку и перезапуск. Неизвестные команды отклоняются даже при останове.
Уставка и реализация регулятора входят в отпечаток checkpoint.

## Границы

Это не многофазный насос и не специализированная корреляция критического
истечения через штуцер. Перенос однофазных характеристик насоса на смесь с газом
без отдельной модели не выполнен. Не добавлены проскальзывание, удержание фаз,
нулевые/обратные расходы, нисходящие ветви, динамика аппаратов и тепловой расчёт.
Ограничения black-oil FIM по положительной добыче и перфорациям на отметке BHP
сохраняются. CUDA-backend вычисляет PVT/квадратуры/AD на устройстве, но дерево,
поиск давления и регулирование пока координируются CPU.

Артефакты проверки: `results/blackoil_active_20261031/`.

## Результаты проверок

Общий быстрый набор: **454 passed, 93 skipped, 12 slow deselected**.
Проверены аналитический водяной предел сопротивления, механический баланс,
производные по компонентам, принимающему давлению и ручным открытиям,
полные B/D FIM для насыщенной и недонасыщенной нефти, режимы уставки и
обоих пределов открытия, откат и pickle/JSON-продолжение.

В связанном примере три ячейки и две скважины рассчитываются пять суток
при давлении приёмника 0.8/1.0/1.2 МПа и уставке коллектора 2.18 МПа.
При 0.8 МПа регулятор проходит от минимального открытия к уставке,
при 1.0 МПа удерживает уставку, при 1.2 МПа остаётся на максимальном открытии.
При ограничении уставка не подменяет фактическое давление.

На CPU reference и RTX 3090 Ti с сетью `torch_device` последовательности
режимов совпали, полевые CUDA-графы сохранились. Максимальная разница давления
0.002613 Па, водонасыщенности 8.49e-11, газонасыщенности 4.27e-10.
Максимальная абсолютная ошибка баланса одного компонента за пять суток
0.002055 кг, относительная к отобранной массе компонента — 4.311e-8.
Это малый связанный контрольный пример, а не новая сверка Norne/Eclipse.

Расписание площадки с ручным сопротивлением ветви, сменой уставки, остановкой
и запуском точно воспроизвело конечный checkpoint и накопления после
сериализации в JSON. Компонентный остаток площадки в этом примере равен нулю.
Численные результаты и SHA256 исходников записаны в `validation.json`,
команды воспроизведения — в `reproduce.sh` каталога результатов.

Отдельно реализован ограниченный локальный **жидкостный** клапан в списке
`valves`; он не заменяет описанное распределённое K. Газожидкостное
критическое истечение по-прежнему не реализовано.
См. [физическую область локального клапана](BLACKOIL_LOCAL_VALVE.md).
