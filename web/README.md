# Сайт oil-simulator

Статический сайт с собственным оформлением. Для размещения в подразделе сайта достаточно скопировать **всё содержимое `web/`**, сохранив подкаталоги `assets/`, `fonts/` и `data/`. Сборка и серверная часть не нужны; пути относительные.

- `index.html` — проект, устройство решателя, проверки и запуск.
- `norne.html` — полный строгий Norne, текущие результаты, исправления, поля пласта и ограничения.
- `gaslift.html` — отдельная повторная проверка GASLIFT-04 до 213 суток.
- `data/norne-results.json` — показатели, критерии, баланс, перезапуск и SHA-256 исходников/данных проверенного прогона.
- `data/norne-field.csv`, `data/norne-wells.csv` — ряды месторождения и накопленные объёмы всех скважин.
- `assets/norne-numbers.json`, `assets/gaslift-numbers.json` — числа и метрики, использованные на страницах.

## Проверенные данные

Norne: прогон `norne_strict_resv_stream_3090_20261029`, 3312 суток, CNV=1e-3, MB=1e-7 без ослабления. 1000,8 с на RTX 3090, 654 принятых подшага и 32 отказа с дроблением. Ошибки итоговой накопленной добычи против Eclipse: нефть −0,064437%, вода +0,158433%, газ −0,099378%. Все изображения Norne относятся к этому прогону; первый объёмный кадр — конец первых 8 суток, не исходное состояние на нулевой дате.

Газлифт пересчитан отдельно 29 октября 2026: 213 суток на CPU. Нефть +0,745518% и газ на лифт −4,356972% относительно OPM. Нормированные ошибки на отчётных датах, знаковые ошибки накопленных объёмов и времена разных версий не подменяют друг друга.

## Обновление графиков и данных

Из корня репозитория, при наличии результатов проверенного прогона и открытого набора Norne:

```bash
NORNE_DIR=opm-tests/norne NORNE_OUT=results/norne python scripts/norne_figures.py
NORNE_DIR=opm-tests/norne NORNE_OUT=results/norne python scripts/export_web_results.py
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/gaslift_figures.py
```

`norne_figures.py` строит все графики и шесть объёмных видов на CPU через Matplotlib, без OpenGL и GPU. Экспорт проверочных данных требует полного аудированного набора файлов, перечисленного в заголовке `export_web_results.py`; он отказывает для незавершённого или ослабленного прогона. HTML содержит готовые значения и должен обновляться согласованно с JSON/CSV. Данные видны без JavaScript; JavaScript нужен только для переключателей изображений и навигации.

Локальный просмотр:

```bash
python -m http.server 8000 --directory web
```

Публикация и коммиты не выполнялись автоматически.
