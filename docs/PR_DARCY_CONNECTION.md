# Квазистационарные Darcy-соединения PR-сосудов

`PRDarcyConnection` — явно выбираемая сокращённая модель горизонтальной
адиабатической линии между двумя конечными перемешанными сосудами.
Она сохраняет компонентные и энергетические запасы сосудов в общем PR-
Ньютоне. Собственного пространственного запаса, инерции и акустических
волн у соединения нет. Подробные `pipe_cell` остаются отдельной моделью.

## Область применимости

- Оба конца — однофазные конечные `vessel` на одинаковой отметке.
- По умолчанию перепад не выше 3% меньшего давления; разрешённый максимум — 5%.
- Число Маха не выше 0,1; скорость дополнительно ограничена паспортом модели.
- Вязкость задана явно, шероховатость и размеры берутся из описания линии.
- Теплообмен линии, пространственное фазовое разделение, фазовые запасы
  и разрешение пуска внутри линии не моделируются.

Используется существующий `darcy_pressure_loss`: точный ламинарный предел
Пуазейля, корреляция Haaland в турбулентном режиме и прежняя гладкая
инженерная интерполяция в переходной области. Коэффициенты не объявляются
экспериментально откалиброванными.

Полный перепад дополнен `K rho v |v| / 2`. По умолчанию
`local_loss_coefficient=1`: идеальный вход и потеря выходного скоростного
напора при перемешивании струи в неподвижном приёмном сосуде, в той же
plug-flow конвенции кинетической энергии, что и подробная PR-труба.
Источник для несжимаемого предела —
[ODOT Hydraulics Manual, §5.2, стр. 13-G-5](https://www.oregon.gov/odot/hydraulics/Docs_Hydraulics_Manual/Hydraulics-13-G.pdf#page=5).
Перенос этого замыкания на PR-газ является явно ограниченной
низкомаховской аппроксимацией, а не газовой экспериментальной калибровкой.
Другие местные потери задаются суммарным коэффициентом; `K=0` оставляет
только распределённое трение для отдельной проверки Пуазейля.

В ламинарном режиме используется точный устойчивый обратный закон
`v = 2 dp / (a + sqrt(a² + 2 K rho |dp|))`, где `a = 32 mu L / D²`.
Режим проверяется по Reynolds полученного решения и пределу скорости;
производные по перепаду и плотности вычисляются непосредственно через
эту формулу. Это исключает 44 итерации поиска, сохраняя тот же закон потерь.
Для переходного/турбулентного режима и общего `vmap` сохраняется
ограниченное устройственное решение той же функции трения.
Начальный корень не дифференцируется через сравнения; последующая
неявная поправка даёт первую производную по перепаду и плотности для
общего AD-Якобиана. Значения и производные проверены независимо, включая
реверс, нуль и переходный Reynolds. Новых глобальных плотных неизвестных
или SciPy-решения в производственном пути нет.

## Перенос и приёмка

Донор выбирается по направлению перепада. Один и тот же поток компонентов
и полной энтальпии вычитается из донора и добавляется приёмнику. В него
включён общий гравитационный отсчёт энергии. Трение не удаляет энергию
из системы: линия адиабатическая, приёмный сосуд переуравновешивает
поступившие компоненты и энергию своим UV-решением.

После решения проверяется PH-состояние доставленного потока при давлении
приёмника. Появление второй фазы отвергает эту сокращённую ветвь.
Нулевой поток не создаёт PH-потока и не вызывает лишнего flash.
Изоляция и запрет обратного течения дают нулевой перенос.

Контроль времени и уточнения патрубков учитывает также разность Darcy-
скоростей coarse/fine в прежних единицах
`transport.velocity_tolerance_m_s`. Для изолированной линии этот вклад
отключён по фактическим командам. Удаление инерционной неизвестной не
отключает контроль точности расхода.

Поддержаны общий sparse-Якобиан с перекрёстными зависимостями обоих
сосудов, открытые материальные границы и существующие гравитационные
колонны/контроллеры. Внешняя материальная книга учитывает только внешние
потоки; внутреннее соединение не является источником компонентов или энергии.

## Конфигурация и checkpoint

В `pr_gravity_transport_graph_v1` добавляется необязательный список:

```json
"darcy_connections": [{
  "name": "recycle",
  "source": "gas_export",
  "target": "gas_suction",
  "length_m": 0.2,
  "diameter_m": 0.001,
  "dynamic_viscosity_pa_s": 0.0001,
  "roughness_m": 0.00001,
  "local_loss_coefficient": 1.0,
  "maximum_pressure_drop_fraction": 0.03,
  "maximum_mach_number": 0.1,
  "allow_reverse": true,
  "open": true
}]
```

Если список пуст, он не добавляется в сериализацию: прежние идентификаторы
моделей сохраняются. Состояния линии в checkpoint нет; её параметры входят
в идентичность графа. Потоки и температура доставки записываются в
`material.darcy_connections` либо в транспортное `coupling` для графа без колонн.

`scripts/reduce_pr_recycle.py` создаёт отдельный запрос из checkpoint для
одной подходящей трубы. Её N/E и объём переносятся в приёмный сосуд,
после чего UV-flash восстанавливает состояние. Исходный запрос не меняется.
Частичная изоляция трубы с запертым запасом не имеет такого эквивалента
и отвергается. Полное устранение собственной геометрии линии — изменение
модели, даже при сохранении начальных суммарных N/E/V.

## Исправление подробного эталона

В существующем режиме `reservoir_ports=stagnation_single_phase` исправлена
скорость входящего в сосуд потока: порт сохраняет отрицательную скорость
контакта вместо её обнуления. Перемешивание происходит в конечном сосуде;
обнуление скорости прямо на границе создавало искусственное акустическое
сопротивление. Независимый проверяющий и тесты направлений обновлены.
Режим `riemann` и его выбор в прежних конфигурациях автоматически не меняются.

Сравнение сокращённого и подробного решений проводится после начального
инерционного слоя с пространственным уточнением подробной трубы.
Совпадение мгновенного пускового расхода не заявляется.
[Измерения и границы](../benchmarks/reports/surface_pr_darcy_reduction/README.md).

## Явный инженерный вариант сети

`surface.pr_model_reduction.reduce_cells(config, names)` переводит выбранные
горизонтальные однофазные трубы между конечными перемешанными сосудами в
существующие `PRDarcyConnection`. Выбор явный, порядок обработки детерминирован;
при неподдерживаемой трубе весь запрос отклоняется без изменения исходного.
Динамические сосуды, сепараторы, оборудование, управление и остальные трубы
сохраняются. Это сокращённая физическая модель, не просто другой интегратор.

```bash
PYTHONPATH=src python scripts/reduce_pr_recycle.py \
  configs/surface_pr_integrated_facility.json \
  --cells gas_recycle_0 --output /tmp/facility-engineering.json
```

Можно перечислить несколько подходящих труб. Объёмы, компоненты и полная
энергия переносятся в конечные приёмники с UV-flash; требуется начальное
состояние покоя. Однофазность и пределы Mach/перепада проверяются существующей
моделью соединения в процессе расчёта. Переход к многофазности требует другой
модели, а не отключения проверок.

Запрещается потеря явного нагрева, переменного сопротивления, управляющих
каналов, защит, боковых связей, стенок, популяций капель и геометрии уровней.
Различающиеся проходные сечения и частичная изоляция с запертым запасом также
отклоняются. Старые функции `reduce_cell` и `merge_pipe_stocks` доступны через
прежний скрипт для совместимости.

В карте преобразования сохраняются перенесённые запасы, доля добавленного
объёма приёмника и оценка времени ламинарной инерционной релаксации
`rho*D²/(32*mu)`. Она выведена из линейного вязкого члена уравнения импульса
при фиксированных плотности и перепаде; это не критерий допустимости
сокращения и не назначаемый шаг интегратора. Для текущей трубки рецикла оценка
около `2.9 ms`: сравнение мгновенного пускового расхода на `1 ms` заведомо
не заменяет проверку после установления режима. Для инженерного применения
нужны отдельные бюджеты на давления, расходы, составы, запасы и энергию на
интересующем интервале. Подробная модель остаётся эталоном для переходов,
которые сокращённая модель по определению не разрешает.

### Согласование границы при сравнении с подробной трубой

Нельзя проверять только совпадение давлений сосудов. На смеси интегрального
стенда через `1 ms` сокращённая линия дала `25.104 m/s`, тогда как подробная
труба с прежними `riemann`-портами — `0.266 m/s`, при максимальной разнице
давлений общих узлов всего `0.2501 Pa`. Парный расчёт изолированного участка
с одинаковыми начальными запасами подтвердил влияние границы: `riemann` —
`0.265802 m/s`, `stagnation_single_phase` — `9.071310 m/s`; оба независимо
проверены. Разницу `9.07` против стационарных `25.1` нельзя объявлять ошибкой
интегратора: этот момент находится внутри начального инерционного перехода.
Само наличие разных решений не доказывает универсальную корректность одного
типа границы для всех геометрий и фазовых режимов.

Для сравнения с идеальным входом и перемешанным приёмником можно явно выбрать
существующую стагнационную модель только в выделенном подграфе:

```bash
PYTHONPATH=src python scripts/enable_pr_subcycling.py \
  configs/surface_pr_integrated_facility.json --pipes gas_recycle_0 \
  --fast-reservoir-ports stagnation_single_phase \
  --output /tmp/facility-detailed-stagnation.json
```

Это явное изменение физической границы, а не автоматическая оптимизация.
Без `--fast-reservoir-ports` сохраняются прежние порты и идентификаторы модели.
Выбор входит в идентичность checkpoint и независимый аудит; порты остальной
установки сохраняются. Стационарное сокращение следует проверять после
установления режима и на согласованных граничных предположениях.
