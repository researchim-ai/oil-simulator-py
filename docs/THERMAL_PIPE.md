# Полная энергия распределённой однородной трубы

`ThermalHomogeneousPipe` решает четыре консервативные переменные по участкам:
массы несмешивающихся жидкости и свободного газа, общий импульс и полную энергию.
Это отдельный горизонтальный CPU-вариант с общей скоростью и температурой фаз.
Жидкость несжимаема, газ идеален, Cv обеих фаз постоянны и задаются явно.
Нет фазового обмена, растворения или автоматического переноса black-oil состава.

## Уравнения и калорика

В каждой ячейке на единицу объёма трубы:

```
Ul = rho_l (1−alpha)
Ug = rho_g alpha
rho = Ul + Ug
J = rho v
C = Ul Cv_l + Ug Cv_g
E = C T + J²/(2 rho)
P = Ug R T / alpha
```

E содержит внутреннюю и кинетическую энергии; это не только `m Cp T`.
При восстановлении состояния кинетическая часть вычитается до определения T.
Газовая Cp равна Cv_g+R; для несжимаемой жидкости h_l=Cv_l T+P/rho_l.
Энергетические нули в этой модели соответствуют u=Cv T. Энтропия в отчёте
использует Tref=1 K и rho_g_ref=1 kg/m³; физический смысл имеют разности.
Эти соглашения не совпадают автоматически с PR/PVT энергетическими нулями.

Консервативные потоки:

```
Fl = Ul v
Fg = Ug v
FJ = J v + P
FE = (E + P) v
```

Последняя строка включает работу давления. Вставка внутренней энергии
вместо полной или пропуск P v нарушили бы перенос энергии на границах.

Стеночное трение входит в источник импульса `−fD rho v |v|/(2D)`.
Для неподвижной адиабатической стенки оно не удаляет полную энергию флюида:
потеря кинетической энергии превращается во внутреннюю. Поэтому отдельного
отрицательного «трения» в источнике полной энергии нет.
Внешний теплообмен задаётся `q_vol=H (Tamb−T)/A`, где H в W/(m·K), A — площадь
проходного сечения. Это заданный резервуар температуры, без запаса металла.

## Метод и ограничения шага

По умолчанию используется [энтропийный поток](THERMAL_NUMERICS.md),
legacy Rusanov выбирается явно. Время интегрируется обратным Эйлером.
Скорость волны аналитическая:

```
gamma_eff = 1 + Ug R/C
c² = gamma_eff P/(rho alpha)
wave_speed = |v| + c
```

Она дополнительно проверяется спектром конечных разностей якобиана полного
четырёхкомпонентного потока. Консервативная схема сохраняет энергии и массы
при смешении численными потоками, но имеет диффузию первого порядка.
Проверки по сетке/времени обязательны; аналитическая скорость волн не делает
всю схему точным решением PDE.

Неизвестные p, alpha, J, T находятся в одном нелинейном решении с разреженной
блочной структурой. Области давления/температуры/наличия обеих фаз,
изменения запасов и температуры контролируются. Отказанная проба не меняет
входные данные, шаг дробится. Дополнительно к масштабированному балансу
проверяется энергетическая транзакция по суммарной энергии через границы
и внешнему теплу: большой запас E не скрывает ошибку малого потока.
Это арифметическая проверка баланса, не физический допуск на точность модели.
В энтропийном режиме дополнительно контролируется дискретное производство
энтропии с численным граничным потоком и теплообменом с резервуаром.
Для legacy Rusanov такой приёмочный критерий не заявляется.

## Конфигурация и команды

В `scripts/run_transient_pipe.py` выбор задаётся явно:

```json
{
  "model": "thermal_homogeneous",
  "pipe": {
    "length_m": 10,
    "diameter_m": 0.1,
    "cells": 8,
    "liquid_density_kg_m3": 850,
    "gas_constant_j_kg_k": 500,
    "temperature_k": 300,
    "distribution_parameter": 1,
    "drift_velocity_m_s": 0,
    "darcy_factor": 0.02,
    "liquid_cv_j_kg_k": 2000,
    "gas_cv_j_kg_k": 1500,
    "heat_transfer_w_m_k": 100,
    "ambient_temperature_k": 340
  }
}
```

Полный файл с `initial`, `periods`, `stepper`: `configs/surface_thermal_pipe.json`.
Числа демонстрационные, не паспортные свойства нефти или оборудования.
Конструкторный `temperature_k` задаёт начальную температуру по умолчанию,
а не фиксирует поле температуры. В `initial` разрешён собственный temperature_k.
Для каждой открытой границы температура обязательна вместе с p, alpha и v;
изотермический формат границы не принимается с молчаливым дополнением.

Ненулевой дрейф, C0≠1 и наклон трубы отклоняются явно. Энергетическое замыкание
для проскальзывания и согласованная гравитационная энергия — отдельная работа;
режим не переводится автоматически на однородный или горизонтальный.
Обе фазы должны присутствовать, T лежать в объявленной области.
По умолчанию min/max T=150/700 K, максимум изменения T=5 K за подшаг.

```bash
python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --output results/thermal_pipe.json
python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --stop-after 1 --output results/thermal_partial.json
python scripts/run_transient_pipe.py configs/surface_thermal_pipe.json --checkpoint results/thermal_partial.json --output results/thermal_resumed.json
python scripts/check_pipe_acoustics.py --thermal --output results/thermal_acoustics.json
python scripts/benchmark_transient_pipe.py --thermal --cells 4 16 64 --output results/thermal_benchmark.json
```

## Состояние и баланс при продолжении

`ThermalPipeInventory` хранит `total_energy_j` по ячейкам наряду с фазовыми
массами, импульсом и часами. Замена на изотермический PipeInventory не допускается.
Векторы `left_boundary_transfer` и `right_boundary_transfer` имеют четыре
элемента `[liquid_kg, gas_kg, momentum_kg_m_s, total_energy_j]`.
`heat_j` — внешнее тепло подшага, `energy_residual_j` — остаток баланса.
Закрытая граница имеет нулевые потоки массы и энергии; импульс получает
реакцию неподвижной стенки. После закрытия сохраняется запас трубы.

`run_pipe_schedule` сохраняет тип состояния и проверяет накопленную энергию
по граничным переносам и внешнему теплу. Отпечаток учитывает тип модели,
калорику и реализацию. Старые checkpoint другой реализации требуют
повторного запуска; они не принимаются как энергетически совместимые.

## Что проверено и что открыто

Проверены независимые формулы равномерного нагрева/охлаждения, работа давления,
адиабатическое торможение без потери полной энергии, открытые балансы,
продолжение после остановки и обратного перепада. Стоячая малая адиабатическая
волна даёт независимый тест сходимости давления и температуры.
Эти проверки не являются экспериментальной калибровкой.

Открыты: тепловое проскальзывание, реальные PVT/PR-свойства и фазовый обмен,
нефтяной и водный компоненты отдельно, наклон/потенциальная энергия,
конечная теплоёмкость стенки трубы, радиальная теплопроводность, связанные
узлы PR-сети, пластовый интерфейс по компонентам/энтальпии, GPU и промысловый
масштаб. Эта модель не закрывает весь тепловой контур месторождения.

## Нелинейное ударное сжатие

`scripts/check_pipe_shock.py` сравнивает встречные потоки с независимыми
условиями Ренкина–Гюгонио. Старый Rusanov давал локальную ошибку T около
0.18 K на N=512. [Энтропийный поток](THERMAL_NUMERICS.md) дополнен
датчиком диссипации, фиксированным на каждом подшаге. Исходный локальный
критерий 0.02 K и проверки полной энергии/энтропии сохранены. Дополнительные
амплитуды и доли газа проверяются отдельной матрицей; результат одной
постановки не переносится автоматически на остальные сетки и режимы.

Параметры по умолчанию:
`numerical_flux: entropy_stable`, `thermal_entropy_dissipation: 1.4`,
`adaptive_entropy_dissipation: true`.
Для воспроизведения постоянного энтропийного потока задайте
`adaptive_entropy_dissipation: false`, `thermal_entropy_dissipation: 0.75`;
для старой схемы — `numerical_flux: rusanov`.
