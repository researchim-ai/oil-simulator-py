# Динамический компонентный PR-сепаратор

`CompositionalSeparator` соединяет равновесную PR-термодинамику с конечными
запасами компонентов, внутренней энергией, стенкой и отборами. Неизвестные
одного неявного шага: количества каждого активного компонента в каждой
фазе, давление, температура и, при наличии стенки, её температура.
Компонентные балансы, равенство фугитивностей, постоянство объёма и
энергетические балансы решаются совместно в Torch float64 на CPU/CUDA.
Внутри Ньютона нет вложенного равновесного flash. Якобиан вычисляет Torch.

Это самостоятельная **нулемерная равновесная модель** с общими P/T.
Необязательная [геометрия слоёв и фазовых патрубков](PR_PHASE_GEOMETRY.md)
добавляет кинематический отбор и уровневую обратную связь при `g=0`.
Она дополняет, а не заменяет геометрический сепаратор несмешивающихся
фаз из [THREE_PHASE_SEPARATOR.md](THREE_PHASE_SEPARATOR.md).

## Балансы и фазовые переходы

Каждый выход переносит свой компонентный состав и молярную энтальпию
из соответствующих фаз. Полная энергия потока включает заданную общую
геодезическую отметку. Запас хранит внутреннюю энергию; работа потока
входит через энтальпию. При наличии стенки её запас и теплообмен решаются
в той же системе; наружный теплообмен учитывается в общем балансе.

После решения выполняется отдельная проверка равновесия и устойчивости.
Смена числа фаз запускает решение другой фазовой ветви. Отсутствующие
компоненты сохраняют точный ноль до поступления с питанием. При переходе
чистого компонента в область насыщения UV-предиктор по запасам и энергии
даёт начальную фазовую ветвь: PT сам по себе не определяет качество.
Предиктор не подменяет неявные балансы принятого шага.

Контролируются локальные и итоговые компонентные/энергетические невязки,
объём и производство энтропии. Неудачное решение дробит шаг, не публикуя
частично изменённое входное состояние. Неопределённая устойчивость и
выход из области свойств считаются отказом. Численный мультистарт TPD
не является доказательством глобального минимума для любой смеси.

## Отборы и управление

`EquilibriumOutlet` — **эмпирическая линейная проводимость**, а не модель
реального сопла. Без геометрического патрубка для выбранной фазы:

`Vdot = conductance × opening × max(P − Pback, 0) × phase_volume / vessel_volume`.

При заданных `geometry`, `height_m` и `diameter_m` доля глобального
фазового объёма заменяется долей площади отверстия, занятой фазой.
Вместо обратной связи по давлению можно выбрать `level_control`.
Формулы и область применения описаны в руководстве геометрии выше.

Режимы выбора: `bulk`, `densest`, `lightest`, `component_rich`.
Последний выбирает фазу с наибольшей долей указанного компонента, только
если достигнут `minimum_mole_fraction`. Это критерий идентификации фазы,
не модель межфазного уноса. На границе выбора закон негладкий.
При отсутствии положительного перепада выход закрыт; обратная подача
с граничным составом через этот объект не реализована.

Можно задать ограниченный пропорциональный закон открытия от давления
(`pressure_setpoint_pa`, `opening_gain_per_pa`, `opening_bias`) либо
передать открытие периода явно. Это не PID с динамикой привода.
`maximum_pressure_drop_fraction` ограничивает объявленную область
применимости проводимости; значение по умолчанию 0.05. Само ограничение
не означает экспериментальной калибровки коэффициента.

## Временная точность

Используется backward Euler первого порядка. При `temporal_error_control`
полный шаг сравнивается с двумя половинными, принимаются половинные.
Контроль включает количества компонентов, P, T и температуру стенки.
Масштаб давления: `1 Pa + relative_tolerance × max(abs(P))`.
Контроль давления нужен для слабосжимаемой жидкости: малая ошибка запаса
сама по себе ещё не обеспечивает точного давления. Ограничиваются также
изменение запасов и температур за принятый подшаг. Это оценка локальной
ошибки, не гарантия заданной глобальной ошибки на произвольном интервале.

## Запуск и перезапуск

Пример: `configs/surface_compositional_separator.json`. Он демонстрирует
три PR-фазы, селективные отборы, питание, нагрев, стенку и закрытие выходов.
Вода и углеводороды здесь — иллюстративная PR-смесь без лабораторной
калибровки; вывод о точности реальной подготовки нефти из неё не следует.

```bash
python scripts/run_compositional_separator.py configs/surface_compositional_separator.json --device cpu --output /tmp/separator.json
python scripts/run_compositional_separator.py configs/surface_compositional_separator.json --device cuda --stop-after 2 --output /tmp/prefix.json
python scripts/run_compositional_separator.py configs/surface_compositional_separator.json --device cuda --checkpoint /tmp/prefix.json --output /tmp/resumed.json
```

Для чистого замера выбирайте свободную GPU через `CUDA_VISIBLE_DEVICES`.
`cuda` не подменяется CPU. Небольшой последовательный flash на GPU может
быть медленнее CPU: CPU управляет фазовыми ветвями, адаптацией и приёмкой;
CUDA Graph и отсутствие синхронизаций для этого блока не заявляются.

Расписание связано с моделью, периодами, начальными запасами, устройством,
runtime и хешами физических исходников. Checksum дополняется физическим
повтором сохранённого префикса; изменение исходников запрещает продолжение
старого checkpoint. Выход публикуется атомарно после успешного расчёта.
Независимый `check_compositional_separator.py` восстанавливает EOS,
проводимости и балансы из сохранённых CPU/CUDA журналов без вызова
нелинейного решателя сосуда.

## Что остаётся

Сеть таких сосудов реализована отдельно:
[COMPOSITIONAL_NETWORK.md](COMPOSITIONAL_NETWORK.md). Она совместно
решает их состояния и upwind-потоки, сохраняя общие компоненты и энергию.

Не реализованы в этом классе: распределённая гидростатика и геометрические
высоты патрубков, захват/унос капель, неравновесный массоперенос,
критическое истечение, сеть связанных конечных PR-сосудов, общая
многофазная трубная динамика и неявное энергетическое сопряжение с FIM.
Реальные PVT, вода/соль/ассоциация, карты и коэффициенты оборудования
требуют отдельной характеризации и измерений. Данные пользователя
для такой калибровки отсутствуют. Этот блок не изменяет расчёт Norne.
