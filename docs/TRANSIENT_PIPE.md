# Распределённая двухфазная труба

`DriftFluxPipe` — отдельная CPU-реализация конечных объёмов с запасами жидкости,
свободного газа и импульсом по участкам. Она добавляет переходные процессы,
удержание и разные скорости фаз. Это изотермическая модель замороженных фаз:
жидкость несжимаема, газ идеален, фазового обмена и растворения нет.
Она не заменяет black-oil PVT или PR-flash и пока не связана с пластовым FIM.

## Уравнения

Консервативные переменные на единицу объёма трубы:

```
Ul = rho_l (1 − alpha)
Ug = rho_g alpha
J  = rho_l jl + rho_g jg
rho_g = P/(R T)
jg = alpha (C0 j + Vd)
jl = j − jg
```

Здесь j — суммарная поверхностная объёмная скорость, jg/jl — поверхностные
скорости фаз, alpha — объёмная доля газа. Истинные фазовые скорости:
`vg=jg/alpha`, `vl=jl/(1−alpha)`. Удержание жидкости равно `1−alpha`.
Потоки компонент: `rho_l jl`, `rho_g jg`. Поток импульса:

```
FJ = rho_l jl²/(1−alpha) + rho_g jg²/alpha + P
```

Источники импульса — гравитация и явно заданное стеночное трение:

```
SJ = −rho_mix g Δz/L − fD rho_mix j |j|/(2D)
```

C0, знаковая Vd и коэффициент Darcy fD задаются явно. Их нельзя считать
универсальными корреляциями для всех режимов и направлений потока.
Структура распределённого параметра и дрейфа опирается на
[работу Zuber и Findlay](https://digital.library.unt.edu/ark:/67531/metadc1201432/).
Это источник формы замыкания, не валидация нашей реализации.
При C0=1 и Vd=0 получается однородный предел с одинаковыми скоростями фаз.

## Численный метод и допустимость

Внутренние грани используют локальный Rusanov, неявный шаг — обратный Эйлер.
Для скорости численной диссипации вычисляется спектр локального якобиана
потоков в консервативных переменных, включая проскальзывание. Не вещественный
спектр отклоняется; мнимые части не превращаются молча в скорость волны.
Нелинейный решатель использует разреженную блочную трёхдиагональную структуру.

Давление и alpha ограничены заданной областью; обе фазы обязаны существовать.
Сингулярное преобразование импульса в скорость отклоняется. Ограничение
изменения запасов за подшаг помогает разрешать переходный процесс.
Неудачная проба не изменяет входное состояние, шаг дробится. Проверяются
суммарные массы и баланс импульса с граничными потоками и объёмными силами.
Это не схема точного гидростатического равновесия на наклонной сетке.
Первый порядок и численная диффузия требуют проверки по сетке и времени;
малый остаток нелинейных уравнений не оценивает ошибку дискретизации.

## Границы, остановка и сохранение

Граница `closed` имеет строго нулевые потоки компонентов и отражающую реакцию
стенки в уравнении импульса. Перекрытие не обнуляет запас трубы.
Открытая граница — явно заданное состояние резервуара P, alpha, j;
величины на грани определяет численный поток, а не навязанное масштабирование
добычи. Прямая/обратная подача разрешены по знаку потоков.
Смена знака потока сама по себе не меняет знак Vd: ориентация трубы фиксирована.

Пример `configs/surface_transient_pipe.json`: подача, перекрытие обоих концов,
затем обратный перепад давления. `PipeInventory` хранит массы по участкам
в kg, импульс в kg·m/s, время и отпечаток модели.
`run_pipe_schedule` сохраняет принятые периоды, signed-переносы через границы,
checksum и отпечаток исходников/команд/численных библиотек. При продолжении
проверяются часы и накопленные компонентные/импульсные балансы.

```bash
python scripts/run_transient_pipe.py configs/surface_transient_pipe.json --output results/pipe.json
python scripts/run_transient_pipe.py configs/surface_transient_pipe.json --stop-after 1 --output results/pipe_partial.json
python scripts/run_transient_pipe.py configs/surface_transient_pipe.json --checkpoint results/pipe_partial.json --output results/pipe_resumed.json
python scripts/benchmark_transient_pipe.py --cells 4 16 64 --output results/pipe_benchmark.json
```

Граничные векторы в отчёте имеют порядок `[liquid, free_gas, momentum]`:
первые два элемента в kg, третий в kg·m/s. Положительный перенос направлен
по оси трубы, поэтому изменение запасов равно левому переносу минус правый;
для импульса добавляется `body_impulse_kg_m_s`.

## Калибровка

`surface.calibration.fit_drift_flux(j, vg, sigma)` подбирает C0 и Vd по явно
переданным наблюдениям фазовой и суммарной поверхностной скорости.
Взвешенный ограниченный МНК требует не менее трёх точек, положительных sigma
и идентифицируемой матрицы наблюдений. Возвращаются ошибки, обусловленность,
активные границы и диапазон j; `predict` запрещает экстраполяцию по умолчанию.
Это не подбор PVT и не автоматическое определение режима течения.

В репозитории пока проверено только восстановление заранее известных
коэффициентов и поведение с весами/вырожденными данными. Реальных измерений
пользователь не предоставил; физическая калибровка оборудования не выполнена.

## Что ещё требуется

Отдельный [тепловой однородный вариант](THERMAL_PIPE.md) добавляет полную энергию.
Энергетическое замыкание при проскальзывании, реальные свойства газа, растворение и фазовый обмен,
водная/нефтяная составляющие отдельно, режимные корреляции и их независимые
эталоны, well-balanced обработка гидростатики, сетки промыслового размера,
GPU-ядро и согласованное сопряжение с PR/black-oil сетью остаются открытыми.
Параметры и тесты этого модуля не подтверждают полную промышленную модель трубы.

Независимая проверка пространственно-временного уточнения:
`python scripts/check_pipe_acoustics.py --output results/acoustics.json`.
Малая стоячая акустическая волна сравнивается с линейным решением
в однородном изотермическом пределе без трения. Она не проверяет
реалистичность корреляции проскальзывания.
