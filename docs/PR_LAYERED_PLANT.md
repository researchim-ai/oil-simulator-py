# Общий PR-граф с профильной трубой

Для нескольких профильных ветвей, общих узлов, параллельных путей и колец
доступен [PRProfileGraphNetwork](PR_PROFILE_GRAPH.md). Описанный ниже
`pr_layered_plant_v1` сохраняет совместимый формат одной цепочки.

`PRLayeredPlantNetwork` связывает одну цепочку `PRLayeredTransportNetwork`
с действительными конечными сосудами `PREquilibriumTransportNetwork`.
Компоненты, энергия, импульс, химические трассы и состояния оборудования
решаются в одном Torch-Ньютоне. Последовательной подстановки давлений
и фиктивных буферов между подсистемами нет.

## Физическая область

Профильная цепочка — прямая наклонная труба постоянного диаметра с общей
скоростью и температурой фаз, поперечными равновесными слоями и интегральными
запасами. Формулы потоков, отражения на закрытых торцах, источника тяжести
и эффективного трения: [профильная труба](PR_LAYERED_TRANSPORT.md).
Этот компонент не вводит независимую инерцию слоёв или проскальзывание.

Каждый торец открыт в именованный конечный сосуд либо закрыт (`null`).
Центр диска должен совпадать с отметкой сосуда. Граничный сосуд использует
однородное равновесное состояние; параметр `maximum_head_fraction`
(по умолчанию 0.001, максимум 0.01) ограничивает допустимый поперечный напор.
Открытие в обычную трубную ячейку, боковые патрубки, переменное сечение
и несколько профильных цепочек этим API не поддерживаются.

## Сохранение и решение

На пересечениях фаз торцевого диска вычисляется единственный HLLC-поток.
Потоки компонентов и полной энергии входят в обе подсистемы с разными
знаками. Реакция опоры конечного сосуда учитывается отдельно от импульса
трубы. Потенциальная энергия приводится к общей отметке; глобальный запас
также включает стенки и роторы обычного графа. Контролируются N/E,
локальный импульс и производство энтропии.

Разреженный Якобиан сохраняет структуру обычного графа и добавляет связи
торцевых трасс с соответствующим сосудом. Повтор фазовой топологии ограничен;
неудачная попытка не изменяет исходное состояние. `advance` сравнивает полный
шаг с двумя половинными и проходит заданный интервал с адаптацией.
Реестр активных компонентов профильной цепочки фиксирован: поступление
нового для него компонента отклоняется явно.

`step` принимает открытия соединений, тепло и температуры тепловых источников,
сопротивления, моменты приводов и `profile_heat_w` с
`profile_utility_temperature_k`. Это команды общего шага; наличие каналов
регулирования в отдельном обычном графе не означает автоматическую обвязку
всего профильного API регуляторами.

## Воспроизведение и проверка

```sh
PYTHONPATH=src python scripts/run_pr_layered_plant.py \
  configs/surface_pr_layered_plant.json --output /tmp/layered-plant.json
PYTHONPATH=src python scripts/check_pr_layered_plant.py \
  configs/surface_pr_layered_plant.json /tmp/layered-plant.json
```

JSON содержит `model`, `initial`, `schedule`; restart задаётся через
`initial.state`. Checkpoint сохраняет обе подсистемы, общие часы и ID модели.
Runner фиксирует хеши исходников. Независимый NumPy/SciPy-аудит восстанавливает
профили, торцевые потоки и балансы, затем проверяет обычный граф с этими
внешними обменами. Заданные начальные P/T/состав проверяются по независимым
запасам и общему гравитационному равновесию; для restart требуется точное
совпадение исходного checkpoint. Подмена начальных условий в отчёте не
считается новым подтверждённым расчётом. Функциональные проверки и CPU/CUDA-сопоставление не
заменяют экспериментальную проверку многофазных замыканий и калибровку.
