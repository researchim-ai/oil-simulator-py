# Трубы переменного сечения и вход из резервуара

## Геометрия и уравнения

`PREquilibriumNozzle` компилирует N+1 диаметров граней и N длин в тот же
`PREquilibriumTransportNetwork`, что используется для труб и сосудов.
Объём усечённого конуса равен `pi*L*(dL^2+dL*dR+dR^2)/12`.
Средний диаметр используется для трения, но не подменяет площадь грани.
Соседние грани обязаны совпадать по площади.

В импульс входит сила неподвижной стенки `P*(A_right-A_left)`.
Она точно компенсирует разность сил давления в состоянии покоя с постоянным P.
Неподвижная стенка не совершает работу; источник энергии от изменения
сечения не добавляется. Теплоёмкость и проводимости стенки распределяются
по фактической боковой площади. Компоненты, импульс и U+K+PE решаются
совместно. Это не отдельная стационарная формула расхода.

## Потоки и входное условие

`wave_fan` принимает `fixed_bound` (по умолчанию), `local_single_phase`
(оценки Davis) и `pressure_single_phase` (предиктор давления PVRS).
Для одной фазы используется аналитическая PR-скорость звука при постоянном
составе: `a^2=-v^2/MW*(P_v-T*P_T^2/Cv)`.
Многофазные стыки сохраняют прежний ограниченный поток. Недопустимая
локальная звёздная область явно отмечается `local_fan_fixed_fallback`.
В сверхзвуковой области используется физический наветренный поток.
PVRS с реальным EOS не является универсально подтверждённой оценкой
сильных волн около критической точки или в жидкости.

`reservoir_ports="stagnation_single_phase"` добавляет три неизвестных на
открытый однофазный стык перемешанного сосуда с трубой: P, T и скорость.
Они входят в общий Ньютон и его разреженный Якобиан. При истечении:
`s_port=s_reservoir`, `h_port+MW*u_port^2/2=h_reservoir`, плюс совместимость
скорости с решением Римана. Это устраняет численную потерю полной энтальпии
на входе. При обратном потоке приёмный сосуд задаёт свои статические P/T;
компоненты и энергия поступают из трубы. Направление решается совместно.

Режим ограничен однофазным входом с дозвуковым истечением из резервуара.
Фазовый переход в самом входном следе и сверхзвуковой вход отклоняются;
разрешённое горло должно находиться внутри трубы. К гравитационной апертуре
колонны это условие не применяется. По умолчанию остаётся `riemann`.

## Воспроизводимость

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_pr_equilibrium_transport.py configs/surface_pr_resolved_nozzle.json --output results/pr_resolved_nozzle/cpu.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/check_pr_equilibrium_transport.py configs/surface_pr_resolved_nozzle.json results/pr_resolved_nozzle/cpu.json
```

Пример проверяет импульс давления, изоляцию и повторное открытие.
Независимый инструмент пересчитывает PR-свойства, потоки, силу стенки,
входную энтальпию и локальные балансы. Тесты включают реверс, разреженный
решатель и совместную систему с гравитационной колонной.

Численные эталоны: точный контакт, сверхзвуковое перенесение, задача Сода
на трёх сетках и пространственная сходимость потока в горле для разреженного
метана к идеальному пределу
[изоэнтропического сопла NASA](https://www.grc.nasa.gov/www/k-12/airplane/isentrop.html).
Эталонные числа Маха определяются отдельно по A/A*, без подбора коэффициентов.
SciPy применяется в независимых проверках; производственная невязка,
автоматический Якобиан и линейная алгебра используют PyTorch.

Поток на заданном изоэнтропическом профиле и короткий переходный расчёт
ещё не подтверждают установившийся критический расход. Для этого нужны
длительный расчёт, независимость от противодавления и уточнение сетки/времени.
Не подтверждены многофазное критическое истечение, кавитация, унос капель
и режимные корреляции нефтегазоводяного течения. Геометрия сопла не заменяет
характеристику реальной арматуры.
