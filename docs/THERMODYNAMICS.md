# Термодинамика PR: чистое вещество и смесь

`PengRobinsonFluid` — отдельная модель реального чистого вещества с тепловыми
свойствами. Она не выводит состав или критические параметры из black-oil PVT
и не заменяет автоматически `BlackOilMixture` в пластовом расчёте.

## Исходные данные и область модели

Требуются имя, критические температура/давление, ацентрический фактор,
молярная масса, идеальная молярная теплоёмкость и диапазон температур:

```json
{
  "name": "propane",
  "critical_temperature_k": 369.89,
  "critical_pressure_pa": 4251200,
  "acentric_factor": 0.1521,
  "molar_mass_kg_mol": 0.04409562,
  "ideal_cp_j_mol_k": 73.6,
  "min_temperature_k": 200,
  "max_temperature_k": 550
}
```

Это демонстрационный калорический набор. Постоянная идеальная Cp не является
точной корреляцией теплоёмкости пропана во всём указанном диапазоне.
Результат фазового равновесия по PR и корректность тепловых свойств — разные
критерии: независимая проверка давления насыщения не калибрует Cp или энтальпию.
Данные для рабочего вещества и температурного диапазона должен задавать пользователь.

Cp идеального газа должна превышать R. По умолчанию опорные температура и давление
равны 298.15 K и 100000 Pa; опорная температура должна попадать в объявленный
диапазон. Абсолютные уровни h/s зависят от этого выбора. Сравнивать энтальпии
разных пакетов можно после согласования опорных состояний.

Текущая область: одно чистое вещество, без реакций и твёрдой фазы. Минимальная
температура модели не ниже 0.5 Tc. Расчёт линии насыщения ограничен 0.5–0.999 Tc;
критическая окрестность и неразрешимые касательные явно отклоняются. Это область
численной реализации, а не гарантия точности PR для произвольного вещества.
Для смеси используется отдельный API `PengRobinsonMixture`, описанный ниже.

## Уравнение состояния и свойства

Используется Peng–Robinson:

```
p = R T / (v_m - b) - a(T) / (v_m² + 2 b v_m - b²)
a(T) = Omega_A R² Tc² / Pc * [1 + kappa (1 - sqrt(T/Tc))]²
b = Omega_B R Tc / Pc
kappa = 0.37464 + 1.54226 omega - 0.26992 omega²
```

Константы Omega_A/Omega_B соответствуют критическим условиям PR; в литературе
часто приводятся округлённые 0.45724 и 0.07780. Молярный объём и газовая
постоянная используются внутри EOS; внешний API возвращает массовые h/s,
плотность в кг/м³, h в Дж/кг и s в Дж/(кг·K).

Энтальпия и энтропия состоят из идеальной части и departure-функций.
Выбираются механически устойчивые корни кубического уравнения. Для чистого
вещества глобально устойчивый корень определяется минимумом фугитивности.
Явный выбор `phase="liquid"`/`"vapor"` может дать метастабильный корень;
это отмечается `stable: false`. Он не маскируется как равновесное состояние.
На линии сосуществования PT не задаёт долю пара: без указания фазы API отклоняет
неоднозначное состояние.

Первые производные по P/T вычисляются через неявное дифференцирование корня
кубического уравнения и departure-функций в FP64. Возвращаются Cp, Cv и скорость
звука для однофазного состояния. Проверяются положительные Cp/Cv и конечность
производных. Вторые производные корня и двухфазная скорость звука не заявляются.

Уравнения и соглашения: [IDAES — cubic EOS](https://idaes-pse.readthedocs.io/en/1.6.3/user_guide/components/property_package/general/eos/cubic.html),
[NIST teqp — cubic models](https://pages.nist.gov/teqp-docs/en/main/models/cubics.html).

## Фазовое равновесие и flash

`saturation_at_temperature(T)` находит давление равенства фугитивностей жидкости
и пара. Границы трёхкорневой области определяются спинодалями; произвольное
начальное приближение не выбирает фазу. `saturation_at_pressure(P)` решает
обратную задачу в поддержанном диапазоне.

`flash_ph(P, h)` и `flash_ps(P, s)` различают однофазную ветвь и скрытый тепловой
интервал. В двухфазном состоянии доля пара определяется балансом h или s;
удельный объём и остальные удельные свойства смешиваются по этой доле.
Для чистого вещества массовая и молярная доли пара совпадают. Плотности фаз
нельзя усреднять арифметически вместо удельных объёмов.

На концах двухфазного интервала допускается малая численная погрешность
восстановления насыщения; фактический остаток flash возвращается явно.
За пределами температурного диапазона или в неподдержанной критической
окрестности решение не подменяется обрезанием T или качества пара.

## Тепловое оборудование

### Изоэнтальпийный сброс

`ThermalLetdown` принимает входные P/T, массовый расход и EOS. На заданном
выходном давлении решается PH-flash с сохранением h. Проверяются энергетический
остаток и производство энтропии с учётом численной точности. Возможны охлаждение и частичное
испарение; при нулевом расходе выходное состояние не выдумывается.
Это низкоскоростные порты без расчёта проходного сечения и пропускной способности.

### Равновесное сопло

`EquilibriumNozzle` использует однородное равновесное приближение для чистого
вещества: фазы в равновесии, без проскальзывания и задержки зародышеобразования.
По давлению вдоль изоэнтропы решается PS-flash:

```
u(p) = sqrt(2 [h0 - h(p, s0)])
G(p) = u(p) / v(p, s0)
m_dot = Cd A opening G
```

Критическое состояние ищется по максимуму G с учётом границ появления фаз;
гладкая оптимизация не должна пропустить максимум на изломе. Обнаруженные
несколько локальных максимумов отклоняются как неподдержанная ветвистость.
Если максимум за нижней границей давления не найден, критическое давление
не выдумывается: `critical_pressure_resolved` возвращается false.

Ниже найденного критического давления расход не зависит от дальнейшего
снижения противодавления. После смешения струи выходное состояние получается
PH-flash при сохранённом h0; оно отличается от состояния горловины.
Скорость звука/Mach для двухфазной горловины не назначаются произвольно.

`throat_area_m2`, `discharge_coefficient`, `minimum_pressure_pa`, `scan_points`,
`pressure_tolerance_pa` задаются явно. Cd в (0,1], открытие в [0,1], нижняя граница
давления положительна; обратный поток не поддержан. Разрешён только диапазон,
в котором доступны тепловые состояния вдоль всего исследуемого пути.
Это опорный CPU-расчёт, а не высокопроизводительная GPU-модель штуцера.

## API и запуск

```python
from surface import PengRobinsonFluid, ThermalLetdown, EquilibriumNozzle

fluid = PengRobinsonFluid(**fluid_spec)
state = fluid.state(pressure_pa=2e6, temperature_k=300)
flash = fluid.flash_ph(101325, state["enthalpy_j_kg"])
```

Полный JSON-пример:

```bash
python scripts/run_surface_thermo.py configs/surface_thermal_propane.json --output /tmp/thermal.json
```

Поддержаны операции `state`, `saturation_temperature`, `saturation_pressure`,
`ph`, `ps`, `letdown`, `nozzle`. Для оборудования параметры конструкции находятся
в `equipment`, параметры режима — рядом с ним. Неизвестные поля/типы операций
отклоняются. Выходной JSON не допускает NaN/Inf.

## Проверка и границы использования

Проверяются производные, термодинамические тождества, Клапейрон, равенство
фугитивностей, PH/PS-возврат и баланс двухфазного состояния. Равновесное сопло
сверяется с независимым идеальногазовым пределом и сгущением сетки поиска.
Примеры насыщения PR сравниваются с [опубликованными результатами CoolProp](https://coolprop.org/coolprop/Cubics.html).
Численные протоколы находятся в `reports/validation`; здесь они не заменяют
справочник API или физические ограничения модели.

Модель не подключена автоматически к нефтегазоводяному FIM. Для этого нужны
состав и согласованная связь компонентного переноса с пластом, а не переименование
трёх black-oil компонентов в чистое вещество. Существующие модели площадки
сохраняют прежнюю термодинамику.


## Многокомпонентная смесь

`PengRobinsonMixture(components, binary_interactions)` принимает от 2 до 12
объектов `PengRobinsonFluid` с уникальными именами и общим опорным состоянием.
`mole_fractions` — **молярные**, строго положительные доли, сумма равна единице
с допуском 1e-10. Отсутствующие компоненты нужно исключить из состава и матрицы;
молчаливого добавления следов или нормирования некорректной суммы нет.

Матрица `binary_interactions` задаётся полностью, симметрична, имеет нулевую
диагональ; каждый kij конечен и меньше единицы. Нули — явное модельное допущение,
не подобранные значения для неизвестной нефти. Поддержаны постоянные kij:

```
a_ij(T) = sqrt(a_i(T) a_j(T)) (1 - kij)
a_mix = sum_i sum_j x_i x_j a_ij
b_mix = sum_i x_i b_i
```

Фугитивности и departure-функции согласованы с этими правилами смешения;
энтропия содержит идеальную энтропию смешения. Формулы приведены в
[IDAES cubic EOS](https://idaes-pse.readthedocs.io/en/2.0.0a3/reference_guides/model_libraries/generic/property_models/ceos.html).
Теплоёмкости идеальных компонентов постоянны в объявленном общем диапазоне.
Калорические данные примера иллюстративны, не откалиброваны по эксперименту.

### Устойчивость и равновесие

`state(P,T,z)` выбирает однородный корень с минимальным Gibbs **при фиксированном
составе**. Это не проверка устойчивости к разделению смеси.
`stability(P,T,z)` минимизирует безразмерное расстояние касательной плоскости
(TPD) с нескольких стартов: исходный состав, оценки Wilson и обогащённые
компонентами составы. Используется нижняя Gibbs-огибающая механически устойчивых
корней. Отрицательный TPD указывает на неустойчивость исходной фазы.
Это ограниченный численный поиск, а не математический сертификат глобального минимума.
Неуспешная минимизация приводит к ошибке, не к выводу об устойчивости.

`flash_pt(P,T,z)` решает равенство компонентных фугитивностей и материальный
баланс через K-факторы и уравнение Rachford–Rice. Тривиальное K=1 решение
отклоняется для неустойчивого исходного состояния. Разделение должно уменьшать
Gibbs; после решения повторяется TPD-проверка относительно общей касательной.
При обнаружении оставшейся неустойчивости расчёт отклоняется: LLE и три фазы
не поддержаны. Вырожденное сосуществование с неопределённой долей фаз тоже
требует дополнительных условий.

Результат содержит `phase_count`, `phases` с молярными долями и составами,
компонентную невязку, h/s и плотность общего равновесного объёма. В двухфазном
режиме дополнительно возвращаются `vapor_molar_fraction` и невязка логарифмов
фугитивностей. Молярная доля пара не равна массовой. Плотность рассчитывается
из суммарной массы и молярных объёмов фаз, без усреднения плотностей.

`flash_ph(P,h_m,z)` и `flash_ps(P,s_m,z)` ищут температуру равновесного состояния
в пересечении объявленных температурных диапазонов компонентов. **Здесь цели
молярные:** Дж/моль и Дж/(моль·K), в отличие от массовых целей чистого флюида.
Вне диапазона и при неразрешённой фазовой задаче выдаётся ошибка.

### Сброс давления и запуск

`MixtureLetdown` сохраняет общую молярную энтальпию и компонентные массы,
выполняет PH-flash на выходе и проверяет знак генерации энтропии.
Он рассчитывает смешанное равновесное состояние после снижения давления;
не определяет расход по площади и не является критическим штуцером.

```bash
python scripts/run_surface_thermo.py configs/surface_thermal_mixture.json --output /tmp/mixture.json
```

Для смеси доступны `state`, `stability`, `pt`, `ph`, `ps`, `letdown`, `nozzle`.
Сопло чистого вещества автоматически на смесь не переносится; для смеси
используется отдельный `MixtureEquilibriumNozzle`, описанный ниже.
Это CPU reference: нет GPU-пакетирования, производных flash для FIM,
водной фазы/ассоциации, химических реакций и калиброванной модели реальной нефти.

### Независимая сверка

Сохранённый эталон метан–этан получен через PQ-расчёт CoolProp PR с явным kij.
Генератор: `scripts/generate_pr_mixture_reference.py`; CoolProp нужен только
для регенерации эталона, не для работы решателя или обычных тестов.
В CoolProp 7.2 используются округлённые коэффициенты PR 0.45724/0.07780
([исходный код](https://github.com/CoolProp/CoolProp/blob/v7.2.0/src/Backends/Cubics/GeneralizedCubic.cpp)).
Проверки разделяют эту конвенцию и наши точные критические коэффициенты;
численное совпадение EOS не подтверждает экспериментальную точность калорики.


## Равновесное сопло смеси

`MixtureEquilibriumNozzle` использует общий компонентный состав вдоль пути
и PS-flash при каждом пробном давлении. Вход — состояние торможения без
заданной кинетической энергии. Для массовых h и плотности rho:

```
u(P) = sqrt(2 [h0 - h(P,s0,z)])
G(P) = rho(P,s0,z) u(P)
mdot = Cd A opening G
```

Ищется максимум G по объявленному диапазону давления. Это однородная
равновесная модель (HEM): фазы имеют одну скорость и мгновенно достигают
теплового и химического равновесия. Вывод из баланса энергии и ограничение
HEM описаны в [исследовании критического истечения](https://web.stanford.edu/~cantwell/Selected_Publications/Liquifying%20hybrid%20fuels%2C%20hybrid%20rocket%20design%2C%20small%20thrusters%2C%20propulsion%20designs%20for%20Mars/Mass%20Flow%20Rate%20and%20Isolation%20Characteristics%20of%20Injectors%20for%20Use%20with%20Self-Pressurizing%20Oxidizers%20in%20Hybrid%20Rockets%20AIAA%202013-3636.pdf).
Это не модель проскальзывания, задержки вскипания или IEC sizing клапана.

Критическое давление находится логарифмическим сканированием и ограниченным
уточнением локального максимума. Дополнительно уточняются обнаруженные границы
смены числа фаз: на них максимум может быть негладким. Несколько найденных
максимумов отклоняются как неоднозначная ветвь. Сканирование конечно и не
доказывает отсутствие узких неразрешённых особенностей: для рабочего состава
нужна проверка сгущением `scan_points`.

Если максимум остаётся на нижней границе, `critical_pressure_resolved=false`,
критическое давление и критический поток возвращаются как null. При разрешённом
максимуме и противодавлении ниже него возникает критическая полка. В докритическом
режиме давление горловины совпадает с противодавлением.

Состояние горловины изоэнтропийное, содержит кинетическую энергию. `outlet` —
другой объект: равновесный полностью смешанный поток при противодавлении после
диссипации кинетической энергии, рассчитанный PH-flash с исходной энтальпией.
Проверяются энергия, компонентные массы и неотрицательная генерация энтропии.
Двухфазные Mach и скорость звука не выдумываются и не возвращаются.

Параметры совпадают с соплом чистого флюида: `name`, `throat_area_m2`,
`minimum_pressure_pa`, `discharge_coefficient`, `scan_points`,
`pressure_tolerance_pa`. В `run` дополнительно передаётся `mole_fractions`.
Все состояния вдоль исследуемого пути должны попадать в общий калорический
диапазон. Ошибки flash не заменяются однофазной аппроксимацией или снижением
точности баланса.

```bash
python scripts/run_surface_thermo.py configs/surface_thermal_mixture_nozzle.json --output /tmp/nozzle.json
```

Модель остаётся CPU reference без интеграции в FIM. Независимо проверен
идеальногазовый предел; равновесный двухфазный случай проверяется по балансам
и сгущению поиска. Экспериментальная точность расхода конкретного оборудования
не подтверждена: нужны калиброванные Cp/kij/Cd, данные геометрии и проверка
применимости равновесного приближения. Водной фазы в модели нет.


Смешение, теплообмен, однофазное повышение давления и PH-сепарация
объединены в отдельной [тепловой схеме](THERMAL_PROCESS.md) с компонентным
и энергетическим балансом, steady-расписанием и перезапуском.


`single_phase_properties` предоставляет аналитические молярные Cp/Cv,
производные объёма и скорость звука PR-смеси с проверкой однофазной устойчивости.
`PRSinglePhaseNozzle` использует их для первого sonic-состояния без полного
равновесного сканирования многофазной области; сетевое применение описано
в [нелинейной PR-связи](DYNAMIC_NETWORK.md).


`PengRobinsonMixture.flash_ps` принимает необязательную `temperature_guess_k`
в общей объявленной температурной области. Подсказка ускоряет поиск скобки,
но не меняет целевую энтропию, фазовую проверку или допуск результата.
Для HEM-сопла `with_outlet=False` пропускает отдельный смешанный PH-выход,
когда его баланс уже решает принимающий динамический сосуд.

## Независимая калорическая сверка

Доступна [воспроизводимая процедура](REFERENCE_VALIDATION.md) по сохранённым
CoolProp 7.2.0 данным: Cp/Cv, фугитивности, производные, скорость звука,
VLE и PH/PS. Соглашения калорики и коэффициентов PR учитываются явно.
Она обнаружила и помогла исправить отказ восстановления трёхкомпонентного flash;
физическая калибровка и глобальная фазовая устойчивость ею не сертифицируются.
