# Энтропийный поток тепловой трубы

По умолчанию `ThermalHomogeneousPipe` использует `numerical_flux="entropy_stable"`.
Старый `rusanov` доступен явно для воспроизведения сравнений. Изменяется
численный поток, а не калорика, EOS, эталонное решение или критерий точности.

## Причина изменения

В задаче встречных потоков схема Rusanov первого порядка сохраняла полную
энергию, но оставляла локальную температурную ошибку в зоне торможения.
Уменьшение dt в четыре раза почти не меняло результат. Эксперименты с HLLC
и более точным решением задачи Римана улучшали давление, но не устраняли
температурную ошибку. Эти экспериментальные варианты не включены в солвер.

Новый поток сочетает энтропийно-консервативную центральную часть,
диссипацию консервативных переменных и дополнительную положительную
тепловую диссипацию. Она переносит энергию только между соседними объёмами.
Поправки состояния по эталонной температуре, обрезания T и удаления энергии нет.

## Переменные энтропии

Обозначения модели: Ul/Ug — массы фаз на объём трубы, alpha=1−Ul/rho_l,
rhog=Ug/alpha, C=Ul Cv_l+Ug Cv_g, theta=1/T, v=J/(Ul+Ug).
Физическая энтропия на объём `S=C ln(T)−Ug R ln(rhog)`.
Для математической энтропии eta=−S:

```
w_l = Cv_l (1 + ln theta) − v² theta/2 + R rhog/rho_l
w_g = Cv_g (1 + ln theta) − v² theta/2 + R (1 + ln rhog)
w_J = v theta
w_E = −theta
psi = R rhog v
```

Это производные eta по консервативным переменным, независимо проверенные
конечными разностями. На физической области eta выпукла: тепловая часть
есть перспектива −log, газовая часть — перспектива x log x; кинетическая
энергия учитывается через E−J²/(2 rho).

## Центральный поток

Пусть `{a}` — арифметическое среднее, `L(a,b)` — логарифмическое среднее
`(b−a)/(ln b−ln a)` с устойчивым пределом при близких аргументах.
В коде отдельно обработаны близкие и сильно различающиеся значения.

```
g = L(rhog_L, rhog_R)
theta_log = L(theta_L, theta_R)
k = {Ul/Ug}
a_face = rho_l / (rho_l + k g)
F_l = rho_l (1−a_face) {v}
F_g = g a_face {v}
F_mass = F_l + F_g
p_face = R {rhog}/{theta}
F_J = {v} F_mass + p_face
F_E = (Cv_l F_l + Cv_g F_g)/theta_log
      − (v_L²+v_R²) F_mass/4 + {v} F_J
```

Поток симметричен, согласован при одинаковых состояниях и сохраняет
постоянное массовое отношение фаз. Прямое раскрытие скачков даёт условие
Тадмора `delta(w) · F_c = delta(psi)`. Оно проверяется на 128 парах
с различными P/T/скоростями и составом. Принцип энтропийного сравнения:
[Tadmor, 1987](https://www.math.umd.edu/~tadmor/pub/TV%2Bentropy/Tadmor.MathComp1987.pdf).
Приведённые формулы относятся к нашей замороженной двухфазной EOS,
а не объявляются общей PR/black-oil формулой из этой работы.

## Диссипация и энергия

К центральному потоку добавляются:

```
F = F_c − lambda delta(U)/2
F_E += − chi lambda Cp_harmonic delta(T)/2
```

lambda — максимум |v|+c двух новых состояний, умноженный на датчик theta
из принятого состояния начала подшага. Cp объёма равна C+Ug R,
среднее Cp гармоническое. chi=`thermal_entropy_dissipation`, по умолчанию 1.4,
допустимы конечные неотрицательные значения. Это **численный коэффициент**, не теплопроводность
реального флюида и не подбираемый параметр PVT.

Он выбран по набору задач численной калибровки, включающему прежние
дополнительные постановки. Эти задачи после выбора коэффициента считаются
регрессией, а не независимой проверкой. Новая зарезервированная матрица
проверяется отдельно и не объявляется автоматически пройденной. Значение явно входит в модель, журнал и контрольную точку.
При уточнении сетки дополнительный поток соответствует вязкости порядка dx
и исчезает для гладкого решения, сохраняя исходные уравнения.

Выпуклость eta даёт `delta(w)·delta(U)>=0`, а тепловая часть даёт
`−chi lambda Cp_harmonic delta(T)^2/(2 T_L T_R)<=0`.
Поэтому диссипация не создаёт отрицательного производства физической энтропии.
Сумма энергии внутренних объёмов сохраняется, так как на каждой грани один
общий энергетический поток с противоположными знаками для соседей.

Отражающая граница строится из зеркального импульса, сохраняя массы и E.
На ней потоки компонент и энергии точно нулевые. Для нового режима проверяется
также полностью дискретный баланс энтропии: численные граничные потоки,
тепло резервуара Q/Tamb, рост энтропии флюида. Отказ не принимается как успех.
Для legacy-режима поле `entropy_production_j_k` равно null: отсутствие
проверки не обозначается нулевым производством.

## Датчик и нелинейное решение

По умолчанию `adaptive_entropy_dissipation=true`. Для граней внутренних
объёмов рассматриваются четыре соседних состояния, включая зеркальную
или явно заданную резервуарную границу. Пусть q — компоненты переменных
энтропии и alpha. Для каждой компоненты:

```
d_minus = q_i − q_(i−1)
d_mid   = q_(i+1) − q_i
d_plus  = q_(i+2) − q_(i+1)
theta_q = (|d_mid−d_minus| + |d_plus−d_mid|)
          / (|d_minus| + 2 |d_mid| + |d_plus| + epsilon_local)
theta   = clip(max_q(theta_q), 0, 1)
```

Локальный порог roundoff равен 64 eps_machine, умноженным на максимум
1 и модуля q в этих четырёх состояниях. Канал alpha обнаруживает материальные
контакты с постоянными переменными энтропии. Датчик не использует номер
ячейки, время удара, эталонную температуру или целевую ошибку.

Датчик вычисляется **один раз из принятого состояния** перед попыткой
подшага. Потоки, EOS, скорость волны и температура в остатке остаются
неявными. Поэтому нелинейная матрица сохраняет трёхъячеечный шаблон.
При дроблении шага датчик пересчитывается из того же принятого состояния;
дополнительной скрытой памяти между шагами или в restart нет.

Предыдущий эксперимент вычислял этот негладкий датчик внутри Ньютона и
не проходил проверки сходимости. Он не включён в рабочий метод. Фиксация
положительных коэффициентов на подшаге устраняет именно эту зависимость
остатка, а не пропускает производные меняющегося коэффициента.

Так как theta лежит в [0,1], доказательство знака энтропийной диссипации
сохраняется. Это не доказательство TVD, точности второго порядка или
безусловной положительности: физические границы состояния, нелинейная
сходимость, балансы энергии/энтропии и дробление шага проверяются отдельно.

Для прежнего постоянного энтропийного потока задайте одновременно
`adaptive_entropy_dissipation=false` и `thermal_entropy_dissipation=0.75`.
Для старого Rusanov — `numerical_flux=rusanov`.
Журнал каждого подшага содержит режим и минимум/максимум theta.
Изменение этих параметров меняет идентификатор модели; старые checkpoint
не принимаются молча как совместимые.

## Проверки и границы

Исходный строгий критерий не изменён: локальная ошибка температуры менее
0.02 K на самой мелкой сетке. Отдельно проверяются уточнение L1-ошибки,
L1 температуры <0.1 K и L1 давления <0.5% эталонного давления.
Нельзя считать выполнение глобального баланса энергии или L1-критерия
гарантией локальной точности в зоне торможения.

```bash
python scripts/check_surface_reference_suite.py --require-local-temperature --include-shock-matrix --shock-workers 4 --output-dir results/thermal_reference
python scripts/check_pipe_shock_matrix.py --matrix validation --cells 512 --workers 4 --output results/reserved_shocks.json
python scripts/benchmark_thermal_fluxes.py --output results/thermal_flux_timings.json
```

Расширенный набор включает четыре прежних дополнительных случая,
четыре случая численной калибровки и четыре зарезервированных случая.
Коэффициент один для всех состояний; состояние не корректируется по эталону.
В зафиксированной проверке все 12 состояний на N=512 прошли: максимум
локальной ошибки 0.0177053 K, в четырёх зарезервированных случаях —
0.0112301 K. Исходная задача даёт 0.0036243 K, сильный режим на N=1000 —
0.0196446 K. Последний результат близок к порогу; локальная ошибка не
обязана монотонно убывать с сеткой.

Прохождение набора не даёт универсальной гарантии 0.02 K при любой сетке,
нагрузке или составе.

Остаются ограничения физики: горизонтальная замороженная смесь,
две фазы, одна скорость/температура, постоянные Cv, идеальный газ.
Поток не добавляет растворение, воду, фазовый обмен или сопряжение с FIM.

Исторические результаты постоянного потока сохранены в
`reports/validation/2026-11-02/THERMAL_SHOCK_FIX_VALIDATION.md`.
