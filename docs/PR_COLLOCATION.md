# Консервативный Gauss4 для PR-графа

`PRCollocation` — отдельный, явно выбираемый временной интегратор замкнутого
HEM-графа `PREquilibriumTransportNetwork`. Давление, температура и количества
компонентов каждой фазы остаются неизвестными PR-равновесия. Свойства не
заменяются постоянными cp/плотностью и не линеаризуются по старому состоянию.

## Уравнения

Для консервативных запасов `Q = (N₁, …, Nс, M, E)` одновременно решаются
две стадии `Qᵢ − Q₀ = dt Σ Aᵢⱼ F(Yⱼ)`. Матрица:

```text
A = [[1/4,          1/4 − √3/6],
     [1/4 + √3/6,   1/4        ]]
b = [1/2, 1/2]
```

На каждой стадии выполняются ограничения химического равновесия и объёма.
После стадий отдельная нелинейная проекция восстанавливает конечные
фазовые количества, P и T из `Q₁ = Q₀ + dt (F(Y₁)+F(Y₂))/2`.
Проекция не меняет целевые запасы. В энергию входят внутренняя,
кинетическая и потенциальная составляющие; импульс хранится у трубных
ячеек. Перемешиваемый сосуд не приобретает осевой импульс.

Пространственные потоки HLLC, давления закрытых торцов, силы трения,
PR-термодинамика и межсосудный теплообмен переиспользуются из существующей
модели. Для этого её монолитный остаток вычисляется при `dt=0`: это
алгебраические ограничения плюс разность запасов. Новая временная
квадратура добавляет те же физические скорости изменения, без копии EOS
или второго рабочего HLLC.

Все стадии и конечное состояние проходят проверку допустимости EOS,
потоков и стабильности фаз. Балансы проверяются локально и по всему графу;
энтропийный критерий существующего решателя сохранён. Для внешнего тепла
нужны явная температура источника и допустимое пассивное направление.

## Ошибка, переходы и стоимость

Оценка времени — разность полного шага и двух полушагов. Принимаются
**два рассчитанных полушага**; экстраполяции запасов или фаз нет.
Разность не делится на 15: используется консервативный исходный бюджет
`PREquilibriumTransportNetwork._error` для P, T, N, E и скорости.
Нелинейные допуски не ослаблены. Для гладкого Gauss4 предложение шага
масштабируется с показателем 1/5; короткая отчётная граница сохраняет
рабочее предложение только при достаточно малой оценке ошибки.

Если фазовая топология стадий несовместима, Newton не сошёлся либо
физическая проверка отвергла Gauss-попытку, весь кандидат отбрасывается.
По умолчанию тот же интервал заново проходит существующую ветвь
backward Euler с поиском фаз и собственной проверкой полного/двух
полушагов. В журнале явно записаны `method="backward_euler_fallback"` и
`fallback_reason`. Ошибку этой ветви нельзя скрыть: шаг дробится, затем
срабатывает общий лимит попыток/минимальный шаг. `phase_fallback=False`
отключает резервную ветвь для диагностики.

Поэтому четвёртый порядок подтверждён **на гладких фазовых ветвях**.
На резервных участках используется первый порядок; четвёртый порядок
через фазовый переход и непрерывная локализация события не заявляются.

Одна Gauss-попытка содержит два нелинейных решения: общие стадии и
конечную проекцию. С оценкой времени это шесть решений против трёх у
прежнего backward Euler. Высокий порядок может компенсировать эту цену
большим шагом на гладких траекториях, но общего ускорения из этого не
следует. Чистого GPU-бенчмарка этого пути пока нет.

## Область текущего адаптера

Подключены закрытые сосуды и трубные ячейки, связи HLLC, заданные
тепловые мощности и `PRHeatLink`, изоляция связей, конечные запасы,
одна или несколько равновесных PR-фаз. Разреженная Torch-матрица
учитывает связи между обеими стадиями и соседними ячейками.

Пока **отвергаются**, а не молча упрощаются:

- насосные/компрессорные аппараты, роторы и HEM-ограничители;
- стенки с конечной теплоёмкостью и гидростатические реконструкции граней;
- отдельные капельные запасы, проскальзывание и drift-flux;
- stagnation-reservoir traces и внешние открытые границы.

Это ограничения нового временного адаптера; перечисленная физика остаётся
доступна через прежние решатели. Обёртка не подключает автоматически
контроллеры, общий граф наземной площадки или пласт. Независимые текущие
проверки выполнены на CPU float64, при g=0. Интегратор работает на
Torch-устройстве модели, но журнал и проверки статусов читаются на CPU.

## API и CLI

```python
from surface import PRCollocation, PREquilibriumTransportState

solver = PRCollocation(model)
report = solver.advance(initial, 0.1, openings={"contact": True})
restart = PREquilibriumTransportState.from_dict(report["state"])
continuation = solver.advance(restart, 0.1)
```

Состояние совместимо с физической моделью и проверяется её `inspect`.
Уставки передаются заново для каждого окна; пропущенные открытия
возвращаются к исходным открытиям модели. Это физический restart, не
автоматический replay всего сохранённого расписания.

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/run_pr_equilibrium_transport.py configs/surface_pr_equilibrium_transport.json --integrator gauss4 --output /tmp/pr_gauss4.json
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python scripts/check_pr_collocation.py --output /tmp/pr_gauss4_reference.json
```

По умолчанию CLI продолжает использовать `backward_euler`. Неподдержанные
модели/команды Gauss4 отвергаются. Каждая Gauss-запись содержит стадии,
конечное физическое состояние, интегралы потоков граней/тепловых связей,
локальные остатки, фактический метод и оценку ошибки.

## Независимые проверки

`check_pr_collocation.py` интегрирует скалярную PR-задачу теплообмена двух
изохорных сосудов. Cv и давление выписаны отдельно через формулу PR;
reference RHS не использует рабочие flash, AD или остатки. DOP853 нужен
только эталону. Ошибки при шагах 0,25 / 0,125 / 0,0625 с дают отношения
около 16,05 / 16,00.

`audit_pr_collocation.py` переиспользует независимые скалярные EOS/HLLC
эталоны прежней валидации. Он пересчитывает физические состояния стадий,
их консервативные уравнения и конечные интегралы, не вызывая рабочие
flash, потоки или `inspect`. Подмена стадии, энергии либо потока
отвергается тестами. Это независимая численная проверка, не новая
экспериментальная калибровка и не доказательство глобального TPD-минимума.
