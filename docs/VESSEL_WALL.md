# Тепловая инерция стенок аппаратов

Динамическая PR-сеть поддерживает сосредоточенную теплоёмкость стенки каждого
аппарата. Температура стенки — отдельная неизвестная общего неявного шага;
она не приравнивается к температуре смеси. Модель работает на CPU.

## Уравнения и баланс

При положительном направлении тепла к флюиду:

```
Qf = UAf (Tw − Tf)
Qa = UAa (Ta − Tw)
ΔUfluid = dt (Hin − Hout + Qdirect + Qf)
Cw ΔTw = dt (Qa − Qf)
Δ(Ufluid + Uwall) = dt (Hin − Hout + Qdirect + Qa)
```

Используется обратный Эйлер: температуры и потоки берутся на новом слое.
Теплообмен со стенкой входит в те же нелинейные уравнения, что компонентные
балансы, объём и энергия смеси. Внутренний поток `Qf` взаимно сокращается
в глобальном балансе; внешнее тепло в отчёте `heat_j` включает только прямой
нагрев и обмен с окружением. Они отдельно доступны как `direct_heat_j`
и `ambient_heat_j`.

Запас энергии стенки равен `Cw*(Tw−Tref)`, энтропия — `Cw*ln(Tw/Tref)`.
Проверяются балансы энергии, производство энтропии, допустимые температуры
и максимальное изменение температуры стенки за подшаг. При отказе шаг
уменьшается, состояние до него сохраняется.

## Конфигурация и запуск

Полный пример: `configs/surface_vessel_network_wall.json`.
В корневом объекте `walls` ключ — имя существующего аппарата:

```json
{
  "walls": {
    "receiver": {
      "heat_capacity_j_k": 1000,
      "fluid_ua_w_k": 10,
      "ambient_ua_w_k": 2,
      "ambient_temperature_k": 280,
      "min_temperature_k": 200,
      "max_temperature_k": 450,
      "max_temperature_change_k": 5
    }
  }
}
```

В `initial.receiver` обязательно задаётся `wall_temperature_k`.
Теплоёмкость должна быть положительной, коэффициенты UA — неотрицательными.
Температуры задаются в K, UA в W/K, теплоёмкость в J/K. Нулевой UA отключает
соответствующий путь обмена. Начальная температура стенки не выводится
автоматически из температуры флюида. В одной сети разрешены аппараты
со стенками и без них.

Период расписания может содержать `ambient_temperatures`, например
`{"receiver": 370}`. Это температура внешнего резервуара, а не уставка
температуры смеси. Для аппарата без стенки такая команда запрещена.

```bash
python scripts/run_vessel_network.py configs/surface_vessel_network_wall.json \
  --output results/wall.json
python scripts/run_vessel_network.py configs/surface_vessel_network_wall.json \
  --stop-after 1 --output results/wall_partial.json
python scripts/run_vessel_network.py configs/surface_vessel_network_wall.json \
  --checkpoint results/wall_partial.json --output results/wall_resumed.json
```

В Python начальные состояния создаются через `network.initialize(fluid, specs)`.
Состояние хранит `wall_temperature_k`, `wall_energy_j`, `wall_model_id`;
несогласованный запас энергии или чужая модель стенки отклоняются.
Отдельный решатель `DynamicVessel.advance` не принимает такие состояния:
нужен сопряжённый `DynamicVesselNetwork`.
Контрольная точка расписания учитывает энергию стенок, параметры модели,
команды и исходный код решателя. Несовместимая контрольная точка отклоняется.

## Защиты и тепловой выбег

Метрика защиты `wall_temperature_k` локализует пересечение порога стенкой.
Действия остановки нагрева отключают **прямой источник тепла**. Они не удаляют
накопленную энергию стенки и не отключают пассивный обмен с окружением.
После срабатывания защиты смесь может продолжать нагреваться, а давление —
расти. Это физический тепловой выбег, а не основание обрезать состояние по
уставке. Достаточность защит требует отдельного анализа сценария.

## Область применимости

Это равномерная стенка с постоянными явно заданными Cw и UA, окружающая среда
имеет заданную температуру и неограниченный запас энергии. Геометрия,
распределение температур в металле, зависимость свойств от температуры,
тепловые напряжения, обледенение и пространственная теплопроводность
не моделируются. PR-смесь сохраняет собственные ограничения: постоянные
идеальные Cp/kij, максимум две равновесные фазы, без водной фазы.
Демонстрационные коэффициенты не являются калибровкой реального оборудования.
Модель не добавляет GPU-расчёт или сопряжение с пластовым FIM.
