# Гравитационное равновесие конечной PR-колонны

`StratifiedPRColumn` решает пространственный равновесный профиль в закрытом
цилиндрическом объёме. Неизвестны локальные P и состав, положения плоских
межфазных границ и общая равновесная температура. Компонентные запасы и
**полная энергия U + потенциальная энергия** заданы и сохраняются.
Численное решение, первые производные и линейные системы — Torch float64
CPU/CUDA. Профиль может содержать одну, две или три разрешённые фазы.

Это самостоятельный равновесный примитив. Он ещё не заменяет временное
решение `CompositionalNetwork` и не добавляет гравитацию в её одноточечные
сосуды. `g=0`-ограничение прежнего кинематического PR-отбора сохраняется.
Новая колонна даёт согласованный покой и локальные состояния для будущего
сопряжения; время осаждения/переходные процессы здесь не вычисляются.

## Физическое замыкание

При вертикальной координате h, направленной вверх от дна, для каждого
присутствующего компонента и каждой фазы выполняется:

`ln(f_i(h)/p_ref) + M_i g h/(R T) = lambda_i`.

Константы `lambda_i` общие для всего объёма. Локальные фугитивности PR
зависят от локальных давления и состава. Это равновесие химического и
гравитационного потенциалов; связь фугитивностей с полем тяжести обсуждается
в [публикации NASA NTRS](https://ntrs.nasa.gov/citations/19860021148) и
[работе о sedimentation equilibrium](https://doi.org/10.1016/S0009-2509(01)00094-X).
Знак здесь соответствует высоте вверх, а не глубине вниз.

Внутри фазы из этих условий и тождества Гиббса—Дюгема следует
`dP/dh = -rho*g`; при этом состав тоже может меняться по высоте.
Для идеальной смеси восстанавливается барометрический закон отдельно
для каждого компонента. У интерфейса обе фазы имеют общие T, P и
химические потенциалы. Капиллярного скачка P нет: поверхностная энергия
и капиллярность в эту модель не включены. Более плотная фаза располагается
снизу; неразрешённое или обратное расположение отвергается.

Глобальные ограничения:

`N_i = sum_layers integral x_i/v_m dV`,

`E = sum_layers integral [u_m/v_m + rho*g*(elevation + h)] dV`.

Температура пространственно однородна в тепловом равновесии, но **не
предписана внешним термостатом**: её находит ограничение полной энергии.
При релаксации исходного неравновесного распределения она может отличаться
от входной температуры. Начальные запасы не подправляются под давление.

## Одно совместное решение

В каждом слое используются узлы квадратуры. Неизвестные каждого узла —
log(P) и независимые логарифмы отношений мольных долей. Общие неизвестные —
`lambda_i`, T и относительные высоты слоёв. По обе стороны интерфейса
добавлены отдельные состояния; их давления приравниваются явно.
Все локальные химические условия, интерфейсы, N и E входят в один Ньютон.
Внутри его residual нет вложенного PT/UV flash.

Для вертикального цилиндра интегрируется линейная высотная координата.
Для горизонтального применяется угловая координата круга, чтобы избежать
корневой особенности площади сечения у стенки. Вес каждого слоя
нормируется на его аналитический геометрический объём. Правила Gauss—Legendre
сохраняются на устройстве при построении модели, а не пересоздаются на CPU
в каждой пробе Ньютона. Шаблон фаз на отдельном решении фиксирован.

Порядок квадратуры повышается по 2 → 4 → 8 → 16, начиная с заданного.
Сравниваются T, среднее давление, относительная потенциальная энергия,
интерфейсы и фазовые компонентные запасы. Сравнение только суммарных N/E
недостаточно: они удовлетворяются каждым дискретным решением сами по себе.
При нехватке максимального порядка результат не публикуется.

Абсолютная отметка вычитается из целевой энергии аналитически через
заданные массы компонентов. Поэтому смена нуля высот не ослабляет
проверку относительной потенциальной энергии и не меняет физический профиль.

## Устойчивость и ограничения фазового набора

Начальный набор фаз получается из однородного UV-приближения. После
совместного решения в каждом узле и на интерфейсах отдельно проверяются
механическая/калорическая допустимость и численная локальная фазовая
устойчивость. Расходящиеся, нечисловые и нарушающие N/E решения отвергаются.
Минимальный разрешённый объём слоя — больше `1e-12` полного объёма.

Если гравитация требует другого активного набора слоёв или слой вырождается,
модель сообщает об этом. **Универсального поиска всех стеков, появления/
исчезновения слоёв и глобального сертификата максимума энтропии нет.**
Мультистарт TPD — численная проверка, а не доказательство для любой смеси.
Стационарная диффузионная стратификация не моделирует конвективное смешение
рабочего сепаратора или кинетику установления равновесия.

До 768 неизвестных используется ограниченный прямой Torch-решатель
с неявными первыми производными EOS. Это локальный термодинамический
примитив, не разреженный решатель тысяч пространственных ячеек.
Разрешены порядки 2/4/8/16; максимальный порядок должен быть выше начального.
Управление поиском и проверки устойчивости синхронизируются с CPU.
Отсутствие CPU-синхронизаций, CUDA Graph и ускорение одиночной колонны
на GPU не заявляются.

## API и локальные состояния

`initialize(P,T,z)` строит исходные равномерные PT-фазы, располагает их
по плотности и вычисляет их N, U и потенциальную энергию по геометрическим
моментам. Затем находит гравитационное равновесие с теми же N/E/V.
Проверяется отсутствие уменьшения энтропии в пределах численного допуска.
Это контролируемое начальное состояние, а не навязанное гравитационное P.

`equilibrate(component_moles, total_energy_j, pressure_guess_pa=..., temperature_guess_k=...)`
принимает сохраняемые запасы напрямую. Начальные P/T обязательны и служат
приближениями. Стенка/тепловой резервуар не входят в этот энергетический запас.

`StratifiedPRState` сохраняет N/E, T, химические константы, интерфейсы,
корни, составы-приближения и полные коллокационные переменные.
`inspect` проверяет сериализованное состояние через residual и фазовую
устойчивость без повторного глобального Ньютона. Изменённые запасы,
температура или несогласованные метаданные не принимаются. Кэш проверки
ограничен восемью состояниями; кэш точечных проб — 64. Возвращаемые
точечные данные копируются, поэтому их изменение не меняет модель.

`sample(state, height_m, side=...)` решает локальные условия химического
равновесия, выдаёт P/T/состав, плотность, энтальпию и энтропию на данной
высоте. Это не линейная интерполяция давления. Точно на интерфейсе нужно
явно выбрать `below` либо `above`. Производные EOS относятся к текущей ветви.

`stream_at(state, height_m, molar_rate_mol_s, side=...)` строит общий
`ComponentEnergyStream` с локальными составом и энтальпией, а также
`mass_rate*g*(elevation+h)`. **Он не отбирает материал из запасов и не
продвигает время.** Конечная площадь патрубка, дросселирование, приводы
и динамический обмен с другой колонной пока не сопряжены с этим API.

## Запуск и аудит

Примеры: `configs/surface_stratified_pr.json` (бинарная двухфазная колонна),
`surface_stratified_pr_3phase.json` (иллюстративные метан/гексан/вода),
`surface_stratified_pr_gas.json` (газовый композиционный градиент).
Реальные PVT, ассоциация воды/солёность и оборудование не калиброваны.

```bash
python scripts/run_stratified_pr.py configs/surface_stratified_pr.json --device cpu --output /tmp/column_cpu.json
python scripts/run_stratified_pr.py configs/surface_stratified_pr.json --device cuda --output /tmp/column_cuda.json
python scripts/check_stratified_pr.py configs/surface_stratified_pr.json /tmp/column_cpu.json /tmp/column_cuda.json --output /tmp/column_check.json
```

Корень конфига: `system`, `initial`, `samples`. System содержит `fluid`,
`geometry`, `gravity_m_s2`, `elevation_m`, `quadrature_order` (4),
`maximum_quadrature_order` (16), `relative_tolerance` (1e-6),
`temperature_tolerance_k` (1e-5). Initial задаётся PT/составом либо N/E
с двумя начальными приближениями. Sample содержит `height_m` либо
`interface_index` с явным `side`, и необязательный `molar_rate_mol_s`.

Выход включает исходные равномерные запасы, новый профиль, квадратурные
веса, U/PE/S, фазовые количества, критерий уточнения, локальные пробы,
потоки и SHA256 физических исходников. CLI фиксирует хеши до импорта
и отказывает в публикации при изменении исходников; запись атомарная.
Изменение запрошенных полей не скрывается под успешным результатом.

Отдельный `check_stratified_pr.py` использует NumPy PR и SciPy только
как проверяющий эталон: заново вычисляет химические условия, геометрию,
начальные/конечные N/E, интерфейсы, локальные потоки. Дополнительная
более мелкая квадратура с независимыми локальными решениями проверяет
интегралы между исходными узлами. Проверяющий скрипт не вызывает глобальный
Torch-решатель колонны. Аналитический идеальный предел, независимый ODE
для реальной PR-гидростатики и конечные разности якобиана дополняют аудит.

## Следующее сопряжение

Для временной модели нужно включить профиль в баланс конечных сосудов,
согласовать производные локальных патрубков по N/E и учесть смену
активных слоёв. Затем — конечная площадь гравитационных отборов и
распределённые многофазные трубы. Одноточечную сеть с общим P и новым
пространственным энергетическим запасом автоматически смешивать нельзя.
