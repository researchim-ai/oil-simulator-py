# Проточная динамика гравитационного PR-сосуда

`StratifiedPRFlow` расширяет квазистатическую колонну заданными входными
потоками и конечными круглыми патрубками отбора. Геометрия сосуда фиксирована;
жидкость и газ используют общий компонентный реестр PR, согласованные
калорические отсчёты и энергию `U + PE`. Стенка имеет конечную теплоёмкость.

## Физическое замыкание

Между подшагами профиль успевает прийти к термодинамическому и
гравитационному равновесию. На подшаге давление, составы в объёме и у
патрубков, температура, химические константы и интерфейсы входят в
**одну неявную систему Torch float64**. Отдельного flash внутри невязки нет.
UV-flash используется только для начального приближения/проверки топологии.

Для каждого компонента и общей энергии:

```
N_new - N_old = dt * (F_in - F_out_new)
E_new - E_old = dt * (Htotal_in - Htotal_out_new + Q_wall_new)
```

`Htotal` включает энтальпию и потенциальную энергию на фактической высоте
патрубка. Входной поток дополнительно может нести кинетическую энергию,
которая поступает в запас сосуда. Работа насоса и перенос между высотами
не предполагаются автоматически.

`StratifiedFeed(height_m, stream)` принимает `ComponentEnergyStream`.
Реестр, EOS, энергетический отсчёт, g и абсолютная высота проверяются;
давление источника должно быть не ниже локального давления приёмника.
Расход входа **задан извне**: гидравлика подводящей трубы пока не решается.
Появление ранее отсутствовавшего компонента активирует его в общей системе.

## Конечные отборы

Используется `EquilibriumOutlet` с обязательными `height_m` и `diameter_m`.
Круглая площадь разбивается по пересечениям с фактическими фазовыми слоями.
Локальные P/x решаются в узлах каждой части патрубка; площадь сухой части
нулевая. Квадратура по углу нормируется на точную площадь сегмента круга.
При исчезновении слоя он перестаёт давать вклад в поток.

Для каждого элемента площади действует линейная характеристика:

```
dVdot = conductance * opening * max(P_local - P_back, 0) * dA / A
```

Это односторонний клапан малых перепадов, **не модель критического истечения**.
`maximum_pressure_drop_fraction` ограничивает область применения;
выход за неё возвращает ошибку оборудования. Обратный напор закрывает
отбор, но не превращает его во вход из неизвестного внешнего резервуара.

Поддерживаются bulk/densest/lightest/component_rich и существующие
регуляторы давления либо уровня. Регулятор и доли экспозиции входят в
общий якобиан. При отсутствии требуемого богатого компонента уровневой
регулятор закрывается. Производные кусочно определены: пороги выбора фаз
и насыщение регуляторов являются переключениями, а не гладкими законами.

## Интегрирование и отказ

Уточнение пространственной квадратуры проверяет профиль, фазовые запасы,
интерфейсы, потенциальную энергию и расходы компонентов каждого патрубка.
Контроль временной ошибки сравнивает полный шаг с двумя половинными;
принимаются половинные шаги. Проверяются N/E, температура жидкости и
стенки, давление, интерфейсы и фазовые количества. В конце интервала
повторно замыкаются сквозные компонентные и энергетический балансы.
Состояние неизменяемое: отказ не публикует частично пройденный интервал.

Проверка производства энтропии включает вход, отбор, стенку и окружающую
среду. Запасы компонентов не обрезаются для спасения отрицательного решения.
Неподходящий фазовый набор может быть переинициализирован ограниченное
число раз; при неудаче подшаг дробится или расчёт явно отказывает.
Универсальная гарантия нахождения глобальной фазовой топологии не заявлена.

## Запуск и независимый аудит

```bash
python scripts/run_stratified_pr_flow.py configs/surface_stratified_pr_flow.json \
  --output results/stratified_pr_flow.json
python scripts/check_stratified_pr_flow.py configs/surface_stratified_pr_flow.json \
  results/stratified_pr_flow.json
```

Для GPU у runner есть `--device cuda`. Выбор GPU задаётся явно через
`CUDA_VISIBLE_DEVICES`; тихого отката на CPU нет. Малые сосуды содержат
проверки фазовой устойчивости и host-синхронизации; поддержку CUDA нельзя
трактовать как обещание ускорения таких небольших задач.

Runner сохраняет состояния всех принятых подшагов, потоки, балансы,
аппаратную информацию и SHA256 исходников; JSON публикуется атомарно.
Входные границы постоянны в рамках модели. Изменение условий источника
не является автоматически реализованным расписанием совместной сети.

Аудитор не вызывает динамический решатель или `column.inspect`. Он
использует независимый NumPy PR, восстанавливает химические условия,
интегралы N/U/PE и механическое равновесие интерфейсов; заново решает
локальные состояния на 32-точечной квадратуре каждого патрубка.
Затем сверяет расходы, регуляторы и подшаговые/интервальные балансы.
Для сценариев без входов дополнительно проверяет энтропийный баланс.
Аудит не является экспериментальной валидацией линейного клапана или
сертификатом глобальной фазовой устойчивости. Начальная равновесная
колонна рассматривается как заданное начальное состояние.

## Подтверждённые проверки и границы

Тесты включают двухфазный отбор из патрубка, пересекающего интерфейс,
якобиан против конечных разностей, независимое скалярное решение разгрузки
идеального газа, заданный вход, активацию нового компонента, обратный
напор, регуляторы, сериализацию и обнаружение подменённого расхода
независимым аудитором.

В изолированном опыте с конечным закрытым патрубком подтверждены переходы
2 → 1 при нагреве и 1 → 2 при охлаждении с сохранением N и энергии
жидкости/стенки. Это отдельные неявные шаги; они не подтверждают любые
трёхфазные переходы, пересечение границ фаз в произвольной связанной сети
или разрешение быстрого межфазного переноса.

Следующий этап — давление/расход от реальной подводящей и отводящей сети
в общей системе, двунаправленные соединения с заданным внешним составом,
а затем подтверждённые сценарии пуска/остановки всей цепочки.

Проверка 4 ноября 2026: совместный CPU-набор статической колонки,
тепловой и проточной динамики — **26 passed**. Отдельный CUDA smoke-test
конечного отбора на RTX 3090 — **1 passed**; полный CUDA-набор не запускался.
В коротком проточном примере (два интервала по 0.1 s) независимый аудит
проверил четыре подшага с максимальной энергетической невязкой
`5.34e-13 J`. Эти числа подтверждают численное сохранение для заданного
режима, а не точность относительно промысловых измерений.

Нелинейная система ограничена 768 неизвестными с явным отказом при
превышении; это модель отдельного сосуда, а не готовый масштабируемый
монолитный решатель многососудной сети.

Дополнительно подтверждён одновременный заданный вход и конечный отбор
на одном отчётном интервале: результат проходит независимый аудит N/E.
Отрицательные проверки аудита обнаруживают как изменённый расход, так и
повреждение сериализованных переменных коллокационного решения.

## Сетевое продолжение

`StratifiedPRNetwork` связывает несколько таких сосудов конечными прямыми
соединителями в одной неявной системе, с обратным переносом и общими
балансами N/E. Геометрические ограничения, независимый аудит и сценарий
остановки/открытия: [STRATIFIED_PR_NETWORK.md](STRATIFIED_PR_NETWORK.md).
Соединители пока не содержат распределённый запас трубы.
