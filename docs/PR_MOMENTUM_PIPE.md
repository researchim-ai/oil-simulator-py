# Импульс, кинетическая энергия и акустика PR-трубы

`PRMomentumPipe` — отдельное горизонтальное однофазное ядро конечных объёмов
на Torch float64 CPU/CUDA. Оно хранит **компонентные количества, осевой
импульс и полную энергию U+K**. Эта модель сохраняет инерцию, тогда как
`PRLinepackNetwork` продолжает решать свою квазистационарную Darcy-задачу.
Автоматической замены модели или пересчёта старого checkpoint нет.

## Уравнения и единицы

Площадь A=pi*D²/4, V_cell=A*dx. Плотности сохраняемых величин и потоки:

```
q = [c_1, ..., c_N, rho*v, rho*u + rho*v²/2]
F = [c_1*v, ..., c_N*v, rho*v² + p, v*(rho*u + rho*v²/2 + p)]
```

Здесь c_i — mol/m³, импульс ячейки — kg*m/s, полная энергия — J;
нулевая высотная отметка общая, гравитационного члена нет. `u` в формуле —
удельная внутренняя энергия на единицу массы; EOS предоставляет ту же
величину через молярную внутреннюю энергию и молярный объём.

```
Q_new - Q_old = dt*A*(F_left_new - F_right_new) + dt*V*S_new
S_momentum = - pressure_loss_per_length
S_total_energy = 0  # адиабатическая неподвижная стенка
```

При трении потеря кинетической энергии превращается во внутреннюю:
дополнительный сток `-v*pressure_loss` из полной энергии здесь был бы
неверным. В однородном периодическом опыте это проверяется напрямую,
включая независимое восстановление PR-температуры по новому запасу U.

Вязкость задаётся явно. При её нулевом значении трение отключено;
ненулевая шероховатость тогда отвергается. Используется общий
`darcy_pressure_loss`: Пуазейль, инженерное C1-смешение перехода
Re=2000..4000, затем Haaland. Трение квазистационарное; радиальная память
нестационарного вязкого профиля не моделируется. Коэффициенты формы
потока импульса и кинетической энергии приняты равными 1.

## Численная схема и звук

Поток Русанова с явной постоянной численной границей скорости alpha:

```
F_num = (F_left + F_right)/2 - alpha*(q_right-q_left)/2
```

Скорость звука вычисляется из той же PR-модели и калорических свойств
при замороженном составе, а не из произвольного постоянного gamma:

```
a² = 1 / (rho_p - rho_T*s_p/s_T)
```

Производные берутся по P/T при постоянном составе; `s` может быть молярной
энтропией, поскольку молярная масса при этом фиксирована.
`wave_speed_bound_m_s` обязателен. Начальное и каждое принятое состояния
проверяются на `abs(v)+a <= alpha`, положительные акустические производные,
границы EOS и численно устойчивую **одну фазу**. Недостаточная alpha —
явный отказ, не тихое переключение схемы. Это не формальное доказательство
глобальной фазовой устойчивости или энтропийной допустимости любого скачка.

Неизвестные — logP, логарифмические отношения активных молярных долей,
масштабированные T и v каждой ячейки. Все компоненты, импульс и энергия
решаются одним неявным Эйлером и одним Torch-якобианом. Nested sound/flash
решений внутри невязки нет: звук и фазовая устойчивость проверяются
при принятии точки. Никакой SciPy-решатель в runtime не используется.

Схема первого порядка; Русанов вносит численную диссипацию. Тест акустики
сравнивает фазу/амплитуду с независимым линеаризованным **дискретным**
решением, а отдельное уточнение 8 → 16 ячеек проверяет уменьшение ошибки
относительно непрерывной акустической волны. Это не обещание точных
фронтов на грубой сетке или экспериментальная валидация гидроудара.

## Границы

- `boundary_mode="periodic"`: замкнутое периодическое кольцо; концевые
  команды отвергаются, потоки на обоих концах совпадают.
- `boundary_mode="ends"`, `None`/`"wall"`: отражающая адиабатическая стенка.
  Компонентный и энергетический потоки строго нулевые; реакция давления
  и численного потока импульса учитывается в балансе силы.
- `PRDirichletBoundary`: заданные PT/состав ghost-состояния с экстраполяцией
  скорости из крайней ячейки. Критические параметры и калорический реестр
  проверяются через `fluid_id`. Этот тип служит численным PT/x-условием;
  для физического резервуара потребуется отдельное характеристическое
  либо сопловое сопряжение со стагнационной полной энтальпией.

Граничные потоки записываются одним **знаковым** вектором: компоненты
(mol/s), поток импульса/сила (N), полная энергия (W), слева направо.
Численный диффузионный поток не подменяется односторонним
`ComponentEnergyStream`. Именно этот общий вектор должен участвовать
в будущем монолитном сопряжении.

## Принятие и checkpoint

Каждая принятая точка сохраняет совместное решение Ньютона и проверяет
согласованность N/M/E с примитивными переменными. Проверяются полные
подшаговые и интервальные балансы с отдельными размерными масштабами:
большая энергия не увеличивает разрешённую утечку молей или импульса.
Проверка энтропии использует соответствующий численный поток Русанова.

Время проходит отчётный интервал точно; полный шаг сравнивается с двумя
половинными, принимаются половинные. Контроль включает запасы, P/T и v.
Ошибки уменьшают dt, а не обрезают запасы. Бюджет, нижняя граница dt и
представимость половинного шага ограничены явно. Неуспешный интервал
не возвращает частично изменённое входное состояние.

`PRMomentumState.to_dict/from_dict` сохраняет N/M/E, коллокационные
переменные, время, следующий шаг и идентичность модели. Несовместимые
или повреждённые N/M/E отвергаются при `inspect`/продолжении.

## Примеры и аудит

```bash
python scripts/run_pr_momentum_pipe.py configs/surface_pr_momentum_pipe.json \
  --output results/pr_momentum_pipe.json
python scripts/check_pr_momentum_pipe.py configs/surface_pr_momentum_pipe.json \
  results/pr_momentum_pipe.json
```

Первый пример — затухание однородного движения в периодической газовой
трубе D=5 mm: кинетическая энергия переходит в U. Отдельный пример
`configs/surface_pr_momentum_acoustic.json` задаёт слабую бегущую волну.
`--device cuda` выбирает CUDA; GPU задаётся через `CUDA_VISIBLE_DEVICES`.
Есть host-проверки фаз и шагов; ускорение маленьких задач не заявлено.

Runner фиксирует SHA256 runtime-исходников до импорта, отказывает при их
изменении и записывает JSON атомарно. История хранит полные принятые
состояния, граничные потоки, вязкий импульс, энтропию и невязки.
`describe` возвращает P/T/состав/v/rho, раздельные U и K, энтропию.

Аудитор использует NumPy PR, заново вычисляет U/K/M, звуковую производную,
потоки Русанова, реакцию стенок, трение и каждый FV-баланс. Runtime decode,
solve и inspect не вызываются — это дополнительно проверено monkeypatch-
тестом. Парсер модели используется лишь для нормализации параметров.
Начальный равновесный checkpoint считается заданным. Независимый аудит
не является доказательством отсутствия других равновесных фаз.

## Границы готовности

Подтверждены однородное движение, вязкое затухание с сохранением U+K,
малые акустические волны, реакция стенок, симметрия смены заданных PT/x
границ, сеточное уточнение, якобиан против конечных разностей,
сохранение/продолжение и обнаружение подмены K, энергии и силы трения.

Труба жёсткая: податливость стенки и её влияние на скорость волны
не включены. Тепловая стенка, наклон/гравитация, многофазные переходы,
фазовое проскальзывание и промышленная валидация сильных скачков остаются
отдельными этапами. Бюджет текущего плотного Ньютона — 768 неизвестных.
Новая труба ещё не соединена с сосудами `StratifiedPRNetwork`: при таком
переходе необходимо согласовать импульс и полную энтальпию на патрубке,
а не просто добавить инерционную поправку к старому Darcy-расходу.
