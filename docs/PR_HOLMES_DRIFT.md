# Непрерывное газожидкостное проскальзывание Holmes

`HolmesGasLiquidClosure` (`model="holmes_gas_liquid"`) работает в том же
PR-графе и сборщике конечных труб, что остальные drift-flux-замыкания.
Газ и жидкость имеют разные скорости; фазовые расходы, импульс,
кинетическая энергия и энтальпия используют эти живые скорости.
Замыкание само по себе не меняет термодинамическую модель PR.

## Корреляция и область применения

Использованы уравнения 3–17, 29 и таблица 1 из
[первичного отчёта Díaz, Stanford, 2004](https://pangea.stanford.edu/ERE/pdf/pereports/MS/Diaz04.pdf).
Профильный коэффициент зависит от газосодержания и объёмной скорости.
Дрейф соединяет пузырьковую и плёночную ветви через число Кутателадзе;
поправка наклона применяется относительно вертикали. Интерполяция таблицы
по безразмерному диаметру линейная. В низкогазовой ветви используется
коэффициент 1.53 из явных уравнений 15–16.

Обязательные параметры: `surface_tension_n_m`, `profile_parameter` (A),
`profile_flattening_start` (B), `velocity_sensitivity` (Fv),
`bubble_transition_start` (a1), `bubble_transition_end` (a2).
Пример задаёт исходные A=1.2, B=0.3, Fv=1, a1=0.2, a2=0.4;
это не калибровка оборудования проекта. Разные экспериментальные наборы
требуют разных коэффициентов. Пределы реализации строже общего семейства:
1≤A≤1.5, 0≤B≤0.3; отклонение не более 80° от вертикали;
безразмерный диаметр по умолчанию 4…200. Нулевой диаметр, нулевая гравитация,
горизонтальные участки и выход из объявленной области отвергаются.

Поддерживаются однофазный предел и две газожидкостные фазы. Для трёх фаз
замыкание не подставляется автоматически. Две несмешивающиеся жидкости
не следует объявлять газом и жидкостью по одному признаку плотности.
Это корреляция проскальзывания, а не классификатор всех наблюдаемых режимов
и не поперечная модель стратифицированной границы. Статический карман
использует отдельное [террейн-замыкание](PR_TERRAIN_HOLDUP.md).

## Переход между системами скоростей

Корреляция использует `j = alpha_g*v_g + alpha_l*v_l`, а сохраняемый
импульс — массовую среднюю U. Поэтому j определяется из уравнения

`rho_l*j + alpha_g*(rho_g-rho_l)*(C0(j)*j+Vd(j)) = rho_mean*U`.

Подстановка U вместо j нарушила бы массовый поток. В реализации
скалярная задача решается на выбранном Torch-устройстве без SciPy и
обмена с CPU внутри вычисления скоростей. Начальное приближение получается
ограниченным Ньютоном, затем двумя дифференцируемыми поправками
восстанавливаются первые и вторые производные неявного решения.
A=1 имеет отдельное точное алгебраическое решение без итераций.

Положительная производная только в найденном корне недостаточна:
при большом газосодержании и наклоне возможны несколько корней.
Проверяется достаточная нижняя оценка производной по всему интервалу
изменения C0. Если её положительность не доказана, состояние отвергается.
Это консервативная граница реализации, а не утверждение о невозможности
физического течения. Полное сопровождение таких ветвей потребует j как
дополнительной сохраняемой координаты и отдельной проверки устойчивости.

## Воспроизведение

Пример: `configs/surface_pr_holmes_inclined.json` — наклон 45°, две конечные
ячейки, изоляция и повторное открытие соединения.
`configs/surface_pr_holmes_high_gas.json` задаёт те же условия при
начальной объёмной доле газа 0.8 в обеих ячейках.

```bash
python scripts/validate_pr_surface_matrix.py --device cpu --case holmes_inclined --output results/holmes_cpu
```

После явного выбора свободной CUDA-карты можно повторить с `--device cuda`.
`scripts/reference_holmes_drift.py` независимо восстанавливает корреляцию
через NumPy/SciPy Brent; основной проверяющий инструмент пересчитывает
балансы компонентов, импульса и полной энергии. В тестах дополнительно
проверяются встречный поток при U=0, смена оси, высокий расход,
газосодержание до 0.99, неоднозначная область, производные и restart.
Численные проверки не заменяют экспериментальную оценку ошибки корреляции.
