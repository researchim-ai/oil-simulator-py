# Геометрический уровень и регулируемый отбор сепаратора

`SeparatorGeometry` задаёт горизонтальный либо вертикальный цилиндр с плоскими
торцами: диаметр, длину и ориентацию. Объём должен совпадать с объёмом
`DynamicVessel`. Для горизонтального цилиндра вычисляется площадь кругового
сегмента и численно обращается объём–высота; для вертикального зависимость
линейна. Днища, уклон корпуса и внутреннее оборудование не включены.

В `DynamicVesselNetwork(..., geometries={name: geometry})` уровень вычисляется
по реальному жидкому объёму PR-равновесия: число молей, доля жидкой фазы и её
молярный объём. Это не массовая доля, принятая за уровень. Нужны две разрешённые
фазы; при неразрешённой классификации ошибка не заменяется догадкой.
Уровень в m выводится в `steps[].vessels[name].liquid_level_m`.

## Ограниченный регулятор отбора

В жидком порту `phase_0` допускается `LevelWithdrawal`:

```
q = clamp(bias + gain (h_new − setpoint), 0, q_max)
```

q в mol/s, gain в mol/(s·m), bias в mol/s, h и setpoint в m.
Уровень берётся на **новом** слое внутри общего нелинейного решения.
Массы компонентов и энтальпия удаляются по фактическому составу жидкой фазы.
Это идеальный ограниченный регулятор заданного расхода: не характеристика
реального клапана/насоса, не PID и не привод с механической инерцией.
Приёмник отбираемого потока и энергопотребление насоса этой командой не заданы.

В JSON периоде:

```json
{
  "duration_s": 0.1,
  "withdrawals": {
    "separator": {
      "phase_0": {
        "setpoint_m": 0.15,
        "gain_mol_s_m": 0.1,
        "max_molar_rate_mol_s": 0.02,
        "bias_mol_s": 0.01
      }
    }
  }
}
```

Корневой `geometries` имеет вид
`{"separator": {"diameter_m": 0.5, "length_m": 0.5092958178940651}}`.
Полный пример: `configs/surface_separator_level.json`, включая теплоёмкость стенки.
Обычный численный расход в `withdrawals` продолжает работать как прежде.

Метрика `NetworkTrip.liquid_level_m` локализует пересечение геометрического
уровня. Порог и допуск должны лежать внутри высоты аппарата.
`stop_withdrawal_vessels` отключает также регулируемый отбор, без скрытого
продолжения фонового регулятора. Сброс защёлки не присваивает уровню уставку.
Схема checkpoint v5 учитывает геометрию, команды и код модели.

```bash
python scripts/run_vessel_network.py configs/surface_separator_level.json --output results/separator.json
```

Это развитие двухфазной равновесной динамики. Трёхфазный нефтеводяной интерфейс,
унос, эффективность разделения, пенообразование, осаждение капель,
характеристики реальной арматуры и датчиков ещё не реализованы этой моделью.
