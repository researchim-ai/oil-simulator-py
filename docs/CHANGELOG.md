# Changelog

## 2026-10-25

- Смешение в стволе нагнетательной скважины: переток из пласта в ствол закачивается обратно через закачивающие
  перфорации, масса через перфорацию — по Дарси, меняется только состав; нетто-закачка непрерывна по p_bh.
  Точный Якобиан связей перфораций одной скважины (`SparseMatrixBuilder(extra_pairs=...)`), проверка конечными
  разностями.
- Исправлено зацикливание Ньютона на нагнетательной с нулевой уставкой и перетоком (Norne, C-3H, 3068 сут).
- `run_deck`: чекпоинты (`checkpoint`, `checkpoint_every`) и продолжение расчёта (`resume`).
- Полный Norne (3312 сут) со смешением: 74 мин на RTX 3090 (после выделения изолированных ячеек — 36 мин на RTX 3090 Ti); FOPT −4.5%, FGPT +0.6%, FWIT −0.7%, FGIT 0.00%
  против Eclipse 2014.2.
- `iter_deck` — пошаговый генератор прогона deck с `control_hook`; `run_deck` — обёртка над ним.
- `DeckEnv` (`src/deck_env.py`) — среда gymnasium для агентов поверх deck Eclipse, старт с чекпоинта.
- Линейный решатель: изолированные ячейки решаются отдельно, Krylov/CPR — только по связанной подсистеме
  (Norne: до 2× быстрее на поздних шагах).
- Регрессионные тесты Norne (`tests/test_norne_regression.py`): концевые точки ОФП против INIT Eclipse и первый
  год истории.

## 2026-10-20 … 2026-10-23

- Полностью неявный black-oil (нефть/вода/газ, Rs/Rv, жирный газ, три состояния ячейки), CPR-AMG на GPU.
- Чтение deck Eclipse: corner-point сетка (COORD/ZCORN, разломы, NNC, PINCH, MINPV, MULTREGT), регионы
  PVT/SATNUM/EQLNUM, EQUIL, ENDSCALE, гистерезис Карлсона, THPRES, VAPPARS.
- Скважины и расписание: WCONPROD/WCONINJE/WCONHIST/WCONINJH (включая RESV при средних условиях), COMPDAT,
  WELOPEN, WTEST, смена типа скважины, групповые контроли GRUPTREE/GCONPROD/GCONINJE, гидростатика ствола флэшем.
- Сравнение со сводками Eclipse и OPM Flow: SPE1, SPE9 — доли процента; Norne проходит все 3312 суток.
- Устойчивость Ньютона на Norne: ячейки без нефти (SO_EMPTY/SO_FILLED), ограничение переключений ячейки,
  ослабленные допуски CNV/MB как в OPM, переток в нагнетательных по подвижностям ячейки.
