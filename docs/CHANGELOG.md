# Changelog

## 2026-10-26

- VFPINJ и ограничение THP нагнетательных (WCONINJE THP, поля 8–9): у закачки BHP-ограничение и THP сверху,
  работает меньшее. Бенчмарк VFPINJ_WCONINJE-01 из opm-tests (газовая и водяная нагнетательные выходят на THP),
  эталон посчитан OPM Flow: WGIR −0.12%, WWIR +0.3%, WTHP точно, все скважинные и промысловые векторы в пределах 1%.
- WBHP закрытой скважины — 0, как в Eclipse/OPM. COMPDAT с SATNUM соединения 0 (по умолчанию) больше не ошибка.
- Масштаб в сравнении с эталоном: обводнённость — не меньше 0.01, дебиты воды — не меньше 1% дебита нефти.
- Таблицы лифта VFPPROD и ограничение по устьевому давлению (`vfp.py`): WCONPROD THP, режим THP в скважинном
  уравнении с точными производными по ячейкам и забою, переключения дебит ↔ BHP ↔ THP по самому жёсткому
  ограничению, вектор WTHP. Бенчмарк SPE1CASE1_METRIC_VFP1 из opm-tests: WBHP, WTHP, дебиты и FOPT в пределах 1%
  от OPM Flow (`tests/data/vfpprod`). Norne разбирает все свои VFPPROD, результат не изменился.
- Масштаб насыщенностей в сравнении с эталоном — не меньше 0.01 (машинный ноль газа в OPM не даёт ложной ошибки).
- Выбор шага и сходимость для deck Eclipse — как в OPM Flow: PID по относительному изменению решения
  с целью 8 итераций Ньютона (`dt_control: "opm"`), CNV 1e-2 с ослаблением до 1 при < 3% PV, допуск дебитов
  скважин 1e-4. Norne: 2193 итерации Ньютона вместо 3309, 8.7 мин вместо 13; FOPT −0.04%, FWPT +0.60%.
- CUDA-графы для свойств ячеек и CPR (`cuda_graphs.py`): Norne 13 мин вместо 20, результаты побитово те же.
- Расчёт только по активным ячейкам (сжатая сетка, `cell_map`): Norne — 44 431 ячейка, 20 мин вместо 35; FOPT 0.00%, FWPT +0.50%, FGPT −0.05% от Eclipse. Сайт, графики и документация обновлены.
- MINPV по умолчанию 1e-6 м³ (как OPM): выклиненные ячейки с почти нулевым поровым объёмом отсекаются.
- RVVD (Rv по глубине при EQUIL item 8 > 0).
- Бенчмарк VAPPARS-01 из opm-tests (VAPOIL + VAPPARS без DRSDT, нагнетание газа): GOR, BHP и добыча газа
  в пределах 2% от OPM Flow.

## 2026-10-25

- Смешение в стволе нагнетательной скважины: переток из пласта в ствол закачивается обратно через закачивающие
  перфорации, масса через перфорацию — по Дарси, меняется только состав; нетто-закачка непрерывна по p_bh.
  Точный Якобиан связей перфораций одной скважины (`SparseMatrixBuilder(extra_pairs=...)`), проверка конечными
  разностями.
- Исправлено зацикливание Ньютона на нагнетательной с нулевой уставкой и перетоком (Norne, C-3H, 3068 сут).
- `run_deck`: чекпоинты (`checkpoint`, `checkpoint_every`) и продолжение расчёта (`resume`).
- VAPPARS отключает заданный раньше DRSDT (как в Eclipse); Rs/Rv для пересчёта RESV — средние по объёмам нефти
  и газа; PVTG выше таблицы ограничен снизу; кэш изолированных ячеек перестраивается при смене перфораций.
- Полный Norne (3312 сут) против Eclipse 2014.2: FOPT −0.16%, FWPT +0.90%, FGPT −0.07%, FWIT −0.15%, FGIT 0.00%;
  35 мин на RTX 3090 Ti. Страница [Norne](NORNE.md), скрипты `scripts/run_norne.py`, `scripts/norne_figures.py`.
- `iter_deck` — пошаговый генератор прогона deck с `control_hook`; `run_deck` — обёртка над ним.
- `DeckEnv` (`src/deck_env.py`) — среда gymnasium для агентов поверх deck Eclipse, старт с чекпоинта.
- Линейный решатель: изолированные ячейки решаются отдельно, Krylov/CPR — только по связанной подсистеме
  (Norne: до 2× быстрее на поздних шагах).
- Регрессионные тесты Norne (`tests/test_norne_regression.py`): концевые точки ОФП против INIT Eclipse и первый
  год истории.
