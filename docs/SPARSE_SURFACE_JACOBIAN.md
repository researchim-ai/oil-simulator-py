# Якобиан наземной сети: полнота производных и масштабирование

Полнота производных не означает плотное хранение. Сохраняются все
производные невязок по связанным неизвестным, включая межъячеечные и
межстадийные связи. Нулевые элементы вне заявленного графа не хранятся.

## Что реализовано

Для задач выше `dense_limit` общий PyTorch Newton использует:

- поддержку ненулевых блоков по физическому графу;
- раскраску столбцов и точные AD-произведения `J·v`;
- извлечение только объявленных ненулевых значений;
- COO-оператор и GMRES без плотного глобального LU;
- диагональное или блочное предобусловливание по вызывающему адаптеру.

PR Gauss/Radau использует разреженную поддержку четырёх комбинаций
стадий по тому же пространственному графу. Матрица с двумя стадиями
больше исходной, но не становится плотной по всей сети. Небольшие
задачи ниже `dense_limit` намеренно используют плотное AD/LU.

Основной backward-Euler PR-адаптер передаёт физические блоки в BlockJacobi.
Временной collocation-адаптер теперь также использует физические блоки,
совместно для обеих стадий узла и его стенки; конечная проекция Gauss
использует одноэтапные группы. [Подробности](PR_BLOCK_PRECONDITIONER.md).
Наличие полного разреженного Якобиана само по себе
не гарантирует малое число итераций на длинной жёсткой сети: развитие
предобусловливателя и крупный связанный бенчмарк остаются нужны.

## Устранённый квадратичный временный буфер

Ранее `ColoredJacobian` сохранял все направления раскраски размером
`число_цветов × число_неизвестных` и вычислял такой же полный сжатый
результат. На локальной линии число цветов мало. Но одна глобальная
строка или узел с большим числом связей может потребовать N цветов:
временные массивы тогда становились N×N даже при O(N) ненулевых элементов.

Теперь направления создаются порциями. По умолчанию — не более 64
направлений и 1 048 576 элементов на буфер направлений. При увеличении
N ширина порции уменьшается; минимум одно направление. Для N больше
самого бюджета один вектор неизбежно больше этого бюджета. Капиллярный
адаптер сохраняет прежнюю ширину не более восьми направлений.

Результат каждой порции сразу сводится к её ненулевым элементам.
Сохраняются только эти значения; полного результата «все цвета × N»
нет. Итог возвращается в исходном порядке координат, включая повторные
запросы. Капиллярная ветвь также больше не склеивает полные результаты
всех порций, и её независимая проверка истинной линейной невязки через
JVP сохранена.

В float64 бюджет одного такого массива обычно не превышает 8 MiB;
это **не ограничение всей памяти решателя**. EOS, AD-промежуточные
данные, sparse-значения, предобусловливатель и базис GMRES занимают
дополнительную память. При построении графа чувствительности к самому
Якобиану autograd может сохранять промежуточные данные разных порций;
оценка ограниченного рабочего буфера относится к обычному Newton-пути.

## Что масштабируется и что ещё ограничивает

Для фиксированного числа неизвестных на узел и ограниченного числа
соседей sparse-хранение растёт с числом рёбер. Направления/сжатый ответ
занимают O(B·N), извлечённые значения — O(nnz), базис GMRES — O(restart·N).
Нулевые производные не заменяют физические связи ради ускорения.

Сильносвязанный граф, глобальные ограничения и большое число компонентов
могут увеличить nnz или число цветов. Ограниченная порция устраняет
квадратичную материализацию направлений, но не делает стоимость всех
таких задач линейной: число JVP и стоимость host-раскраски могут оставаться
большими. Matrix-free Newton–Krylov с подходящим sparse-предобусловливателем
и обработка глобальных связей через дополнение Шура — отдельное развитие,
а не уже подтверждённая возможность этого блока.

## Проверки

Проверяются аналитические и dense-AD производные при нескольких размерах
порций, повторная сборка на новом состоянии, переставленные/повторные
координаты и ограничения выделяемых тензоров. Есть sparse-Newton тест
на 2048 неизвестных с запрещёнными глобальными `jacfwd` и LU, а также
физические капиллярные задачи, независимые балансы и тест пропущенной
нелокальной связи, который обязан завершиться отказом.
