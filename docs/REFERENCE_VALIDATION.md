# Независимая проверка PR и энергетики трубы

Эта процедура проверяет реализацию уравнений в объявленной области, а не
подтверждает промышленную точность всех моделей. Эталонные свойства получены
отдельным CoolProp 7.2.0 PR, без импорта нашего солвера. Для обычной проверки
CoolProp не нужен: используются сохранённые данные с происхождением и hash.

## Состав проверки

`tests/data/surface/pr_caloric_coolprop.json` содержит 24 гомогенных состояния
и 32 двухфазных состояния. Чистые вещества: метан, этан, пропан, CO2.
Смеси: метан/этан и метан/этан/пропан с явно заданными kij, включая ненулевые
и отрицательные значения. Из этих состояний построены 148 сравнений:
гомогенные свойства, VLE и выбранные обратные PH/PS в двух соглашениях PR.
Количество сравнений не равно количеству независимых экспериментальных точек.

Проверяются плотность, Z, молярный объём, энтальпия/энтропия, Cp/Cv,
производные объёма, скорость звука и фугитивности. VLE дополнительно проверяет
долю пара и составы фаз. PH/PS получает цель от внешнего эталона, а не от
предыдущего собственного PT-расчёта.

Для трубы отдельно проверяются линейные изотермическая и адиабатическая волны,
а также симметричное ударное сжатие. Последний эталон получается из сохранения
массы, импульса и энергии на разрыве, без вызова EOS/потоков солвера.

## Соглашения термодинамики

У нас задан постоянный идеальный Cp, тогда как собственная идеальная калорика
CoolProp может зависеть от температуры и иметь другие нули. Поэтому эталон
использует независимые residual-свойства CoolProp с явно согласованной
идеальной частью. Это не сравнение абсолютной энтальпии двух разных калорик.

Для энтропии важно различие опорных состояний: residual CoolProp задан
относительно идеального газа при той же плотности. Departure при одинаковых
P,T равен `smolar_residual + R ln(Z)`. Идеальная часть включает энтропию
смешения. Cp/Cv получаются заменой только идеальной составляющей;
скорость звука вычисляется с этой калорикой и независимыми производными EOS.

В рабочей модели остаются точные коэффициенты PR:
OmegaA=0.4572355289213822, OmegaB=0.07779607390388846.
CoolProp 7.2.0 использует 0.45724/0.07780. Поэтому есть две явно разные полосы:

- `matched_coolprop`: адаптер **только процедуры проверки** согласует коэффициенты.
  Он проверяет реализацию уравнений при одной постановке.
- `production_exact`: рабочие коэффициенты не меняются; отличия выводятся
  отдельно и проверяются по более широкому бюджету различий соглашений.

Допуски записаны в `scripts/pr_reference_support.py`, фактические ошибки —
в каждом сравнении. Это не допуски Ньютона и не оценка экспериментальной ошибки.
Коэффициент притяжения теперь берётся из одного свойства компонента как
для EOS, так и для калорической касательной, исключая разные соглашения
в первой и второй температурных производных.

Документация исходного backend: [CoolProp Cubics](https://coolprop.org/coolprop/Cubics.html).
Версия, git revision и генератор зафиксированы в JSON; текущая веб-документация
может относиться к более новой версии.

## Качество самого эталона

У некоторых трёхкомпонентных PQ-состояний CoolProp 7.2.0 наблюдается остаток
компонентного баланса заданной подачи порядка 1e-6, хотя фугитивности фаз
замыкаются значительно точнее. Такие значения нельзя подавать как точную
проверку одновременно номинальной подачи и заданной доли пара.

JSON сохраняет исходную подачу `requested_mole_fractions`, её остаток
`coolprop_feed_residual`, исходную плотность и все свойства фаз.
Строго согласованное сравнение использует подачу, восстановленную по
независимым фазам и доле пара:

```
z_effective = (1−beta) x_liquid + beta y_vapor
```

Плотность также вычисляется по этим фазовым объёмам и восстановленной
компонентной массе. Это явная смена проверяемого входа на самосогласованное
эталонное состояние, а не утверждение о совпадении на исходной номинальной
подаче. Исходные значения сохранены для аудита; они не затираются.
Тесты отдельно проверяют эту реконструкцию.

Гомогенная принудительно выбранная ветвь не доказывает глобальную устойчивость
смеси. Численный multistart TPD нашего солвера тоже не является математическим
доказательством отсутствия всех других фаз.

## Исправление восстановления flash

Расширенная матрица воспроизвела отказ PT для смеси 0.5/0.25/0.25 при 5 MPa,
297.86084733540304 K. Начальное beta=0.5 приводило поиск к K=1 либо границе
beta, несмотря на отрицательный TPD. Это прерывало также PS-поиск температуры.

Если обычные старты не дали допустимого разделения, теперь пробуются оценка
beta из Rachford–Rice и дополнительные значения 0.1/0.9. Повторно решаются
те же уравнения; критерии фугитивностей, компонентного баланса, Gibbs и TPD
не ослабляются. Численный отказ не превращается в фиктивную одну фазу.
Обычный успешный путь не получает дополнительных нелинейных решений.

## Запуск и строгие критерии

```bash
python scripts/check_pr_reference.py --output results/pr_comparison.json
python scripts/check_surface_reference_suite.py --output-dir results/surface_reference
python scripts/check_surface_reference_suite.py --require-local-temperature --output-dir results/surface_reference_strict
```

Первый CLI — gate PR: ненулевой код при несоответствии.
Общий CLI запускает PR, обе волны и ударный тест; сохраняет каждый результат,
журнал, hash исходников и сводку. Старые выходные файлы удаляются перед
соответствующим заданием и не заменяют отсутствующий новый результат.
GPU скрыта только для дочерних процессов проверки; другие расчёты не затрагиваются.

Статусы различаются:

- `passed`: выбранные проверки прошли, включая локальную температуру.
- `passed_with_local_temperature_limit`: стандартные проверки прошли,
  но строгая локальная температура не подтверждена.
- `failed`: не пройдена выбранная обязательная проверка.

`--require-local-temperature` требует отклонение температуры в зоне
торможения менее 0.02 K на самой мелкой сетке. Проверка L1 не заменяет
этот локальный критерий. `--include-shock-matrix --shock-workers 4` добавляет
12 состояний: прежние дополнительные задачи, случаи численной калибровки
и новую зарезервированную матрицу. Обновление коэффициента по результату
задачи лишает её статуса независимой проверки; это разделение отражено
в `scripts/check_pipe_shock_matrix.py`.

Реализация: [численный поток](THERMAL_NUMERICS.md). Она не меняет EOS,
Cv или независимый эталон. Подмена температуры эталоном и удаление энергии
не используются. В summary записывается, включена ли расширенная матрица;
её отказ не маскируется прохождением исходной задачи.

## Регенерация

Эталонный пакет устанавливается отдельно от окружения симулятора:

```bash
python -m venv /tmp/oil-pr-reference-env
/tmp/oil-pr-reference-env/bin/pip install CoolProp==7.2.0
/tmp/oil-pr-reference-env/bin/python scripts/generate_pr_caloric_reference.py --output /tmp/pr_caloric_coolprop.json
```

Генератор не импортирует наше EOS-ядро. При изменении генератора старый hash
не принимается молча; fixture нужно явно проверить и обновить.
В проверенном окружении повторная генерация дала точное совпадение JSON.

Не покрыты: реальная калибровка свойств, вода/ассоциация/три фазы,
полная критическая область, тепловое проскальзывание, весь промысел
и GPU-производительность. Протоколы конкретных запусков находятся в
`reports/validation/`, актуальные команды и область — здесь.

## Компрессорный блок

`--include-compressor` добавляет независимые критическую продувку и
стационарные частичную/полную рециркуляции из `check_compressor_train.py`.
Результат и отпечатки исходников входят в общий отчёт. Флаг подтверждает
только объявленную область сухого идеального газа; реальные карты,
постпомпажная динамика и PR/многофазность им не проверяются.

## Внешние измерения фазового равновесия метан–этан

Добавлен отдельный экспериментальный протокол May et al. (2015),
DOI [10.1021/acs.jced.5b00610](https://trc.nist.gov/ThermoML/10.1021/acs.jced.5b00610.html).
Это измеренные состояния из NIST ThermoML, отдельно от прежних
CoolProp-проверок реализации и эмпирических корреляций Antoine.
Использованы все 17 состояний метан–этан из наборов 1/2: температура
203,22–243,61 K, измеренное давление 2,124–6,885 MPa. Более широкая
область заголовка статьи относится также к другим смесям и здесь не
объявляется проверенной.

Исходный JSON получен из NIST, контрольная MD5 XML совпала с полем
`THERMOML_MD5_CHECKSUM`. Числа и расширенные неопределённости сохранены
в `tests/data/surface/may2015_methane_ethane.json`; выбранные исходные
наборы и метаданные — в `may2015_thermoml_excerpt.json`, без аннотации
статьи. `may2015_manifest.json` связывает URL, контрольные суммы и
преобразование. Экстрактор `scripts/import_may2015_vle.py` сопоставляет
строки по точным `(T, x_CH4_liquid)`, проверяет единицы и идентичности
компонентов. Давление kPa переводится в Pa; измеренный состав газа
относится к ЭТАНУ. Позиционное объединение строк не используется.

Рабочие параметры PR взяты без изменения из
`configs/surface_stratified_pr_gas.json`, как в капиллярных FIM-примерах;
`kij=0`. Протокол закреплён в `configs/validation_may2015_pr.json`.
Измеренные T и жидкий состав заданы как вход. Давление пузырьковой
точки и состав пара предсказываются из равенства фугитивностей.
Стартовые приближения Wilson используют только фиксированные свойства
компонентов; измеренные выходы не участвуют в поиске корня. Численно
тривиальные корни исключаются. Найденное сосуществование дополнительно
проверяется обычным production PT-flash на сконструированной смеси
равных количеств полученных фаз. Эта условная доля 1/2 не называется
измеренной долей пара.

Все 17 состояний дали единственное устойчивое предсказание. Средняя
абсолютная относительная ошибка давления 1,0221%, максимальная 2,6291%.
Средняя абсолютная ошибка мольной доли этана в паре — 0,003843.
В архивированные расширенные маргинальные интервалы попали 15/17
давлений и 16/17 составов. Два давления выходят за границы лишь примерно
в 1,016 и 1,011 раза; один состав — в 1,309 раза. Порог после сравнения
не менялся; новые поправки на округление или подгонка не добавлялись.
Широкие интервалы высокобарических точек также сохранены без исключения.

Архивные неопределённости имеют уровень 95% и включают оценённое
распространение стандартных неопределённостей. Ковариации не даны.
Эти доли попадания — маргинальные диагностические показатели; они не
являются совместным статистическим критерием квалификации EOS.
Теплоёмкости, нефть/вода/рассол, трубная гидравлика и весь промысел
этим сравнением не подтверждаются.

```bash
PYTHONPATH=src:scripts python scripts/validate_may2015_vle.py \
  --output /tmp/may2015-vle.json
```

Повтор на RTX 3090 Ti дал те же 17 предсказаний; максимальное различие
с CPU по давлению <3,4e-8 Pa, по составу <3,8e-15. Полные ошибки каждой
точки, исходные интервалы и отпечатки исходников сохранены в общей
сводке `benchmarks/results/surface_external_validation.json` и архиве
`surface_external_validation_reports.json.gz`.
