# Капельный запас, коалесценция и энергия поверхности

`PRDropletPopulation` добавляет к каждой выбранной ячейке общего PR-графа
число капель `N` — дополнительную неизвестную того же Ньютона и часть
checkpoint. Жидкостный объём `Vd` берётся из текущего локального фазового
равновесия. Представительный диаметр и энергия поверхности:

```
d = (6 Vd / (pi N))^(1/3)
Es = sigma pi N d^2
(dN/dt)_collision = -K N^2 / (2 Vcell)
```

Это замыкание моментов M0/M1 с постоянным ядром Смолуховского, а не
секционное распределение размеров. Для закрытого объёма при постоянном
ядре `N(t)=N0/(1+K N0 t/(2 Vcell))`. Аналитический предел и происхождение
уравнения: [работа по уравнению коагуляции](https://www.math.uni-hamburg.de/research/papers/hbam/hbam2004a180.pdf).
`K` задаётся пользователем в м³/с; экспериментальной калибровки нет.

Диаметр меняет живое замыкание Стокса/Адамара–Рыбчинского внутри Ньютона,
поэтому коалесценция меняет осаждение. Поверхностная энергия входит в полную
энергию ячейки и фазовые потоки. Уменьшение поверхности при коалесценции и
улавливании переходит во внутреннюю энергию. Добавочного источника тепла нет.
Характеристическая система включает дополнительный переносимый запас,
а разреженный Якобиан — его связи с соседними ячейками и энергетическими строками.

## Конфигурация и соединения

В узле `pipe_cell` задаются `drift_flux` типа `DispersedOilWaterClosure` и:

```json
"droplet_population": {
  "family": "oil_drops",
  "coalescence_kernel_m3_s": 1e-15,
  "maximum_number_density_m3": 1e24,
  "gas_compressibility_threshold": 0.5
}
```

Начальное число выводится из начального объёма дисперсной фазы и
`drift_flux.droplet_diameter_m`; его также можно задать явно в initial.
В checkpoint оно обязательно и называется `droplet_number`.
Разные непосредственно соединённые семейства/маркеры отклоняются.

Конечный приёмный объём без капельного запаса должен явно объявить
`droplet_capture=true`. При прямом потоке он поглощает капли с сохранением
компонентов и полной энергии; при обратном — подаёт фазы, для которых размер
вновь образующихся капель определяется объявленным начальным диаметром.
Это явное граничное замыкание, не предсказание распыла форсунки.
Подключение к точной равновесной гравитационной колонне выполняется через
такой конечный улавливающий объём и обычный свободный трубный торец.
Все объёмы остаются в общей нелинейной системе.

Для дисперсии используются смешанные отборы: боковой порт без высоты.
Слоистый отбор несовместим с предположением о локально перемешанном облаке
и отклоняется. Диаметр выходящих капель проверяется относительно реального
прохода патрубка, а не только диаметра исходной трубы.

`PRResolvedSeparator(..., terminal_response_s=0, droplet_population=...,
drift_flux=...)` собирает капельную модель вместо предписанного линейного
терминального дрейфа. Двойное применение обоих законов запрещено.

## Фазы и область применимости

Нефтяная и водная жидкие фазы имеют явно выбранные компонентные маркеры.
Газ выделяется по Z и контрасту плотностей; поэтому водяной пар не обязан
содержать преимущественно газовый компонент. Неоднозначная жидкостная
классификация отклоняется. Порог Z является явной частью модели.

При отсутствии пары «дисперсная жидкость — жидкий носитель» запас капель и
энергия поверхности равны нулю, а движение становится однородным. Растворённая
нефть сама по себе не создаёт капель. При появлении дисперсной фазы без
входящего капельного потока начальное число определяется объявленным диаметром;
это правило зарождения, не модель кинетики нуклеации.

Сохраняются ограничения разбавленности, малых Re/Eo, размера относительно
прохода и малого капиллярного скачка из [описания жидкостного дрейфа](PR_DISPERSED_LIQUIDS.md).
Не реализованы секционный спектр, турбулентное дробление, пена,
концентрированные эмульсии и фазовая инверсия. PR-водная компонента примеров
синтетическая; проверка балансов не заменяет реальную водную PVT.

## Проверки

`tests/test_surface_pr_droplet_population.py` проверяет сохранение компонентов
и энергии, коалесценционное нагревание, сходимость к непрерывному аналитическому
решению, живой Якобиан, перенос числа между ячейками, capture/реверс и
независимый NumPy-аудит с намеренным повреждением checkpoint.
`reference_pr_population.py` независимо пересчитывает роли, размер,
поверхностную энергию, потоки и дискретный баланс числа.

## Расширение: работа мешалки и дробление

Для явного источника новых капель реализована
[энергетически обеспеченная популяция](PR_POWERED_BREAKUP.md).
Она сохраняет существующие перенос, коалесценцию и поверхностную энергию,
добавляя заданную кинетику числа капель и конечную механическую мощность.
Секционный спектр размеров этим расширением не заменяется.
