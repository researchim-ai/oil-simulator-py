# Физические блоки для PR Gauss/Radau

Разреженный временной PR-адаптер теперь передаёт существующему
`BlockJacobi` группы неизвестных по физическим узлам. Для каждой ячейки
в один блок включены фазовые запасы, давление, температура, скорость
и температура её стенки **обеих временных стадий**. Это позволяет
предобусловливателю учитывать локальные химические/объёмные ограничения,
жёсткий теплообмен и связи двух стадий совместно.

Конечная проекция Gauss4 получает одноэтапные блоки тех же узлов.
Radau3 сохраняет конечное состояние последней стадии. Дополнительной
проекции или нового нелинейного решения не добавлено.

## Глобальная система сохраняется

Глобальный sparse-Якобиан и межъячеечные связи не меняются. Локальные
обратные блоки используются слева внутри GMRES; они не заменяют
глобальное решение независимыми решениями сосудов. Финитность и
истинная нелинейная невязка заново проверяются после решения.
Допуски остаются прежними: цель Newton `3e-12`, разрешённая стагнация
`1e-11`, дополнительная проверка невязки `<1e-9`.

Плотный фактор строится только внутри локального блока, максимум
256 неизвестных. Более крупная группа разбивается на части; это
ограничение предобусловливателя, а не удаление связей из глобальной
матрицы. Блоки покрывают каждую неизвестную ровно один раз.

Размеры/группировка берутся из текущей ветви фаз и активных компонентов.
Факторы обновляются вместе с численным Якобианом; при его разрешённом
повторном использовании сохраняются согласованные с ним факторы.
Новый вызов Newton начинает без старых факторов. При сингулярном
локальном блоке существующий `BlockJacobi` использует диагональный
резервный путь; окончательный критерий глобальной сходимости остаётся.
Групповые обращения и векторы GMRES остаются на устройстве fluid.

Оптимизация включена по умолчанию для sparse Gauss4/Radau3. Внутренний
переключатель `physics._collocation_block_preconditioning = False`,
установленный до создания адаптера, возвращает прежнее диагональное
предобусловливание для диагностики. Физическая идентичность модели и
формат checkpoint не меняются. Малый dense-путь остаётся прежним.

## Квалификация и границы

Тесты проверяют разбиение с полной/частичной стенкой, обе стадии,
конечную проекцию, локальные действия против dense-AD блоков,
сравнение с малым глобальным dense-решением и независимые балансы.
Отдельно проверены вырожденный локальный блок и ложный успешный статус:
предобусловливатель не может обойти повторную проверку невязки.

Парные CPU-пробы используют неоднородные PR-тепловые кольца с конечными
стенками и одинаковым фиксированным шагом 0,02 с. Это проверка решения
одной и той же дискретной системы при жёстком локальном обмене.
Она **не подтверждает точность такого шага во времени**, полноту
нефтегазоводяной физики, гидравлическое масштабирование или скорость
всей площадки. Контроль временной ошибки обычного `advance` не изменён.

Локальный BlockJacobi не является многосеточным/CPR-предобусловливателем
для глобальных низкочастотных мод. Длинные гидравлические сети, широкие
связи, рециклы, глобальные ограничения и сильные переходы требуют
отдельной квалификации и, возможно, дополнительного глобального уровня.
