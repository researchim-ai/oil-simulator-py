# Лишняя работа в полном PR-старте

15 ноября 2026. Проверяется исходный полный стенд
`configs/surface_pr_integrated_facility.json`. Его геометрия и допуски
не изменены. Все измерения — CPU float64, один поток; GPU не квалифицирован.

## Найденный и исправленный численный дефект

Первая система имеет 274 неизвестных при `dense_limit=1024`: здесь
используется dense AD/LU, а не sparse GMRES. Ускорение блочного GMRES
поэтому не может напрямую исправить этот участок.

При прежней политике Newton быстро выходил на невязку порядка 1e-11,
затем тратил почти весь бюджет на поправки и линейный поиск. Строка
баланса компонента колонны оставалась немного выше допустимого уровня;
полные поправки увеличивали шум вычитания больших энтальпий насоса.
Неуспешное решение запускало другие фазовые ветви.

В тракте смеси уже была оценка округления энтальпийных строк; в
однофазном тракте она отсутствовала. Теперь для открытого однофазного
насоса добавлены оценки только трёх строк:

- изоэнтропическая работа: `3 eps (|his| + |hin| + |MW g H|) / Escale`;
- работа с эффективностью: соответствующая сумма модулей операндов,
  включая деление на эффективность;
- дросселирование: `3 eps (|hdel| + |hout|) / Escale`.

Оценки ограничены сверху **1e-10**, как в существующем тракте смеси.
Энтропия, давление и температурные ограничения закрытого клапана получают
нулевую добавку. Это оценка округления арифметики над вычисленными
энтальпиями, не строгая оценка всей погрешности EOS или физической модели.

Линейный поиск теперь использует эти же явные построчные масштабы,
замороженные на текущей итерации. Шум строки с большим сертифицированным
масштабом не скрывает улучшения более строгих строк. Цель Newton 3e-12,
базовый стагнационный бюджет 1e-11 и повторная жёсткая проверка полной
транспортной невязки <1e-9 сохранены. Практический бюджет трёх
энтальпийных строк расширен только на описанную явную оценку округления;
общего ослабления всех уравнений нет. Уравнения, их AD-производные,
компонентные и энергетические проверки не изменены.

## Воспроизводимая проверка первой системы

`first_newton/` содержит протокол, две пары AB/BA и полные векторы
невязок/построчных оценок. В обоих вариантах совпадает SHA-256 начального
вектора. Прежняя политика воспроизводится двумя внутренними переключателями
в одной версии исходников. Таймер охватывает только первый Newton,
без инициализации и последующей физической приёмки.

- Прежняя политика: **931 вычисление невязки**, 38 сборок Якобиана,
  оба запуска завершились отказом по бюджету итераций. Времена
  **40,315 и 39,003 с**, медиана **39,659 с**.
- Исправленная политика: **49 вычислений**, 5 сборок, оба запуска
  уложились в явные построчные бюджеты. Времена **3,296 и 3,200 с**,
  медиана **3,248 с**. Максимальная невязка строк без добавки округления
  — **1,552e-14**.

Это сокращение лишней работы одного ранее неуспешного решения.
Отношение времён около 12,2 **не является ускорением всей установки**
и не сравнением двух успешно завершённых физических интервалов.
`stop_reason: line_search_stalled` нового решения отражает остановку
поиска; успешность определяется заново проверенной конечной невязкой
и явными бюджетами, а не текстовым статусом.

## Что по-прежнему ограничивает временной шаг

`temporal_error/` независимо от политики приёмки приписывает ошибку
первой coarse/fine попытки реальным координатам состояний. Используется
сам производственный `_error`: остальные различия поочерёдно зануляются
для диагностики, такие гибридные состояния не интегрируются и не принимаются.
Максимум изолированных ошибок точно совпал с исходной общей ошибкой.

На dt=0,0001 с общая ошибка — **22,27425**. Полностью доминирует
`gas_recycle_0`; следующая по величине ошибка — **0,11548** у водяного
отбора. Регуляторы: положения **0,00158**, интеграторы **0,00025**;
сепаратор — **5,29e-7**. Они не являются причиной первого дробления.

В рецикле диаметр **0,001 м**, длина **0,2 м**, объём **1,571e-7 м³**
(**0,157 мл**). Coarse/fine скорости **0,178208 / 0,200482 м/с**,
разность **0,0222743 м/с** при допуске **0,001 м/с**. Нормированные
различия его давления, температуры, компонентов и энергии — соответственно
0,000426; 0,007665; 0,000029; 0,000315. Дробление вызывает именно скорость.

Этот стенд явно разрешает динамику микроскопического газового объёма
и переносит его требование к шагу на всю сеть. Для медленного режима
работы оборудования это кандидат на отдельную квазистационарную модель
линии или на согласованную многоскоростную интеграцию. Оба варианта
требуют отдельного сравнения с подробной динамикой. Автоматическое
увеличение диаметра, удаление запасов или ослабление допуска скорости
в данной проверке **не выполнялись**. Такой маленький стенд не задаёт
обязательный шаг для любых промысловых сетей.

## Физическая проверка и оставшаяся граница

Короткий связанный старт использует ту же установку с единственным
интервалом **1e-6 с**; он не заменяет секундный пуск/изоляцию/перезапуск.
Начальная реализация до ограничения оценок сверху сохранена в
`startup_trajectory.json`, её независимый аудит — `startup_pre_cap_audit.json`.
Окончательная версия проверяется отдельно в `startup_final_trajectory.json`.
Она также принята с первой попытки; независимый scalar-PR аудит проверил
оба принятых подшага и управляющих состояния. Максимальная локальная
ошибка энергии — **3,8411e-8 Дж**. Принятые интервалы начальной и
окончательной реализаций совпали точно. Сертификат — `startup_final_audit.json`.

Повтор исходного полного рабочего цикла с окончательной версией достиг
60-секундного CPU-лимита: `full_facility_acceptance.json`, **accepted=false**.
Первый coarse/fine расчёт уже завершился корректным отказом по временной
ошибке 22,27425, выбран следующий dt=1,90696e-5 с; далее расчёт остался
во второй попытке. Полный цикл и длительная производительность
не квалифицированы. Дополнительные критерии приёмки ради таймера не удалены.

## Регрессия

**117 разных тестов прошли, 2 пропущены.** Исходный расширенный запуск:
111 прошли, шесть обращений тестов реверсивного насоса использовали старый
пятиэлементный контракт `evaluate`. В исходной Git-версии метод уже
возвращал шестой результат — оценки округления. Тесты обновлены к этому
контракту с дополнительной проверкой нулевых оценок для реверсивной ветви;
весь её набор повторён: 24 прошли, 18 уже входили в исходные 111.
Новые пять проверок также повторены после ограничения оценок сверху.

Проверены открытый/закрытый/отключённый однофазный насос, невязки вне
бюджета, строгие несертифицированные строки, dense/sparse насосы,
многофазный тракт смеси, реверс, приводы, гравитационные фазовые переходы,
состав и энергия. `validation.json` связывает проверки и манифесты;
сохранённые манифесты окончательных прогонов совпадают с текущими исходниками.
Ruff, форматирование, компиляция и `git diff --check` пройдены.

## Воспроизведение

Из корня репозитория, с новым отсутствующим выходным каталогом:

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/benchmark_pr_startup_newton.py --output /tmp/pr_newton_work_fresh --repeats 2
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/diagnose_pr_facility_error.py --output /tmp/pr_temporal_error_fresh
```

Сырые манифесты сохраняют измеренные хеши. Все утверждения о времени
ограничены указанными CPU-сценариями; чистого GPU-замера нет.
