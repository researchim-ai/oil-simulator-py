# Меньше физических проб у границы допустимого режима

Продолжение оптимизации `surface_continuation_secants`. Допуски FIM,
ширина конечной скобки, шаги времени и аудит массы не менялись.

## Изменения

1. Локальный поиск делает минимальную пробу на половину допуска вместо
   целого допуска. Раньше два конца могли оказаться на расстоянии ровно
   одного допуска, а округление делало ширину чуть больше и требовало
   третьего решения. Новая точка по-прежнему физически рассчитывается;
   остановка возможна только с проверенными концами нужной ширины.
2. После двух медленных сужений скобки разрешена одна проба по секущей
   в пределах одного допуска от конца перед делением пополам. Если
   она не помогает, следующее застоявшееся предложение делит интервал
   пополам. Исключение разрешено лишь один раз на весь поиск и только
   для `continuation_safeguarded`. Прочие стратегии сохраняют прежний
   порядок предложений. В неблагоприятном случае это одна лишняя проба,
   не отмена гарантированного сужения интервала.

## Свежая GPU-пара

65 536 ячеек / 64 скважины, 30 суток, два события, 9 принятых стадий,
без отказов. RTX 3090 Ti, лимит Torch 12%; конфигурации и расписания
пары проверены на точное равенство. Контроль неизменности исходников
и независимый аудит массы пройдены.

- Полные FIM-пробы: **41 → 34** (−17,1%).
- Линейные попытки: **104 → 89** (−14,4%).
- Время интегрирования: **48,895 → 44,348 с**, наблюдаемые 1,10×.
- Все шесть локальных поисков требуют двух FIM-проб вместо трёх.
- Начальный полный поиск: 8 → 7 FIM-проб. Полные поиски после событий
  сохранены, их работа на этом примере не уменьшилась.

Машина и GPU общие с другими задачами. Одна пара не доказывает постоянный
коэффициент ускорения; время исключает импорты, построение модели и
итоговый аудит. По сравнению с исходной версией до оптимизации продолжения
режима число FIM-проб уменьшено с 53 до 34; времена разных запусков
не следует использовать как измерение общего ускорения.

Относительно предыдущего кода: конечное давление 0,0277 Па, BHP 1,533 Па,
расходы 0,0366%, накопления 0,00693%. Это не побитовое совпадение:
допустимый конец скобки может меняться в пределах прежнего допуска.
Относительно уточнённого расчёта с шагом 1,25 суток: давление 3,572 Па,
BHP 6,154 Па, расходы 0,0778%, накопления 0,0216%. Все прежние бюджеты
выполнены: `comparison.json`, `finest_comparison.json`.

## Область применимости и воспроизведение

Синтетический слабо истощающийся black-oil пласт с квазистационарной
площадкой. Не Norne, не подробная переходная PR-сеть и не экспериментальная
валидация. Для новых режимов нужны свои проверки.

Публичный профиль не менялся:
`configs/fim_blackoil_facility_field64k_continuation.json`.
Сохранены точные Python-исходники `before_source.tar.gz`,
`after_source.tar.gz`, изменение `implementation.patch`, конфигурация,
расписание, журналы и результаты. При воспроизведении из архива runner
используйте абсолютный путь PVT как в `large.json`.

Из корня репозитория, на доступной GPU:

```sh
CUDA_VISIBLE_DEVICES=GPU-2f9ce359-f3f4-accc-bf9c-31bc88bb1cb7 CUBLAS_WORKSPACE_CONFIG=:4096:8 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/run_fim_facility_forecast.py --config configs/fim_blackoil_facility_field64k_continuation.json --schedule benchmarks/reports/surface_endpoint_probe/schedule.json --days 30 --report-days 5 --device cuda --cuda-memory-fraction .12 --output /tmp/endpoint-probe-run
```

112 тестов прошли, 2 GPU-проверки пропущены в CPU-наборе (`tests.log`).
Реальная GPU-пара выполнена отдельно. Проверены плоские корни, ограничение
числа дополнительных проб, сохранение деления пополам, события,
периодические сканирования, восстановление и откат состояния.

## Месячная регрессия сильного истощения

без отказов, аудит массы пройден. FIM 1684 → 1683, линейные попытки
5009 → 5006. Наблюдалось 246,930 с против архивных 263,165 с;

давление — на 0,00155 Па. С уточнённым эталоном: BHP 164,79 Па,
расходы 0,0958%, накопления 0,1136%. Все прежние бюджеты сохранены.
