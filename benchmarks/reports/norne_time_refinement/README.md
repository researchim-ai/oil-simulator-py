# Norne: три вложенные временные сетки

Проверка 0–755 суток, RTX 3090. Все три запуска используют одинаковые
исходники, физические входы, начальное состояние, CNV=1e-4, MB=1e-8,
скважинные/линейные допуски и резервный поиск Ньютона. Для каждого шага
исходной сетки выполнено точное деление на 2 и на 4, без автоматического
дробления отказавших шагов. Половинный прогон переиспользован только после
проверки совпадения хешей исходников и запускающего скрипта.

## Результат

- Исходная сетка: 136 подшагов, 2 резервных повтора, 140,491 с.
- Половинная: 272 подшага, 1 резервный повтор, 197,916 с.
- Четвертная: 544 подшага, 0 резервных повторов, 330,965 с.

Все завершены, проверены CNV/MB, накопленные балансы, границы насыщенности,
сумма насыщенностей и неизменность исходников/входов. Часы и вложенность
фактических сеток проверены отдельно. Допуски нигде не ослаблялись.

На конечных полях RMS считается с одним набором весов — PV четвертной
сетки, нормированным на сумму. При переходе от пары h/h2 к h2/h4:

- Давление: RMS 12,768 → 7,291 кПа; наблюдаемый порядок 0,808.
- Sw: RMS 0,0007893 → 0,0004600; порядок 0,779.
- Sg: RMS 0,0010060 → 0,0005746; порядок 0,808.
- So: RMS 0,0008546 → 0,0004771; порядок 0,841.

Все RMS-различия уменьшаются. Локальные максимумы также уменьшаются,
но остаются существенными: давление 0,384762 → 0,204619 МПа,
Sg 0,033968 → 0,021107. Это разницы решений, не известные точные ошибки.

Накопленная добыча также сближается. Половинная сетка относительно
четвертной отличается по нефти на −0,01126%, воде +0,25558%, газу +0,00445%.
Порядки отдельных интегральных величин нельзя объявлять порядком схемы:
компенсация ошибок может давать значения выше первого порядка.

## Что подтверждено и что нет

Есть убывающий трёхсеточный тренд на этом окне при фиксированной физике
и допусках. Это не строгая верхняя граница ошибки, не доказательство
асимптотического порядка на всех режимах, не физическая калибровка и не
полная девятилетняя временная сходимость. Локальные поля требуют более
внимательного выбора шага, чем интегральная добыча.

Существующий PID-контроллер по изменению состояния/числу итераций не
превращён в оценщик временной ошибки. Производственные настройки шага
не изменялись. Следующий обоснованный этап — контроллер с отдельными
физическими масштабами давления/насыщенностей и проверкой ошибки, включая
откат проб и события расписания. Не следует автоматически уменьшать
все шаги вчетверо или обещать заданную точность по этой единственной серии.

## Проверка и воспроизведение

Новый scripts/check_norne_time_refinement.py переиспользует difference_order
из существующей проверки наземной динамики. Он отклоняет разные исходники,
допуски/физические входы, незавершённые расчёты, неподтверждённые сетки,
несовпадение фактических шагов, невалидные поля/балансы. 15 тестов прошли,
включая независимую ODE y'=-y с backward Euler на неравномерной сетке,
отклонение разрывов сетки и изменённых параметров.

Архив самодостаточен для повторного сравнения: grid.npz расположен рядом
с каждым manifest и проверяется против записанного хеша оригинального файла.

```bash
PYTHONPATH=src:scripts /home/user/miniconda3/bin/python scripts/check_norne_time_refinement.py benchmarks/reports/norne_time_refinement/coarse benchmarks/reports/norne_time_refinement/medium benchmarks/reports/norne_time_refinement/fine --out /tmp/norne_time_refinement.json
```

Для повторения расчётов использовать scripts/benchmark_norne_accuracy.py,
аргументы из manifests, --mode cnv_ref --line-search-fallback и новые каталоги
вывода. Рабочий решатель и настройки по умолчанию в этом этапе не менялись.
