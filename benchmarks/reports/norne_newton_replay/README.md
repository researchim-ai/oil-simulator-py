# Воспроизводимый отказ отдельного шага BlackOil FIM

Рабочие алгоритмы и допуски в этом исследовании не изменялись. Добавлены
универсальное сохранение предшагового состояния (`--capture-day` в
benchmark_norne_accuracy.py) и scripts/replay_blackoil_step.py. Снимок
содержит решатель, dt, время, хеши исходников и настройки PyTorch.
Это инструменты диагностики, не специальные условия внутри решателя.

## Воспроизводимость

На RTX 3090 повторный шаг с 484 суток, dt=3,6 суток, воспроизводит отказ
за 6,377 с вместо повторного расчёта 0–484 суток. Все 21 набора критериев
точно совпали с независимым повтором того же снимка. Хеши исходников
совпадают. last_newton_iters при отказе может относиться к предыдущему
шагу: в новом отчёте число поправок при отказе не выдаётся за достоверное.

Детерминированный режим PyTorch обязателен для сопоставимости. В первом
исследовательском повторе он не был включён, и шаг случайно сошёлся после
20 поправок. После восстановления исходных настроек отказ воспроизводится.
Этот случай не считался исправлением и не включён в квалификацию решателя.

## Проверенные гипотезы на одном исходном состоянии

- Исходный режим: отказ после 20 поправок; большие конечные CNV.
- Перестроение AMG каждую итерацию: отказ, не устраняет проблему.
- Увеличение бюджета Ньютона до 80: отказ линейного решения раньше
  исчерпания бюджета, проблему не устраняет.
- Сохранение направления локальной поправки при ограничении компонент:
  отказ после 20 поправок. Недостаточно для исправления.
- Уменьшение максимальной поправки насыщенности до 0,05: сходится после
  12 поправок, CNV ≤1,65e-4. Это диагностическая настройка на одном случае,
  НЕ доказательство универсальности и НЕ изменение рабочего значения.

Наблюдается рост невязки, множество переключений фаз и последующее
переключение ограничения C-1H. Установлена чувствительность траектории
Ньютона к ограничению поправок; точная первопричина и универсальное
исправление пока не подтверждены. В частности, успешность более осторожного
шага не доказывает дефект физики или достаточность глобальной релаксации.
Следующая работа — контроль принятия нелинейной поправки с корректным
откатом пробных состояний, включая скважинные ограничения, затем проверка
на независимых задачах. Ни одна гипотеза из списка не включена в production.
Отказ уточнённого режима на 502 сутках этим исследованием не закрыт.

## Проверки инструмента

Независимая небольшая CPU-модель сохраняется и воспроизводит число поправок
и приёмку; проверен запрет незаявленной смены исходников. Вместе с тестами
осцилляций: 11 passed, 1 skipped (CUDA недоступна в CPU-запуске).
Реальный GPU-повтор сохранённого Norne выполнен отдельно.

Снимок: `.scratch/norne_restart_diagnostics/captured/prestep_484.pt`.
Python pickle следует загружать только из доверенных локальных источников.

```bash
CUDA_VISIBLE_DEVICES=GPU-9ade3f1f-7ead-7504-f762-07be60234d31 CUBLAS_WORKSPACE_CONFIG=:4096:8 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /home/user/miniconda3/bin/python scripts/replay_blackoil_step.py .scratch/norne_restart_diagnostics/captured/prestep_484.pt --out .scratch/norne_restart_diagnostics/new_replay
```

Новый каталог вывода обязателен. Ожидаемый exit code текущего снимка — 1
(воспроизведённый отказ), а не ошибка самого инструмента.
