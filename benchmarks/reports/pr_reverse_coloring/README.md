# Сжатые производные и выбор направления AD по структуре сети

В рабочую CPU-ветвь PRCollocation перенесена техника сжатого восстановления
производных по раскраске графа, описанная в
[CasADi §3.9](https://web.casadi.org/docs/#calculus-algorithmic-differentiation).
Реализация использует PyTorch и существующий ColoredJacobian на
транспонированной структуре. Новых вычислительных зависимостей нет.

## Реализация

* ReverseColoredJacobian строит один актуальный VJP-граф на вызов,
  восстанавливает значения исходных координат ограниченными пакетами.
* Для ограниченных плотных задач используется сжатая обратная AD при
  уменьшении числа направлений более чем на 25%; далее прежняя LU.
  Касательная встроенного контроля ошибки использует тот же метод.
* Для больших CPU-систем выбирается прямая или обратная разреженная AD.
  Нижние границы конфликтов позволяют не строить заведомо дорогой план
  для общей строки баланса или общего столбца датчика. Сохраняются COO/GMRES
  и существующий предобусловливатель.
* Ограниченный кэш хранит только точную структуру графа. Численные матрицы,
  свойства и графы AD между состояниями этим кэшем не сохраняются.
* Native/CUDA сохраняют собственную политику. Численные уравнения,
  допуски и контроллеры шага не изменены.

## Связанная установка

`steady/`: исходная 16-узловая установка, рабочий checkpoint, интервал
0,016214944613224563 с. Три чередующиеся пары после двух прогревов,
CPU eager, OMP/MKL по одному потоку. Медиана **4,847563 → 4,435211 с**,
**1,09297×**, сокращение времени **8,51%**.
Построение модели и решение включены, независимые аудиты и сериализация
исключены. Каждый замер включает подготовку собственного структурного кэша.
Reference использует прежний полный reverse AD для Ньютона и forward AD
для встроенной касательной; optimized включает сжатую обратную AD для обоих.
Остальные оптимизации SDIRK и бюджет точности одинаковы.

Все восемь траекторий прошли независимый аудит. Конечная разница в трёх
парах равна нулю в исходной норме. Это короткий рабочий интервал;
полный секундный цикл, Norne и GPU в этой серии не измерялись.
`steady/sources.tar.gz` фиксирует исходники до замера,
`steady/summary.json` — времена, бюджеты и SHA256 исходников.

`graph-validation.json` проверяет исходные матрицы 295/403 неизвестных
против полного jacrev в исходной и возмущённой точках. Сжатое число
направлений — 177/285. Проверяется и независимый аудит самого расчёта.

## Масштабирование ядра

`global-balance.json`: синтетическая матрица с одной общей строкой
и остальными локальными строками. Аналитические производные известны.
Для 129/513/2049 неизвестных: 129/513/2049 → 2 направления;
ускорение собственно построения производных **3,76× / 12,11× / 52,39×**.
Для 2049: медиана **17,084 → 0,326 мс** по семи чередующимся повторениям;
подготовка плана отдельно **87,267 → 2,411 мс**. Ошибка против аналитики
равна нулю. Это отдельное ядро; его коэффициент нельзя приписывать всей
установке или перемножать с ускорениями других серий.

Тесты дополнительно проверяют тензорный бюджет на 20 000 неизвестных,
симметричный случай общего столбца, отсутствие глобального плотного AD/LU
в COO/GMRES-решении на 513 неизвестных, повторные состояния, смену структуры,
границы кэша и переключения связанной установки.
