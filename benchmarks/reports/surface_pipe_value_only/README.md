# Трубные пробы без ненужных графов производных

Приняты три чередующиеся CPU-пары: 1024 ячейки, 16 скважин,
0,003 суток, 16 принятых половинных стадий. Конфигурация, численные допуски
и команды одинаковые. Конечные поля, все сохранённые принятые стадии,
скважинные показатели, trace и материальные балансы совпали точно.
Медианы: **20.305279 → 19.159776 с**;
отношение 1.059787. Хост общий; это короткая регрессия
исполнения, не время полного месяца, Norne или физическая калибровка.

Убрана запись графа для высших производных при поиске скобки и для
первого порядка Гаусса, который служит только оценкой ошибки. dv/dp,
необходимая уравнению импульса, считается всегда. Полный граф сохранён
на возвращаемой квадратуре и для итоговых неявных чувствительностей.
Ненужная поправка после сходимости не вычисляется; пробный граф
освобождается перед финальным дифференцированием. Это не замена PVT,
трения, критерия критического течения или допусков квадратуры.

Проверки включают давление, чувствительности, вторые производные,
движущуюся границу появления газа, совпадающие PVT-узлы, воду, газ,
реальный choking и резервный скалярный путь. CUDA-пара на RTX 3090 Ti
прошла с лимитом аллокатора 8%. В артефактах — исходные протоколы,
траектории шести запусков и их контрольные суммы.

`reference_sources.tar.gz` хранит исходники контрольного пути;
`candidate.diff` содержит изменения двух трубных модулей. Hash записей
source_sha256 всех шести завершённых запусков сверены с исходниками.
`pairs/config.json` содержит исходную конфигурацию с абсолютным PVT;
`config.json` и копия PVT предназначены для запуска из рабочего дерева.

Повтор сравнения с текущей реализацией, из корня проекта:

```sh
reference_dir=$(mktemp -d)
tar -xzf benchmarks/reports/surface_pipe_value_only/reference_sources.tar.gz -C "$reference_dir"
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
PYTHONPATH=src:scripts python scripts/benchmark_facility_source_pair.py \
  --reference-root "$reference_dir" \
  --config benchmarks/reports/surface_pipe_value_only/config.json \
  --days .003 --pairs 3 --output /tmp/pipe_execution_pairs
```

Месячный контроль трубной оптимизации завершён и принят:
**1820,822 → 1706,572 с CPU** на общем хосте, минус 6,27% времени.
Конечные поля, все 1128 сохранённых принятых стадий и скважинные
показатели на 60 отчётных датах совпали точно. Баланс компонентов прошёл
аудит, swap отсутствует. 254 модуля решателя из выполненного снимка
сверены с рабочим деревом; различий нет. Полный протокол —
`month_comparison.json`. Это регрессия исполнения, не новая независимая
валидация физики или результат Norne.

Три пары окончательной реализации: медиана CPU 20.30528 → 19.15978 с. 115 тестов прошли, 9 пропущены в CPU-окружении; отдельно 2 CUDA-теста прошли на RTX 3090 Ti с лимитом аллокатора 8%. Логи: cpu_tests.log и gpu_tests.log.
