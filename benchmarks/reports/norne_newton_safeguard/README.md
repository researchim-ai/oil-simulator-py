# Резервный поиск поправки BlackOil FIM

## Реализация и область применения

Добавлен общий, выключенный по умолчанию `newton_line_search_fallback`:
обычный Ньютон выполняется без изменений; после его отказа транзакция
восстанавливает исходное состояние, затем тот же dt повторяется один раз
с backtracking. Отвергнутые пробы восстанавливают изменяемые данные и кэши
скважин. Ограничения скважин переключаются только на внешних итерациях,
не внутри пробного поиска; потоки и гистерезис фиксируются при сходимости.

При неудаче линейного решения на переиспользуемой AMG в поисковом режиме
разрешена одна пересборка того же нелинейного состояния и повтор с новой
AMG. Это важно: старые J/R уже изменены исключением скважин и масштабированием,
поэтому повторно использовать их нельзя. Новый режим не меняет CNV/MB,
линейные допуски, физику и запрошенный dt. Если оба способа не помогли,
шаг отвергается и обычный контроллер времени может его уменьшить.

Поиск использует неизменный в пределах одной поправки масштаб по PV/B,
максимальную нормированную невязку ячеек и уравнений скважин, пробует
alpha=1,1/2,…,1/256 и требует уменьшения merit с коэффициентом 1e-4.
Это достаточное условие принятия пробной поправки, не замена итогового
CNV/MB-аудита. Сопряжённая наземная сеть ещё не квалифицирована; её
использование с этой опцией явно отвергается. Поддержан обычный BlackOilWells.
В коде нет условий по Norne, календарному дню, ячейке или имени скважины.

## Завершённые GPU-проверки 0–755 суток

RTX 3090, заданные фиксированные сетки; каждый принятый шаг проверен по
сходимости, границам насыщенности и накопленным балансам. Исходники и
входы неизменны внутри каждого запуска, hashes сохранены в manifests.

- `fallback_aligned`: половинная сетка, CNV=1e-3/MB=1e-7;
  272 подшага, один резервный повтор, 193,199 с всего / 182,357 с solver.
- `ref_current`: исходная сетка, CNV=1e-4/MB=1e-8;
  136 подшагов, два резервных повтора, 141,789 с всего / 131,378 с solver.
- `ref_half_fresh`: половинная сетка, CNV=1e-4/MB=1e-8;
  272 подшага, один резервный повтор, 197,916 с всего / 187,170 с solver.

В последнем запуске максимальные накопленные относительные ошибки баланса
нефть/вода/газ: 2,60e-7 / 1,38e-10 / 1,70e-7. Все запрошенные подшаги
пройдены без дробления. Ранее эти фиксированные сетки отказывали на
484, 424 и 502 сутках соответственно.

Первые два успешных запуска выполнены до добавления повторного линейного
решения с новой AMG внутри поискового режима. Финальная версия проверена
третьим запуском и независимыми тестами. Протокол не утверждает, что все
запуски выполнены с побитово одинаковыми исходниками; manifests фиксируют
различие. Это не контролируемый бенчмарк ускорения.

## Точность: два разных эффекта

На половинной сетке обычные и строгие допуски различаются на 755 сутках:
max Δp=280,790 Па (PV-RMS 153,860 Па), max ΔSw=0,0001303,
max ΔSg=0,0003782. При строгих допусках между исходной и половинной сетками:
max Δp=384761,841 Па (PV-RMS 12768,335 Па), max ΔSw=0,022645,
max ΔSg=0,033968. Значит, в данном окне влияние временной дискретизации
существенно больше эффекта проверенного ужесточения нелинейных допусков.
Это сравнение двух сеток, не доказательство асимптотической сходимости,
не строгая оценка ошибки и не независимая экспериментальная валидация.
Для оценки порядка/ошибки нужна дальнейшая временная сходимость.

## Отрицательные результаты сохранены

- `search_window`: постоянный поиск с нулевых суток отказал на 299 сутках.
  Поэтому он не включён по умолчанию и не выбран рабочим режимом.
- `ref_half`: резервный поиск без обновления неудачной AMG всё ещё отказал
  на 502 сутках; добавление ограниченного свежего линейного повтора закрыло
  этот контрольный интервал (`ref_half_fresh`).
- `fallback_window`: 271 шаг прошёл, затем стенд запросил ULP-хвост времени.
  В диагностическом стенде исправлена привязка к абсолютным границам и
  округление максимальной длительности вверх; производственный интегратор
  не менялся. Повтор `fallback_aligned` завершён. Указание 755,0000000000001
  суток в metadata — представление floating point в пределах аудита 1e-8 суток.

## Независимые тесты и ограничения

Окончательный CPU/CUDA-набор: 27 passed. Покрыты принятие уменьшенной пробы,
исчерпание поиска, исключение с откатом, единственный commit, повтор из
восстановленного состояния, отсутствие повторов успешного шага, ограничение
числа попыток и пересборка после модификации матрицы Schur-исключением.
Также пройдены существующие тесты black-oil, осцилляций и адаптивной AMG.

Полный девятилетний Norne с новым режимом и связанная наземная сеть ещё
не проверены. Режим остаётся экспериментальным и выключенным по умолчанию.
Успешное решение фиксированного шага не означает, что его временная
погрешность мала: это разные критерии.

## Воспроизведение

Команды используют scripts/benchmark_norne_accuracy.py, deck
`.scratch/ot2/norne/NORNE_ATW2013.DATA`, сетки
`.scratch/norne_local_refinement/{current,half}_grid.npz`,
`--line-search-fallback` и `--mode step` либо `--mode cnv_ref`.
Точные аргументы и аппаратное окружение записаны в manifests.
Все каталоги вывода должны быть новыми. Коммит и push не выполнялись.
