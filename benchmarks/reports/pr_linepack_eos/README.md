# Пакетный EOS конечных патрубков PR-linepack

Подтверждённая серия `validated/`: медианы **46,469797 → 33,990726 с**,
ускорение **1,36713×**, сокращение времени на **26,9%**. Четыре аудита
пройдены, во всех расчётах 14 принятых подшагов. Максимальное расхождение
отчётных состояний — **1,4287e-11** исходного временного допуска.

Сравниваются две реализации одних уравнений `StratifiedPRNetwork`:
прежние отдельные EOS-вызовы каждого конца патрубка и пакетный
`PhaseEOSGroups` с сохранением индивидуальных температур и фазовых корней.
Обе используют те же геометрию, квадратуры, неизвестные и допуски.

Запрос: `configs/surface_pr_linepack.json`, два конечных сосуда,
горизонтальная двухъячеечная труба, три интервала общей длиной **0,003 с**
(открытие, изоляция, повторное открытие). Это короткий синтетический тест
балансов и реализации. Его скорость не характеризует Norne, большую
установку, другой термодинамический режим или производительность GPU.

В `validated/` сохраняются результаты полной парной серии: `request.json`,
`sources.tar.gz`, `samples.json`, четыре полные траектории `*.json.gz`
и итоговый `summary.json`. Две пары выполняются в порядке
original/grouped, затем grouped/original. Каждый запуск строит и
инициализирует модель заново. Импорты предварительно выполнены;
инициализация, flash и решение включены в измерение, аудит и запись — нет.
Каждый результат проходит независимый аудит PR-профилей, Дарси,
геометрии и балансов компонентов/энергии. Все отчётные состояния
сравниваются исходным оценщиком `StratifiedPRNetwork._error`.
Две пары — локальная проверка эффекта, не статистическая квалификация.

Повторить из корня репозитория с новым каталогом результата:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 CUDA_VISIBLE_DEVICES='' \
PYTHONPATH=src:scripts python scripts/benchmark_pr_linepack_eos.py \
  configs/surface_pr_linepack.json --repeats 2 --output /tmp/linepack-eos
```

Файлы **в корне этого каталога**, вне `validated/`, относятся к первому
незавершённому запуску. Оба физических расчёта и их аудиты прошли, но
сравнение состояний остановилось из-за ошибки типа аргумента в benchmark
(оценщик ожидал карту сосудов). Эти два файла оставлены для прослеживаемости,
не включены в итоговую серию и не составляют её подтверждение. Исправленный
benchmark передаёт именно карты и имеет отдельные проверки этого контракта
и восстановления настройки EOS при отказе аудита.
