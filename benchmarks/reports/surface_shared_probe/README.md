# Пять связанных решений вместо шести

13 ноября 2026 года. Область: первый интервал 1 мкс исходного
`surface_pr_integrated_facility_liquid_mixture.json`, Torch CPU, float64,
один поток OMP/MKL. Пластовый решатель и физические уравнения не менялись.

## Что удалено

Прежний контроллер решал полный шаг и два полушага. Для каждой из трёх
временных проб отдельно выполнялись два порядка квадратуры: шесть
связанных нелинейных решений на обычном пути.

Новый контроллер сначала рассчитывает два полушага с прежним уточнением
квадратуры, сравнением состояний и потоков конечных патрубков. Если оба
полушага подтвердили один порядок, отбрасываемая полная временная проба
решается сразу на нём. Для временной ошибки сравнивается один и тот же
пространственный оператор на полном шаге и двух полушагах. Уточнять
пространственную квадратуру этой отбрасываемой пробы отдельно не требуется.

Это **четыре решения для принимаемых полушагов плюс одно для полной пробы**.
При разных порядках либо отказе прямой пробы используется прежний путь
полного уточнения. Поэтому пять — число решений обычного успешного пути,
а не универсальный предел при отказах или поиске фазовых ветвей.

Непроверенная пространственно полная проба помечается `quadrature_probe`
и не попадает в принятую историю. Независимый аудитор запрещает такой
маркер и требует допустимого численного `quadrature_error` у принятых шагов.
Самостоятельный публичный `advance` непроверенную квадратуру не разрешает.
При отказе всего интервала ранее рассчитанные полушаги не публикуются.

## Три пары измерений

Обновление Ньютона предыдущего этапа включено в обоих вариантах. Отличается
только отдельное уточнение отбрасываемой полной пробы. Каждый запуск —
новый процесс; во второй паре порядок исполнения обратный. Хеши исходников
совпадают во всех шести запусках и проверены до/после расчёта.

- Пара 1: 57,343 → 46,697 с.
- Пара 2, обратный порядок: 57,469 → 46,545 с.
- Пара 3: 57,596 → 46,740 с.

Медиана **57,469 → 46,697 с**, сокращение времени **18,75%** на этом
инструментированном CPU-старте. Это отдельное измерение данного изменения;
его нельзя складывать с историческими процентами других поколений исходников.

Во всех контрольных случаях — шесть глобальных решений, 467 явных вычислений
невязки, 36 Якобианов и 48 принятых обновлений Ньютона. Во всех новых случаях
— пять решений, 339 вычислений невязки, 27 Якобианов и 36 обновлений.
Дифференцирование Якобианов не включено в счётчик явных вычислений невязки.

Размеры систем на принятом пути: 292/400 неизвестных для первого полушага,
292/400 для второго, затем одна система на 400 для отбрасываемой полной пробы.

## Проверки результата

Во всех трёх парах конечное состояние и полные записи обоих принятых
полушагов совпали **побитово**. Совпали также хеши векторов решений всех
четырёх нелинейных систем принимаемых полушагов. Отбрасываемая полная проба
может отличаться на уровне округления: нормированная временная ошибка
0,026414637856325696 против 0,026414637856318757. Выбор следующего шага совпал.

Все шесть независимых аудитов прошли; максимальная локальная энергетическая
невязка — 6,04e-8 Дж в обеих политиках. Допуски времени, пространственной
квадратуры, нелинейной невязки и физические проверки не ослаблены.

Отдельные тесты проверяют пять фактических вызовов глобального решателя,
сохранение проверок обоих полушагов, разные порядки квадратуры, отказ
прямой пробы, откат всего интервала, недопустимые сертификаты, запрет
публикации пробы и перезапуск. Расширенный CPU-набор: **137 прошли,
один CUDA-тест пропущен**, включая реальное сопряжение FIM и восстановление
после отказа. Два предупреждения PyTorch касаются beta API `index_reduce`
и sparse CSR в неизменённом FIM-коде, а не численной сходимости.

Продолжение из того же checkpoint с 1 до 2,5 мкс прошло без отказов за
49,89 с. Независимый аудит прошёл, принятая история и конечное состояние
совпали побитово с предыдущим прогоном на шести решениях. Это отдельная
проверка restart/роста шага, не парный замер ускорения продолжения.

## Воспроизведение

Новая политика включена по умолчанию. Прежняя схема доступна как
`run_pr_controlled_surface.py --refine-discarded-probe`. Выбор записывается
в `numerical_policy.shared_probe_quadrature`, формат checkpoint сохранён.

Ограниченная парная серия, из корня репозитория:

```bash
python benchmarks/reports/surface_roundoff_trials/run_pairs.py --mode shared_probe --pairs 3 --output /tmp/surface_shared_probe_reproduction
```

Драйвер задаёт CPU и число потоков, ограничивает каждый процесс 160 секундами,
запускает независимый аудитор и проверяет точное совпадение принятой истории.
`validation.json` содержит измерения,
сравнения и хеши исходников/аудиторов. `reports.json.gz` содержит полные
отчёты, инструментирование, журналы и драйверы всех шести запусков.

Это не замер GPU и не подтверждение полного секундного расписания.
Дальнейшее сокращение ниже пяти решений требует другого оценивания
пространственной/временной ошибки или другого интегратора; простого
отключения проверок здесь нет.
