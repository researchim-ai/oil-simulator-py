# Проверка начального приближения между FIM-пробами

**Решение: экспериментальные варианты не включены в рабочий решатель.**
Все семь запусков завершены, прошли source guard, checksum и штатный
материальный аудит. Завершение расчёта не равно прохождению строгого
сравнения. Рабочие src/scripts побайтно совпадают с контрольным снимком.

## Проверенные варианты

Синтетический связанный black-oil прогноз: 1024 ячейки, 16 добывающих,
сборное дерево на CPU, пласт и СЛАУ на RTX 3090 Ti, лимит Torch 8%,
один CPU-поток. Используется конфиг `gpu_certified`: сертификат v2,
AMG между пробами и постепенное выделение FGMRES уже включены.

1. **Тёплое приближение.** Последние сошедшиеся p/Sw/третья неизвестная,
   фазовые флаги и BHP сохраняются только внутри текущего поиска.
   Использование разрешено при изменении уставок не более 10%.
   Запасы исходного временного слоя не заменяются; новая точка служит
   только стартом Ньютона. Стартовые 0,00005 суток: FIM **17 → 24**,
   линейные попытки **32 → 33**, wall **9,980 → 11,832 с**.
   Строгая регрессия пройдена, но работы стало больше. Отклонено.
2. **Смещение секущей внутрь стороны нарушения на четверть допуска
   скобки.** Без тёплого старта. На 0,001 суток FIM **87 → 84**,
   линейные попытки **172 → 166**, wall **48,846 → 48,585 с**.
   Регрессия пройдена; отличие накоплений 9,223e-8 при бюджете 1e-7.
   Выигрыш времени не установлен, дополнительная политика не включена.
3. **Тёплый старт с обязательной первой поправкой Ньютона.** На стартовом
   окне FIM **17 → 17**, линейные попытки **32 → 26**, wall
   **9,980 → 9,613 с**, строгая регрессия пройдена. Но на 0,001 суток:
   FIM **87 → 84**, линейные попытки **172 → 129**, wall
   **48,846 → 43,667 с**, **регрессия не пройдена**. Максимальное
   относительное отличие дебитов 1,6394e-7, накоплений 1,4914e-7 при
   прежнем бюджете 1e-7. P отличается на 0,0001675 Па, BHP на 0,002863 Па;
   эти поля свои бюджеты проходят. Рабочий решатель не изменён.

Времена — наблюдения общей карты, по одной пробе варианта, а не
статистически подтверждённые ускорения. Горизонт 0,001 суток — 86,4 с
модельного времени, пять макрошагов / десять принятых половинных стадий.
Отказов макрошагов нет. Это не Norne, не месяц и не вся динамическая PR-сеть.

## Причина и границы вывода

Во внешнем поиске задан абсолютный допуск множителя уставок 1e-9.
У FIM относительный допуск дебита скважины по умолчанию 1e-5. Вблизи
множителя 0,003 изменение на 5e-10 соответствует относительному
изменению уставки около 1,6e-7, то есть укладывается в допуск скважины.

При тёплом старте Ньютон может законно принять прежнее состояние без
поправки. В сохранённой трассе новая уставка даёт совершенно тот же
расход и знак запаса ограничения: внешний поиск получает плоский
участок, затем делает дополнительные пробы. Обязательная поправка
устранила этот эффект в стартовом опыте, но не гарантирует совпадения
последнего допустимого конца скобки в длиннейшем опыте.

На последней стадии 0,001 суток:

- контрольный допустимый множитель: `0.0030502897744484796`;
- тёплый с поправкой: `0.0030502892766004173`;
- относительное отличие множителя: `1.6321336629221146e-7`;
- обе конечные скобки имеют ширину около `5e-10`, меньше допуска `1e-9`.

Это объясняет масштаб расхождения дебитов. Оба расчёта удовлетворяют
заданным критериям FIM и внешней скобки; провал регрессии сам по себе
не доказывает физическую ошибку одного из них. Но он запрещает заявлять
сохранение более строгого бюджета сравнения 1e-7. Бюджет не ослаблялся,
неудачный опыт не переименовывался в успешный.

Следующий содержательный этап — согласовать погрешности внутреннего
решения скважин и внешней скобки с бюджетом конечных расходов, затем
проверить сходимость при ужесточении этих допусков. Одного улучшения
начальной точки Ньютона недостаточно. Для промышленного включения
также нужны ограничение памяти приближения, холодный повтор при его
отказе и проверка фазовых переходов/событий/восстановления. У прототипов
этой квалификации нет; они находятся только в архиве эксперимента.

## Артефакты

`runs.json` содержит фактическую работу и wall time всех семи завершённых
запусков. `comparison.json`, `floor_comparison.json`,
`interior_comparison.json`, `floor_evolution_comparison.json` сохраняют
результаты при прежних бюджетах: P/BHP 0,1 Па, Sw/Sg 1e-8, Rs 1e-5,
относительные дебиты/накопления 1e-7. Неудачный результат имеет
`accepted: false`. В `experimental_sources.tar.gz` четыре точных
снимка src/scripts; исходные команды — `prototype.py`, `probe.py`,
`floor.py`. `startup_*` содержит траектории, протоколы и source guard.
Ни один экспериментальный исходник не подменяет рабочий src.
