# Совместный Radau для PR-транспорта и машин

Основные результаты: `pump-10ms/summary.json` и
`compressor-10ms/summary.json`. Каждый каталог содержит точный `request.json`,
мелкошаговую опорную траекторию, два подготовительных прогона и шесть полных
измеренных траекторий `.json.gz`. Запросы построены из существующих
синтетических стендов насосного PR-графа и конечных компрессорных ёмкостей;
их полное описание сохранено в JSON и не требует импорта тестовых фабрик
для воспроизведения.

В обоих методах одинаковы физика, начальное состояние, команды и допуски.
`radau3` оценивает временную ошибку полным шагом и двумя половинными;
`radau3-embedded` использует встроенный оценщик и линейную коррекцию.
Подготовка выполняется отдельно. Три пары запускаются в чередующемся порядке,
CPU, OMP/MKL по одному потоку. Измеряется весь `run`, включая создание модели
и инициализацию, без независимого аудита и сериализации результатов.
Нативные скомпилированные ядра и CUDA не используются.

За 0,01 с модели медиана насосного примера: 1,868087792 → 0,735040843 с,
ускорение 2,54×; нелинейных решений 24 → 6. Компрессорного:
2,089079884 → 0,772900724 с, 2,70×; 21 → 6. Компрессорный встроенный режим
учитывает одно начальное согласование алгебраических состояний машин.
Это не сравнение двух версий исходников или одинаковых временных сеток:
сравниваются два оценщика временной ошибки на новой общей схеме машин.

Все двенадцать измеренных траекторий прошли независимый NumPy-аудит
PR-состояний, карт, PS/PH, стадийных запасов, углового момента и энергетических
потоков. Отказов и BE fallback не было. Остатки общего баланса энергии
не превышали 6e-10 Дж. Опорная траектория той же физики считалась с верхним
шагом 0,0003125 с. В исходной норме точности конечные расхождения нового
режима равны 5,5955e-6 для насоса и 0,51343 для компрессора; допустимо ≤1.
Это проверка временной чувствительности, не внешняя физическая валидация.
Отдельный тест подтверждает третий порядок на точном решении изолированного
привода; изменение карт/мощностей в опубликованных стадиях аудит отклоняет.

Результаты относятся к небольшим закрытым транспортным PR-сетям с машинами.
Гравитационные сепараторы, PI и актуаторы полной установки пока не включены
в этот общий временной адаптер. Нельзя переносить ускорение на всю установку,
Norne, GPU, прогнозы на годы или заявлять по нему режим реального времени.
Динамические signed-карты с переходом скорости через ноль и жидкие смеси
в насосных трассах пока явно отклоняются новым адаптером.

Воспроизведение из корня проекта:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/benchmark_pr_driven_radau.py benchmarks/reports/pr_driven_radau/pump-10ms/request.json --output /tmp/pr-pump-radau --reference-step-s 0.0003125 --repeats 3
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/benchmark_pr_driven_radau.py benchmarks/reports/pr_driven_radau/compressor-10ms/request.json --output /tmp/pr-compressor-radau --reference-step-s 0.0003125 --repeats 3
```

`sources.tar.gz` содержит файлы из SHA-256-манифеста обеих серий;
`checksums.json` фиксирует входы, результаты и архив. Во время замеров
скрипт проверяет неизменность исходников. Подготовительные эксперименты
на 0,001 с модели находятся в `pilot-1ms/`; они предшествуют добавлению
начального согласования карт и независимого стадийного аудита. Их результаты
не используются в приведённом итоговом сравнении.
