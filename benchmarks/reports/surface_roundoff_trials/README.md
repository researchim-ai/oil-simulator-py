# Стоимость подтверждения сходимости PR-сети

Продолжение работ от 13 ноября 2026 года. Проверена исходная конфигурация
`surface_pr_integrated_facility_liquid_mixture.json`, ограниченная первым
интервалом 1 мкс. Физические уравнения, квадратуры и допуски не менялись.
Пластовый решатель не изменялся. Это квалификация численной политики на
ограниченном старте, а не полное подтверждение рабочего цикла установки.

## Изменение

Внутри явно разрешённого вызывающим кодом бюджета стагнации/округления
решатель теперь требует две последовательные попытки без снижения лучшей
нормы хотя бы на 1%, раньше требовались четыре. Если норма заметно снижается,
счётчик сбрасывается. Вне разрешённого бюджета этот механизм не останавливает
Ньютон. Возвращается лучшая допустимая итерация; затем применяется ранее
исправленная итоговая построчная проверка сходимости. Целевой допуск и
разрешённый бюджет округления сохранены.

На CPU дополнительно переиспользуется невязка при точном совпадении пробного
вектора с текущим либо последним пробным. Порядок проб не меняется, приближённых
ключей нет, кэш ограничен одной итерацией. На CUDA таких проверок совпадения
нет, дополнительных синхронизаций ради них не добавлено.

Изолированная проверка переиспользования без изменения подтверждения стагнации
дала всего четыре пропущенных вычисления: 718 → 714. Время одиночной пары
70,43 → 71,97 с не подтверждает ускорения этой оптимизации на данном стенде.
Основной измеренный выигрыш относится к сокращению подтверждения стагнации.

## Три пары на одинаковых исходниках

Каждый вариант запускался отдельным CPU-процессом, один поток OMP/MKL,
`CUDA_VISIBLE_DEVICES=''`. Порядок второй пары обратный. Исходники проверены
SHA-256 до и после каждого запуска; все шесть запусков относятся к одному
поколению исходников. Контрольная политика: четыре подтверждения, без
переиспользования одинаковых проб. Новая политика: два подтверждения и
переиспользование одинаковых проб.

- Пара 1: 74,176 → 63,020 с.
- Пара 2, обратный порядок: 72,338 → 61,179 с.
- Пара 3: 71,541 → 61,088 с.

Медиана: **72,338 → 61,179 с**, сокращение времени **15,43%**. Это три пары
инструментированных запусков на одном стенде, не статистическая гарантия
для другого оборудования, физического режима или полного рабочего цикла.

Во всех контрольных запусках — 718 явных вычислений невязки и 45 Якобианов;
во всех новых — 467 вычислений и 36 Якобианов. Число связанных решений
осталось равным шести: временные полный шаг/два полушага, в каждой пробе
два порядка квадратуры. Построение производных не включено в счётчик явных
вычислений невязки. Сокращается стоимость доведения систем до сходимости,
а не число физических проб.

## Точность и независимый аудит

Все шесть запусков прошли независимый аудит компонентов, импульса и энергии.
Максимальная локальная энергетическая невязка новой политики — около
6,04e-8 Дж. Число фаз и метки их ветвей совпали с контрольными.

Конечные состояния не совпадают побитово. Максимальные абсолютные различия
306 численных координат относительно контрольной политики:

- давление: 3,28e-6 Па;
- температура: 5,40e-12 К;
- интерфейсы: 1,54e-14 м;
- компонентные количества: 6,20e-11 моль;
- записанная полная энергия: без различия.

При отдельной сравнительной шкале `atol=1e-9`, `rtol=1e-8` наибольшее
отношение отклонения к бюджету — 0,0003272. Это шкала сравнения координат,
не изменение временных/нелинейных допусков модели. Хеши первых двух
глобальных решений совпали, следующих четырёх — различаются. Эти различия
не скрыты под утверждением о побитовой эквивалентности.

Проверки самого решателя включают остановку на границе, округление,
плотный/разреженный пути, сохранение лучшей допустимой итерации, продолжение
продуктивного снижения невязки внутри бюджета, запрет принятия невязки вне
бюджета и отсутствие переноса значений между разными задачами.
Расширенный набор: **124 прошли, один CUDA-тест пропущен**. Он включает
гравитационные сосуды/патрубки, открытые границы, теплообмен, трубы, насосные
соединения, управление и restart. GPU-режим в этом этапе не квалифицирован.

Продолжение из нового checkpoint с 1 до 2,5 мкс завершилось без отказов
за 57,14 с. Принят интервал 1,5 мкс с временной ошибкой 0,05709 и предложен
следующий шаг 2,25 мкс. Независимый аудит продолжения также прошёл;
максимальная локальная энергетическая невязка — 1,16e-7 Дж. Это одиночный
контроль restart/роста шага, не отдельное подтверждение процента ускорения.

## Воспроизведение

Для контрольной политики CLI:

```bash
python scripts/run_pr_controlled_surface.py CONFIG --device cpu --stagnation-patience 4 --evaluate-identical-trials --output REFERENCE.json
```

Новая политика используется по умолчанию, обе настройки записываются в
`numerical_policy`. Самостоятельная воспроизводимая серия ограниченного
старта, из корня репозитория:

```bash
python benchmarks/reports/surface_roundoff_trials/run_pairs.py --output /tmp/surface_roundoff_reproduction --pairs 3
```

Этот скрипт самостоятельно задаёт CPU/число потоков, чередует порядок,
ограничивает каждый процесс 160 секундами, проверяет хеши исходников и
запускает независимый аудитор. В окружении должен быть установлен Torch.
Исходная геометрия микростенда не изменяется.

`validation.json` содержит времена, счётчики и сравнения; `reports.json.gz`
содержит полные шесть отчётов, инструментирование, журналы и драйверы.
Главное структурное ограничение — шесть связанных решений — остаётся;
ускорение полного секундного расписания и GPU здесь не заявляется.
