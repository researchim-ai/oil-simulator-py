# Пакетная гидравлика сборного дерева: CPU-квалификация

Опциональный `network.hydraulic_backend=torch_batch` объединяет независимые
трубы одного уровня. Сохранены интеграл импульса в координате давления,
PVT/PVTO, moving-bubble splitting, Colebrook, float64, квадратурные допуски,
неявные чувствительности и проверки механического баланса. Плотной
матрицы по трубам нет. [Метод и настройки](../../../docs/BATCHED_BLACKOIL_HYDRAULICS.md).

## Окончательная версия: полный FIM

Последовательные парные запуски, один Torch CPU-поток, CUDA отключена.
Сравниваются одинаковые физические конфигурации: меняется только численный
`hydraulic_backend`. Источники неизменны внутри каждого запуска и совпадают
с окончательной версией, что проверено в `validation.json`.

- **512 скважин, 1024 ячейки, одни модельные сутки:**
  scalar **26.069 с**, batch **2.944 с**,
  ускорение **8.86×**.
- **2048 скважин, 4096 ячеек, одни сутки:**
  scalar **102.706 с**, batch **10.225 с**,
  ускорение **10.04×**.

В каждой задаче принят один шаг. Все скважины работают в режиме surface,
отводы реально рассчитаны пакетно: 512/2048, **0 скалярных повторов**;
общий коллектор — существующая одиночная скалярная труба.
Время `solve_wall_s` охватывает фактический FIM-прогон, не только одно ядро.
Это одиночные окончательные парные замеры; ускорения не экстраполируются
на произвольную топологию, глубокие цепочки, другие составы или Norne.

Число ячеек и диаметр общего коллектора меняются между размерами
(2048: 1 м вместо 0,5 м); сравнение scalar/batch **внутри каждого размера**
идёт на одной и той же физике. Это не тест сильного масштабирования между
512 и 2048. Каждая скважина имеет одну перфорацию и свой отвод.

Максимальная разность конечного давления: **2,80e-9 Па**;
Sw/Sg — менее 8e-16; Rs — менее 5e-14. Относительная разность
накопленных компонентных отборов менее 7e-14.
Заранее сохранённые бюджеты — `comparison_budgets.json`:
0,1 Па, 1e-8 для Sw/Sg, 1e-5 для Rs, 1e-6 для накопленных отборов.
`comparison512_final.json` и `comparison2048_final.json` включают
отдельный материальный/операционный аудит обеих траекторий.

## Повторы и происхождение версий

Первичная серия `wells512_*_1/2/3` дала медианы **26,194 → 2,973 с CPU**,
**8,81×**. Начальный парный 2048-прогон — **102,572 → 10,037 с**, 10,22×.
В расчётных модулях после неё изменены только сохранение численной политики в `to_dict` и
использование сохранённой последовательности геометрии в конструкторе
пакета. Первичные SHA не переписывались; эти запуски явно отделены от
окончательных каталогов `*_final`. Медиана трёх первичных запусков не
выдаётся за медиану окончательной версии. Все окончательные пары
повторно прошли контроль и имеют собственные исходные hashes.

## Разные трубы и составы

`heterogeneous128_final_cpu`: 128 независимых труб, seed 57;
длины 100–450 м, диаметры 0,07–0,14 м, подъёмы 0–40 м, разные
шероховатости, K, компонентные расходы и выходные давления.
Три последовательных повтора после прогрева обоих путей:

- медиана scalar **1.397784 с**;
- медиана batch **0.103952 с**;
- ускорение ядра **13.45×**;
- максимальная разность давления **2.53e-06 Па**;
- максимальная масштабированная разность производных **1.43e-10**;
- разность диссипации **1.41e-10**.

Это отдельный тест труб, не время пласта/площадки. Составы здесь содержат
свободный газ; движение точки насыщения проверяется другими тестами.
Сравнение выполняет сам `PipeBatch`, без скалярного повторного решения.

## Пласт и ограничения оборудования, 30 суток

`coupled_*_final_cpu`: 3 ячейки, 2 скважины, 6 пятисуточных шагов,
существующая обратная связь ограничений площадки с добычей.
Оба пути прошли независимый аудит массы и операционных ограничений.

Scalar **12.775 с**, batch **12.431 с CPU**.
Разность давления — **7,92e-9 Па**, накопленных компонентных отборов —
**4,99e-14 относительно**. Для такой малой задачи устойчивое ускорение
не заявляется; это проверка согласованности сопряжения.
Точная сводка — `coupled_final_comparison.json`.

## Проверки и границы

Основная регрессия: **182 passed, 9 skipped** (`regression.txt`).
Отдельно **8 passed** проверок аудитора (`audit_regression.txt`);
модули не пересекаются: всего **190 прошедших тестов**.
Проверяются производные против конечных разностей, полный скважинный
Шур, реальные FIM-шаги, pickle restart, старые состояния без новых полей,
сохранённый фазовый переход, реальный choking, явный скалярный повтор,
отклонение изменённой физики/нечисловых полей/испорченных балансов и
недостоверных счётчиков исполнения.

Повтор по скалярному пути сохраняет его рекурсивное дробление квадратуры
и поиск допустимой физической ветви. Его физический/численный отказ
передаётся вызывающему коду; допуски не ослабляются.
Счётчики отчёта относятся к конкретному solve/принятому шагу и не являются
профилем всех итераций FIM.

Матрица пласта остаётся разреженной. `blackoil_fim.py` и `torch_linear.py`
не изменены. Термодинамика этой ветви изотермическая homogeneous Rs-only;
нет slip/holdup, реверса/нулевого расхода, нисходящих труб или разделения
потока. Проверка против старого представления не является независимой
экспериментальной калибровкой PVT/корреляций.

Драйвер NVIDIA недоступен (`nvidia-smi -L`, exit 9). Это CPU-измерения,
не GPU/Norne-результат. На GPU ещё остаются поэлементные admission-проверки
составов; топологическая оркестрация и отчёт остаются на host.

## Воспроизведение

Запускать последовательно; каждый выходной каталог должен отсутствовать:

```bash
export CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts
python scripts/run_structured_well_forecast.py --config benchmarks/reports/surface_pipe_batch/wells2048_scalar_input.json --days 1 --report-days 1 --output /tmp/pipe_scalar2048
python scripts/run_structured_well_forecast.py --config benchmarks/reports/surface_pipe_batch/wells2048_torch_batch_input.json --days 1 --report-days 1 --output /tmp/pipe_batch2048
python scripts/check_pipe_batch_forecast.py /tmp/pipe_scalar2048/trajectory.json.gz /tmp/pipe_batch2048/trajectory.json.gz --budgets benchmarks/reports/surface_pipe_batch/comparison_budgets.json --output /tmp/pipe_comparison2048.json
python scripts/benchmark_blackoil_pipe_batch.py --pipes 128 --repeats 3 --output /tmp/pipe_heterogeneous128
```

Конфигурации месячного сопряжения — `coupled_scalar_input.json` и
`coupled_torch_batch_input.json`; запускать существующим
`run_fim_facility_forecast.py --days 30 --report-days 5` и сравнивать
`compare_fim_facility_forecast.py --allow-numerical-policy` с теми же бюджетами.
