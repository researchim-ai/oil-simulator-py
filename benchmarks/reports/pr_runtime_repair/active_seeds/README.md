# Удаление повторной работы фазового предиктора

Сошедшиеся и точно неподвижные старты исключаются из следующих итераций
независимого пакетного поиска. Все исходные кандидаты возвращаются в
исходном порядке. Проверка кривизны выполняется только при выполнении
предварительных обязательных критериев стационарности. Седловые точки
по-прежнему отклоняются; неразрешённые старты передаются прежнему fallback.
Критерии точности, EOS и физические модели не изменены.

На первом пробном coarse/fine шаге исходной подробной установки:
34.7151 с до изменений, 32.4726 с после. Состояния coarse/fine и индикатор
ошибки совпали точно. Это одиночный последовательный замер на общем хосте,
не доказательство устойчивого ускорения на 6.5% и не полный цикл установки.
GPU проверена на эквивалентность, производительность GPU не измерялась.

Проверки: 29 CPU-тестов устойчивости, 26 CPU/CUDA-тестов (частично
пересекаются), 33 численные проверки плёнки и 3 пропуска CUDA.
Экспериментальное расхождение плёнки не исправлено. Замыкание плёнки не
используется в этом интегрированном стенде и не вызывает его микрошаги.

Первую временную ошибку по-прежнему определяет скорость в gas_recycle_0:
22.274250199161266 при dt=1e-4 с. Цена термодинамики и необходимость
разрешать быстрый пуск — разные ограничения. Полный подробный цикл
не квалифицирован. Упрощённый Darcy-рецикл уже реализован отдельно;
его нельзя выдавать за точное разрешение инерционного пуска.

В comparison.json сохранены оба состояния, в summary.json — хеши
исходников. baseline.py и candidate.py фиксируют сравниваемые ядра.
Для повтора из корня проекта: PYTHONPATH=src:scripts:tests
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 CUDA_VISIBLE_DEVICES='' python
benchmarks/reports/pr_runtime_repair/active_seeds/repeat.py.
Повтор пишет /tmp/pr-active-seeds-repeat.json и не заменяет этот результат.
