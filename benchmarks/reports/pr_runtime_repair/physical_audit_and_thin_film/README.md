# Проверки кэша физического состояния и тонкой плёнки

Исправлены два воспроизводимых дефекта:

- После cp.mul_(1.1) проверка прежнего транспортного состояния проходила
  через кэш, хотя без кэша возникал ConservationError по энергии. Кэш графа
  и колонны теперь отслеживает фактические параметры EOS, их замены и версии.
  AD-запросы обходят кэш. Изменение только времени/следующего шага повторной
  физической проверки не требует; границы шага проверяются перед кэшем.
- Фиксированная нижняя граница alpha=1e-5 исключала существующие решения
  тонкой кольцевой плёнки. Интервал расширяется по гравитационному масштабу,
  но корень по-прежнему определяется исходным балансом сил. Проверены
  независимый гравитационный предел, пакетные входы и CUDA.

43 расширенных CPU-теста прошли, 48 CPU/CUDA-тестов плёнки и кэша прошли.
Дополнительно прошли 34 целевых CPU-теста; наборы частично пересекаются.
Первый coarse/fine шаг исходной подробной установки сохранил оба состояния
и оценку ошибки точно. Исправление кэша не объявлено кратным ускорением.

Проверенные, но НЕ включённые варианты:

- stagnation_single_phase + local_single_phase: начальная временная ошибка
  9.13694 вместо 22.27425, но всё ещё >1. Это другая модель граничных условий;
  её глобальная эквивалентность не утверждается, конфиг не заменён.
- 20 вместо 10 итераций пакетного предиктора: 391 вместо 418 вызовов fallback,
  но 37.98 вместо 33.81 с. Состояния совпали точно; изменение отклонено.
- Нормированный градиент резервного направления: тот же результат и те же
  418 fallback, 32.79/32.80 с. Изменение отклонено.

RTX 3090: первый пробный шаг занял 82.713 с с холодной компиляцией.
Индикатор 22.274250199161045 против CPU 22.274250199161266. Установившаяся
GPU-производительность этим одиночным измерением не определена.

Повторён Hannover: 16 окон, MAE 58.83796/48.28435 Pa; квалификация false.
Исправление нижней границы не исправляет экспериментальное замыкание.
Полный подробный цикл установки также пока не квалифицирован. Многошаговое
локальное интегрирование быстрых частей в этой работе не реализовано.

Исходники фиксируются в sources и source_sha256. Отчёты опытов сохраняют
оба состояния. Изменения не закоммичены.
