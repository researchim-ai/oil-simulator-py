# Пакетное минимизирование неразрешённых фазовых стартов

Рабочий путь сохраняет исходный Newton-предиктор. Уже принятые кандидаты
не изменяются. Для оставшихся стартов выполняется независимое пакетное
inverse-BFGS минимизирование общего Gibbs-объектива, затем снова прежние
проверки стационарности, кривизны и полного EOS. Неразрешённые случаи
возвращаются исходному скалярному LBFGS. Временные/физические допуски,
исходные старты, геометрия и команды стенда не изменены. Матрицы BFGS
локальны в пространстве состава каждого старта, не глобальны для сети.

На исходном подробном стенде CPU-пара: 33.1668 → 25.9952 s (1.276×).
Оба состояния coarse/fine и ошибка совпали точно. В отдельном
инструментированном запуске новой реализации резервных вызовов было 0
вместо прежних 418. Запуски выполнены на общем хосте, не являются
статистическим исследованием производительности.

RTX 3090: 47.2162 s, состояния и ошибка точно совпали с прежним GPU-
расчётом. Прежние 82.713 s включали холодную компиляцию; их отношение
не выдаётся за измеренное установившееся ускорение GPU.

80 CPU/CUDA-проверок термодинамики, 52 CPU-проверки сопряжения/регрессий
и 32 CPU/CUDA-проверки Darcy прошли. Наборы пересекаются. Внешний барьер
повторён с отрицательным результатом: Hannover MAE 58.84/48.28 Pa;
VLE вычислены 17/17 точек, попадание давления в прежние границы 15/17.
Численная проверка не объявляется экспериментальной калибровкой.

Также добавлен точный ламинарный обратный закон Darcy + местная потеря,
включая аналитические AD-производные; переходный/турбулентный и vmap-
пути сохраняют исходный решатель. На сокращённом стенде одна пара дала
35.3694/35.3156 s с точно одинаковыми состояниями: заметного выигрыша
для всей установки только от этого изменения не заявляется.

Первый пробный шаг исходной подробной установки всё ещё отвергается
по временной ошибке 22.27425 > 1. Полный цикл не квалифицирован.
Локальное подшагивание быстрых труб в этой работе не реализовано.

Для повтора CPU-пары из корня проекта:
PYTHONPATH=src:scripts:tests OMP_NUM_THREADS=1 MKL_NUM_THREADS=1
CUDA_VISIBLE_DEVICES='' python
benchmarks/reports/pr_runtime_repair/batched_minimization/repeat_cpu_pair.py
Результат записывается в /tmp/pr-batched-minimization-repeat.json.
Исполнявшиеся исходники и их хеши сохранены; коммитов не было.
