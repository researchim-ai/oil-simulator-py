# Расширенная область переиспользования неактивных уставок без чувствительности

Ранее сертификат версии 2 применялся только при `sensitivity_safeguarded`.
Теперь `inactive_cap_certificate_version=2` позволяет использовать его
с обычным `facet_safeguarded`. Дополнительных линейных решений для
чувствительности, конечных разностей или суррогатных расходов нет.
Существующая физическая проверка переиспользуется, новая модель не вводится.

## Что допускает пропуск FIM

Сначала из одного старого состояния/dt/управления физически решается
недопустимая проба. Для каждой добывающей скважины проверяются режим
поверхностного давления либо BHP, отсутствие активной уставки дебита и
неравенство переключения. Если оно остаётся выполненным при следующем
множителе дебита, уравнения всей системы не изменяются. Уже доказанная
недопустимость сохраняется. Пробу можно зарегистрировать со ссылкой на
исходное решение без повторного FIM.

Версия 1 использует двукратный запас над порогом активирования уставки;
версия 2 сохраняет 25% запаса. В обеих версиях граница области строго
выше вычисленного порога переключения. За её пределами запускается FIM.
При наличии хотя бы одной скважины с активным дебитом сертификата нет.
В следующий шаг, оценочную половинную стадию, новое управление или
восстановленный расчёт сертификат не переносится. Допустимое итоговое
решение всегда получено обычным FIM при выбранных уставках. Сетка
начального поиска и допуск ширины скобки не изменены.

Default версии 1 сохранён. Историческое поведение `sensitivity_safeguarded`
с версией 2 также сохранено. Opt-in конфиг:
`configs/fim_blackoil_facility_depletion_gpu_certified.json` отличается от
`gpu_hybrid_amg` только номером сертификата. AMG и постепенное выделение
базиса FGMRES одинаковы с обеих сторон сравнения.

## Воспроизведение

Все физические прогоны исполнялись на одном замороженном снимке
`executed_sources.tar.gz`. Использована RTX 3090 Ti, лимит Torch 8%, один
CPU-поток, пласт/СЛАУ на GPU, сборное дерево на CPU. Модель синтетическая:
1024 ячейки, 16 скважин, изотермический black-oil и квазистационарное
оборудование. Это не Norne и не валидация всей динамической PR-сети.

`comparison.json` содержит строгие результаты; `measure.py` — команды
чередующихся пар. Независимый `check_capacity_certificate_policy.py`
проверяет completion, checksum, неизменность исходников внутри прогона,
одинаковые Python/PVT/конфиги/устройство/лимит памяти/потоки. Разрешено
различие только `inactive_cap_certificate_version` 1 → 2. Применяются
прежние бюджеты P/BHP 0,1 Па, насыщенности 1e-8, Rs 1e-5, относительные
дебиты и накопления 1e-7. Сам аудитор дополнительно проверяет, что
исполненная версия сертификата соответствует конфигу.

После заморозки снимка в текущем общем компараторе дополнено только
информационное перечисление разрешённых численных настроек; вычисления
и проверки не менялись. Новые тесты лежат отдельно от исполненного кода.

## Ограничения скорости

Завершены две чередующиеся стартовые пары по 0,00005 суток и одна пара
по 0,005 суток (432 с модельного времени). Старт: **20 → 17 FIM** в
каждой паре; медианы времени **10,618 → 10,387 с**. Ускорение по этому
короткому окну не установлено с достаточной повторяемостью.

На участке 0,005 суток выполнены одинаковые 11 макрошагов / 22 принятых
половинных шага / 33 связанных решения, без отказов. Фактические FIM:
**228 → 195** (на 14,47% меньше); линейные попытки **512 → 409**
(на 20,12% меньше). Дополнительных решений чувствительности — ноль.
Wall time этой пары: **136,581 → 115,427 с** (наблюдаемое сокращение
15,49%, отношение 1,18). Поиск по-прежнему оценивает 228 кандидатов,
но 33 из них теперь доказанно не требуют повторного решения пласта.

Во всех трёх парах конечные поля, BHP, дебиты и накопления совпали
побитово. На длиннейшем окне отдельно проверены все 22 принятые стадии:
времена, dt, отборы, число итераций Ньютона, surface-отчёты скважин/труб,
площадочные отчёты и команды также совпали побитово
(`stage_comparison.json`). Максимальный полный макрошаг — около 59,68 с;
на нём ведущая нормированная временная ошибка давления 0,795 при пороге 1.
Допуск давления 2,5 Па и остальные строгие регрессионные допуски сохранены.

Пройдены 89 CPU-проверок (48 базовых, 5 новых защит аудитора/компаратора,
36 проверок прогноза и фиксации состояния), шесть CUDA-случаев пропущены
в CPU-запусках. Отдельно пройдены две CUDA-проверки смены команд,
восстановления и физической эквивалентности. Старый сохранённый месячный
прогноз sensitivity и стартовый AMG-архив принимаются новым аудитором.

Карта/хост общие; изолированное ускорение оборудования не заявляется.
В части стартовых/контрольных замеров параллельно выполнялись наши
проверки корректности, поэтому wall time — наблюдение, а не чистый
производительный замер. Число FIM и точность проверяются независимо
от загрузки. Полный месяц повторно не запускался, результаты коротких
окон не переносятся на многолетний прогноз.

Пропускается только повтор неизменившегося недопустимого состояния.
Оставшиеся решения для нового времени и для действительного поиска
границы остаются; монолитное сопряжение наземных ограничений с Ньютоном
этой работой не реализовано.
