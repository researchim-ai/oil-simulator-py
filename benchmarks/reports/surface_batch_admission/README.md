# Пакетный допуск PVT/PVTO: меньше обменов с host

`blackoil_batch_admission.validate_inputs` заменяет отдельные вызовы
`model.validate` для каждой трубы внутри `PipeBatch`. Покрытие PVT/PVTO,
непрерывность Bo/mu_o в точке насыщения, знаки и конечность расходов,
а также zero-GOR PVTO для производных чистой воды проверяются тензорно.
На host передаётся один пакет из пяти флагов на весь пакет труб.

Это дополнительная оптимизация уже существующего `torch_batch`, не
изменение интеграла импульса, квадратуры, производных или временного шага.
[Алгоритм и область модели](../../../docs/BATCHED_BLACKOIL_HYDRAULICS.md).

## Честное парное сравнение

В обеих ветвях запускается **один текущий FIM и одно пакетное ядро труб**.
`run_pipe_admission_forecast.py --admission legacy` временно подставляет
прежний построчный допуск только в память отдельного процесса. Режим
`batch` использует новый тензорный допуск. Файлы исходников не заменяются;
геометрия, PVT, физические ограничения и конфигурации совпадают.

Обычный driver проверяет учёт массы и неизменность расчётных исходников.
Дополнительный `admission_policy.json` сохраняет выбранный режим, SHA256
wrapper, проверку его неизменности и число реальных вызовов допуска.
Таким образом, замер не смешивает эту оптимизацию с прошлым ускорением
самого ядра труб относительно независимых скалярных труб.

Один Torch CPU-поток, float64, CUDA отключена; процессы идут последовательно,
CPU-тесты во время замеров не запускаются. Измерен весь `solve_wall_s`.

- **512 скважин / 1024 ячейки / одни сутки:** три парных запуска.
  Legacy: 2,978 / 3,042 / 2,888 с; batch: 2,468 / 2,589 / 2,612 с.
  Медианы **2,978 → 2,589 с CPU**: время меньше на **13,1%**, скорость 1,15×.
- **2048 скважин / 4096 ячеек / одни сутки:** один парный запуск,
  **9,950 → 8,522 с CPU**: время меньше на **14,3%**, скорость 1,17×.

Во всех восьми прогонах принят один шаг, скважины работают по давлению
сети. **Все конечные P/Sw/Sg/Rs и накопленные компонентные отборы
совпали побитно**. Обе траектории каждого сравнения независимо прошли
учётный аудит. Результаты находятся в `comparison*.json` и исходных
`trajectory.json.gz`; численные результаты не нормировались задним числом.

512-скважинный прогон вызвал допуск 16 раз (пакеты по 128 труб),
2048-скважинный — 64 раза. Новый путь передаёт один статусный пакет на
такой вызов; legacy дополнительно выполняет построчные проверки на
каждую трубу. Это счётчики исполнения, **не измеренные задержки PCIe**.

## Строгость допуска

Тесты сравнивают данные с прежним валидатором, покрывают смешанные режимы,
плохую строку внутри допустимого пакета, отрицательные/нулевые/нечисловые
расходы, выход давления за покрытие, недостаточный Rs-диапазон, разрывы
Bo и mu_o, плоский Rs, чистую воду без zero-GOR PVTO, некорректные типы
давления. Тест на 512 строк запрещает вызовы `model.validate` и
`Tensor.__bool__/__float__/__int__`; единственное разрешённое чтение
статуса — `tolist` для пяти флагов.

Входные Tensor на устройстве модели принимаются без извлечения их
значений в Python. Проверка идёт под `torch.no_grad`; физический граф
интеграла строится дальше обычным образом. Безопасные индексы неактивных
строк не ослабляют условия допуска. Переполнение полной компонентной
массы явно отклоняется.

Общая регрессия: **205 passed, 10 skipped**, лог `regression.txt`.
Новые CUDA-тесты предусмотрены, но в окружении драйвер NVIDIA недоступен.
GPU-ускорение, полная автономность GPU и изменение скорости Norne не
заявляются. В скалярных одиночных трубах/повторах, управляющем коде сети
и отчётах сохраняется host-работа. Линеаризация пласта и
`blackoil_fim.py` / `torch_linear.py` не изменены.

Для сравнения 512/2048 используются разные размеры пласта и диаметры
общего коллектора. Это две отдельные квалификации, не сильное
масштабирование одной физической задачи. Заключение о 13–14% относится
к этим CPU-сценариям; для других PVT-таблиц и топологий требуется замер.

## Воспроизведение

Выходные каталоги должны отсутствовать. Запускать последовательно:

```bash
export CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts
python scripts/run_pipe_admission_forecast.py --admission legacy --config benchmarks/reports/surface_pipe_batch/wells2048_torch_batch_input.json --output /tmp/admission_legacy2048
python scripts/run_pipe_admission_forecast.py --admission batch --config benchmarks/reports/surface_pipe_batch/wells2048_torch_batch_input.json --output /tmp/admission_batch2048
python scripts/check_fim_well_forecast.py /tmp/admission_batch2048/trajectory.json.gz
pytest -q tests/test_blackoil_batch_admission.py tests/test_blackoil_pipe_batch.py tests/test_pipe_batch_forecast_audit.py
```

Все SHA256 и повторные проверки источников/балансов — в `validation.json`.
