# Проверка BlockJacobi на полном адаптивном интервале

15 ноября 2026. CPU, float64, один поток, Torch 2.7.0+cu126.
Это квалификация шестизлового PR-графа, не всей наземной установки.
GPU недоступен драйверу в текущем окружении; CUDA-результатов здесь нет.

## Постановка

Без изменений взят `configs/surface_pr_open_relaxation.json`: два параллельных
двухъячеечных трубопровода, два сосуда, бинарная двухфазная смесь,
материальный вход, резервуар с разрешённым обратным потоком и закрытие/
открытие связи. Четыре отчётных интервала по 1 мс, всего **0,004 с модели**.
Это слабое возмущение; длительные промысловые режимы им не подтверждаются.

Сравниваются диагональный и физический блочный предобусловливатели одного
производственного Radau3 `advance`. Все допуски и физические проверки
сохранены. Три пары в порядке AB/BA/AB. Каждый запуск получает новую
модель; короткий прогрев отдельной модели не входит в таймер. В таймер
включены адаптивные попытки, все coarse/fine решения и внутренние проверки,
сборки Якобиана/факторов, первая подготовка границ и сериализация отчётов.
Независимый scalar-PR аудит выполняется вне таймера.

## Результат: ускорение не подтверждено

- Диагональный вариант: 42,434; 44,699; 44,150 с. Медиана **44,150 с**.
- Блочный вариант: 44,629; 44,894; 44,243 с. Медиана **44,629 с**.
- Отношение времён **0,9893×**; блочный вариант примерно на 1,1% медленнее
  по медианам. При таком размере эффекта строгая статистическая оценка
  регрессии не заявляется. Практического выигрыша эта серия не показала.

Все шесть запусков: 46 попыток, 92 принятых полушага, 138 нелинейных
решений, 129 сборок Якобиана, без отказов и fallback. Крупнейший локальный
блок — 14 неизвестных. Сокращения работы Newton на данном режиме нет.

В отчётных состояниях давление, температуры, компоненты и энергия совпали
точно; максимальная разность импульса — 4,964e-24 кг·м/с. Бюджеты сравнения
заданы в скрипте до запусков и сохранены в `summary.json`.

Две уникальные полные траектории независимо проверены по всем 92 полушагам:
scalar EOS, локальные N/M/E/S, внутренние грани и внешние потоки N/H/S.
Остальные четыре запуска используют сертификат только при точном SHA-256
совпадении полной модели, начального состояния, расписания и всех отчётов.
Это численная проверка, не экспериментальная калибровка замыканий.

`summary.json` содержит времена, исходный SHA-256-манифест, runtime,
сравнения и сертификаты. Gzip-архивы содержат все принятые состояния и
счётчики решений. Манифест фиксирует скрипт **до** последующего добавления
журнала: исторические хеши не переписаны. Производственные исходники
во время измерений оставались неизменными.

## Полная установка проверяется отдельно

`full_facility_acceptance.json` — отдельная неуспешная квалификация
`surface_pr_integrated_facility.json`: 17 связанных вершин, 8 ячеек труб,
5 патрубков сепаратора, нефтяной/водяной насосы, газовый компрессор и
управление. Запрошен цикл 0,2 с пуска + 0,2 с изоляции + 0,6 с перезапуска.

За **60,019 с** достигнут лимит: лог содержит инициализацию и первую
попытку dt=0,0001 с, **ни одного принятого шага**. `accepted: false`,
исходники неизменны. Это не сертификат решения одной секунды и не
доказательство неверной физики: расчёт не завершился в данном бюджете.
У этой установки другой временной адаптер; перенос выигрыша отдельных
тепловых проб на неё недопустим. Следующая задача — ускорение и
квалификация именно пути gravity/column/equipment/control.

`full_facility_profile.json` — отдельный 30-секундный диагностический
профиль того же старта с cProfile и остановкой по таймеру, не замер
скорости и не завершённая траектория. До остановки зафиксированы
382 вызова `trial_value`, 8 834 вызова `tensor_homogeneous` и 6 294 вызова
`ray`. Профиль показывает дорогой путь пробных невязок, EOS и патрубков;
он сам по себе не доказывает корневую причину количества итераций.
Времена вложенных функций перекрываются, складывать их нельзя.

Архивные тепловые траектории из прерванной серии независимо перепроверены
отдельно. Их времена имеют неполное происхождение и не смешиваются с
новыми измерениями: [архивный протокол](../adaptive/README.md).

## Воспроизведение

Из корня репозитория, с новым отсутствующим выходным каталогом:

```bash
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/benchmark_pr_adaptive_preconditioner.py --cases open6 --repeats 3 --output /tmp/pr_open_adaptive_fresh
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/validate_pr_integrated_facility.py --config configs/surface_pr_integrated_facility.json --device cpu --timeout-s 60 --output /tmp/pr_facility_fresh/result.json
```

Новый журнал записывает `protocol.json` до расчёта, а `progress.json` с
сертификатами — после каждого проверенного запуска. Только успешное
завершение всей серии публикует `summary.json`. Прерванные каталоги
сохраняются и не перезаписываются следующим запуском.

[Алгоритм и границы](../../../../docs/PR_BLOCK_PRECONDITIONER.md).
