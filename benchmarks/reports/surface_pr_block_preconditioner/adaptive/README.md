# Архив прерванной адаптивной серии

Шесть тепловых траекторий и один гидравлический запуск сохранились после
прерывания процесса. Завершённого `summary.json` и исходного манифеста
этой серии нет. Времена ниже — **исторические наблюдения**, а не заново
квалифицированное измерение текущей версии исходников.

Тепловые архивы повторно прочитаны и проверены текущими независимыми
аудиторами. Полные SHA-256 траекторий совпали с сохранёнными измерениями,
модели/начальные данные — с текущим 32-узловым тепловым стендом.
Обе уникальные траектории проверены во всех 58 принятых полушагах;
остальные архивы совпадают с одной из них точно. Все три пары уложились
в исходные бюджеты конечных отчётных состояний.

Независимая scalar-PR ОДУ с дополнительным уточнением дала максимальные
ошибки на всех принятых состояниях: **0,000227 K** по температуре газа,
**0,000101 K** по стенке и **0,720 Па** по давлению. Это подтверждает
сохранённые траектории; такая перепроверка не восстанавливает утраченный
манифест исходников первоначального замера.

Сохранённые медианы трёх пар: **92,490 → 80,486 с**, отношение **1,149×**
(примерно на 13% меньше времени). Это существенно скромнее ускорения
одного фиксированного жёсткого шага. Данные, сертификаты повторного
аудита и явно отмеченное ограничение происхождения времён находятся
в `revalidated_thermal.json`.

Неполный гидравлический запуск не включён в новую парную статистику.
Полная новая серия из шести запусков, её манифест и неуспешная проверка
всей установки — [в соседнем протоколе](../adaptive_open_verified/README.md).
