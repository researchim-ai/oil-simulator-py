# Продолжение режима по разрешённой узкой скобке

В большой модели четыре из девяти стадий возвращались к полному поиску:
история содержала только узкую финальную скобку, а прежний фильтр требовал
расстояние не меньше восьми допусков поиска. Допуск завершения поиска
ошибочно использовался как единственный критерий разрешимости секущей.

Для `continuation_safeguarded` сохранён приоритет широких секущих. Если их
нет, используются фактически решённые концы предыдущей скобки. Ширина
должна превышать 32 ULP координат, изменение ограничения — 64 ULP его
масштаба. Сертифицированные без нового решения строки, отсутствующие
концы, неверная допустимость, нечисловые и неположительные наклоны
отбрасываются. Это защита от округления, не оценка всей ошибки FIM.
Полученный наклон только предлагает точку: каждый новый режим решается
FIM и проверяется площадкой. Ненадёжное продолжение возвращает полный
поиск; события, периодические сканирования и аудит массы сохранены.

## Контрольная пара GPU

Одинаковые конфигурация, PVT, расписание, допуски и оборудование; меняется
только реализация поиска. Синтетическая модель 65 536 ячеек / 64 скважины,
30 суток, 9 принятых стадий, без отказов. RTX 3090 Ti, лимит Torch 12%.

- FIM-пробы: 53 → 41 (−22,6%).
- Линейные попытки: 162 → 104 (−35,8%).
- Наблюдаемое время интегрирования: 69,120 → 48,421 с (1,43×).
- Четыре возврата к полному поиску заменены локальными скобками.
- Конечное давление отличается на 2,8e-9 Па; BHP на общих отчётных датах
  — на 1,9e-9 Па. Различия расходов и накоплений порядка округления.
- Независимый аудит массы пройден обоими расчётами, без изменения допусков.

GPU и машина общие с другими задачами. Время исключает импорты,
построение модели и итоговый аудит; одна пара не доказывает устойчивый
коэффициент ускорения. Снижение количества физических решений воспроизводит
причину выигрыша без зависимости от загрузки устройства.

Сравнение с ранее сохранённым уточнённым шагом 1,25 суток
(`surface_forecast_profiles/large_run2`) также прошло исходные бюджеты:
конечное давление 3,54 Па, BHP 4,62 Па, расходы 0,0778%, накопления 0,0216%.
Данные: `comparison.json`, `finest_comparison.json`, каталоги `before`, `after`.
Конфигурации и расписания свежей пары дополнительно проверены на точное
равенство. Контроль неизменности исходников включён в каждом прогоне.

Публичный профиль: `configs/fim_blackoil_facility_field64k_continuation.json`.
Модель имеет слабое истощение; это black-oil с квазистационарной площадкой,
не Norne и не квалификация подробной переходной PR-сети. Подтверждается
численная согласованность, а не экспериментальная точность замыканий.

## Воспроизведение

Из корня репозитория (только на доступной GPU):

```sh
CUDA_VISIBLE_DEVICES=GPU-2f9ce359-f3f4-accc-bf9c-31bc88bb1cb7 CUBLAS_WORKSPACE_CONFIG=:4096:8 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONPATH=src:scripts python scripts/run_fim_facility_forecast.py --config configs/fim_blackoil_facility_field64k_continuation.json --schedule benchmarks/reports/surface_continuation_secants/schedule.json --days 30 --report-days 5 --device cuda --cuda-memory-fraction .12 --output /tmp/continuation-secant-run
```

`before_source.tar.gz` и `after_source.tar.gz` содержат точные Python-исходники
для пары; `implementation.patch` — изменение кода и регрессионные проверки.
Для старого runner из распакованного архива нужен абсолютный путь PVT
как в сохранённом `large.json`. UUID/PVT-путь следует согласовать с местом
воспроизведения; для сравнения использовать одинаковый протокол.

## Регрессия сильного истощения и проверки

Месяц CPU, 1024 ячейки / 16 скважин, два события: 490 стадий, без
отказов, аудит массы пройден. FIM 1686 → 1684, линейные попытки
5013 → 5009. Наблюдалось 263,165 с против архивных 285,115 с;
при столь малом изменении работы это не свидетельство ускорения CPU.
Относительно прежнего рабочего профиля давление отличается на 0,00314 Па,
BHP — на 0,00821 Па. Сравнение с уточнённым эталоном сохранило прежние
бюджеты: BHP 164,79 Па, расходы 0,0958%, накопления 0,1136%.
Данные: `small`, `small_comparison.json`, `small_finest_comparison.json`.

Регрессионный набор: 106 passed, 2 skipped (GPU-проверки в CPU-режиме),
см. `tests.log`. Фактическая большая GPU-пара выполнена отдельно. Ruff
и `git diff --check` пройдены. Проверены также события, периодические
сканирования, восстановление после перезапуска и откат состояния.
