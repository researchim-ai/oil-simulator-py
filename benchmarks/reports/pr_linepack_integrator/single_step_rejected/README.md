# Отклонённый вариант: один полный BE-шаг

Первый embedded-вариант принимал один полный BE-шаг и заменял step doubling
линейной оценкой разницы с трапецеидальным решением. Все шесть траекторий
прошли независимые проверки балансов. Медианы CPU составили
35,727 → 27,215 → 18,702 с (reference/newton/embedded).

Однако проверка уменьшенным шагом дала 1,45058 исходного временного бюджета
для embedded-варианта; reference/newton дали максимум 0,707525. Этот вариант
**отклонён по точности** и не включается в итоговое ускорение.
Сохранены исходники, шесть траекторий, аудиты и refinement.json/refined.json.gz.

Рабочий опциональный оценщик сохраняет обе консервативные половины шага.
Его результаты находятся в соседнем каталоге validated. Быстрые числа этого
отклонённого варианта нельзя использовать как результаты текущего решателя.
