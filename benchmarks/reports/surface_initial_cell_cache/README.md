# Повторное использование начальных свойств пласта

Область: короткий связанный изотермический black-oil опыт, 1024 ячейки,
16 скважин, 0,003 суток, 16 принятых половинных стадий. Это регрессия
оптимизации; не приёмка месяца, Norne или независимая валидация физики.

Три CPU-пары с чередованием порядка: медиана **22,64494 → 21,24506 с**,
отношение 1,06589. Хост общий, статистическая погрешность не установлена.
Точные времена всех шести запусков — `repeats.json`. Во всех парах точно
совпали конечные поля, состояния каждой принятой стадии, расходы,
давления скважин, материальные балансы, режимы и поисковые trace.

Кэш хранит только свойства и их производные для одного восстановленного
начального состояния текущего поиска мощности. Последующие итерации
Ньютона считают свои свойства. Кэш не переносится на другой шаг или
полную/половинную стадию. Установленный предел 64 МиБ относится к
сохранённым тензорам; при превышении выполняется обычный расчёт.
Дополнительных сравнений массивов или чтений скаляров с GPU нет.

В отдельной паре cProfile число вычислений функции свойств сократилось
с **528 до 387** (включая полные стадии оценки ошибки). Под профилировщиком
функция занимала 7,49 → 5,50 с; эти времена не равны времени обычного запуска.
Усилие линейного/нелинейного решения и численные допуски не изменены.

`measured_sources.tar.gz` точно соответствует source_sha256 из повторов;
контрольные суммы архива проверены перед публикацией. `repeat.py` сохраняет
точный скрипт исходного опыта; `config.json` и PVT содержат модель.
Переносимая команда для актуального рабочего дерева:

```sh
CUDA_VISIBLE_DEVICES='' OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
PYTHONPATH=src:scripts python scripts/benchmark_initial_cell_cache.py \
  --config benchmarks/reports/surface_initial_cell_cache/config.json \
  --days .003 --pairs 3 --device cpu --output /tmp/cell_cache_pairs.json
```

CLI не перезаписывает существующий результат. Он повторно проверяет
балансы и управление каждой пары, точное совпадение всех принятых состояний
и неизменность исходников, PVT и конфига. Новый запуск не обязан повторить
времена общего хоста из опубликованного опыта.

Дополнительно: 97 тестов ядра/сопряжения прошли, 9 CUDA-тестов пропущены в
CPU-окружении. Отдельные проверки новой оптимизации на RTX 3090 Ti прошли:
2 теста, лимит аллокатора 8%. Материальные балансы проверяются по прежним
критериям; экспериментальная калибровка этим не утверждается.

Пакетный расчёт одиночной магистрали отдельно проверен и отвергнут:
24,79 с против 22,88 с на CPU при точном совпадении результатов. Его
в рабочий путь не переносили; `rejected_singleton.json` сохраняет наблюдение.

После переноса в рабочее дерево: 146 тестов прошли, 10 пропущены в CPU-окружении. Лог — working_tree_tests.log. Дополнительный месячный контроль завершён и принят; полный протокол — month_comparison.json.
