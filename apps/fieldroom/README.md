# FIELDROOM

Самостоятельное инженерное приложение. `web/` — отдельный информационный сайт;
эта директория не требует его файлов и не входит в его публикацию.

```sh
python -m http.server 8771 --bind 127.0.0.1 --directory apps/fieldroom
```

Откройте http://127.0.0.1:8771/. Создайте проект или добавьте демонстрационный.
Главная хранит проекты в IndexedDB: название, заметки, один активный архив.
Архивы проходят общий валидатор `archive.js` до сохранения. Резервная копия
JSON содержит весь проект; восстановление создаёт новый ID, не перезаписывает
существующие проекты. Название и заметки сохраняются также при переходе
к другому проекту, создании проекта и скачивании резервной копии; замена
расчёта сохраняет текущие правки карточки вместе с архивом. При ошибке записи
правки остаются в форме для повторной попытки. Данные привязаны к адресу и профилю браузера; очистка
данных браузера удаляет их. Сохраняйте резервные копии вне браузера.

`viewer.html?project=ID` открывает выбранный проект. `viewer.html` без ID —
демонстрационный просмотр. Кнопка временного расчёта меняет только текущий
просмотр, не сохранённый проект. Постоянная замена архива доступна в карточке.

Сейчас: проекты, 3D/2D-просмотр, поля, истории, балансы, инспектор и CSV.
Следующие самостоятельные модули: редактор модели и графа; версии сценариев
и архив запусков; backend заданий CPU/CUDA; ИИ-помощник с контекстом проекта,
предпросмотром изменений и журналом действий. Эти модули ещё не подключены.
API-ключи и вызовы ИИ в текущей браузерной версии отсутствуют.

Границы адаптера и физические ограничения: `docs/ENGINEERING_VIEWER.md`.
